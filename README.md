# 项目总览

将抽象的心理与社交困境，转化为可操作、可沉浸、可迭代的认知工具链。三个子项目从同一根系长出——先理解困局的机制与悖论，再沿着信号抽象、沉浸演绎、注意力调配三层管道，让改变在身体与环境条件中自然发生。

### 三层协作逻辑

| 层级 | 项目 | 角色 | 输出物 |
|------|------|------|--------|

## 子项目详情

### 1. card — 简化信号规则卡牌桌游

**定位**：L1 信号抽象层。将真实世界中的心理困境、社交策略、叙事逻辑提炼为一套可打、可演、可交流的卡牌规则系统。

核心理念是"功能代偿"——如同骨折者使用拐杖，用卡牌预设规则 + 有限选项降低即时表达成本。它把抽象的行为策略封装为具象的"卡牌"，使使用者在社交场景中像打牌一样调用预设方案。

关键文档入口：[`card/index.md`](card/index.md) — 完整叙事串联（困境 → 工具 → 社会机制 → 策略 → 实践）

---

### 2. coze-studio — 沉浸润色工作流编排

**定位**：L2 沉浸生成层。一站式 AI Agent 开发平台（开源自字节跳动扣子平台），通过可视化工作流编排，将 card 产出的简化信号转化为丰富的多模态叙事内容。

利用 Prompt、RAG、Plugin、Workflow 等核心能力，把精简的卡牌规则"演绎"为具象的场景、对话、交互——让抽象信号变得人性化、可沉浸。

- 后端：Go (Hertz 微服务，DDD 架构)
- 前端：React + TypeScript (Rush.js monorepo, 135+ 包)
- 基础设施：MySQL、Redis、Elasticsearch、Milvus、MinIO、NSQ

> **注意**：coze-studio 目前尚未完整适配 Windows 原生环境运行和开发（`feat/windows-adapt` 分支进行中，详见 [`WINDOWS_ADAPT.md`](coze-studio/WINDOWS_ADAPT.md)）。当前基线为 Linux/WSL2 环境。

---

### 3. cognitive-cards — 注意力机制调配工具

**定位**：L3 注意力调配层。一套既是设计说明书、也是产品本身的认知工具系统。围绕"设计者-执行者"自我指涉悖论展开——当一个人试图设计工具来改变自己，元认知的审视会破坏执行的纯粹性。

核心机制：
- **10 张认知卡片**：从"悖论绕过"到"信念覆盖"，构成四层系统架构
- **8 枚锦囊**：对应认知循环中的关键分支节点，实时生成感官引导词
- **涌现引擎**：用户输入 → 向量语义匹配 → 语料库细化 → 锦囊路径涌现
- **环境优先**：工具只改变条件（触发器、容器、过渡、沉淀、关闭），不规定反应

技术栈：Python (Flask) + FAISS 向量检索 + SQLite FTS5 + LLM 降级方案

关键文档入口：[`cognitive-cards/设计理念总览.md`](cognitive-cards/设计理念总览.md)

## 卡牌隐喻的双视角解读：以"借刀杀人"为例

### 同构

卡牌名"借刀杀人"借用经典桌游概念，隐喻当被求助时可选的两条路线：

| 路线 | 性质 | 说明 |
|------|------|------|
| **主力路线** | 直接帮到 | 直接给出对方所需物品/支持，实际办到了，这是主力援助 |
| **辅助路线** | 转介支持 | 自己办不到，但提供线索、转介或方向等辅助支持 |

两种隐喻解读共存，取决于观察视角：

| 视角 | 解读 | 理性基调 |
|------|------|----------|
| **被卡牌作用的人** | 代价转移，保全自身 | 利益理性 |
| **发出卡牌的人** | 支持接力，传递善意 | 温情感激 |

> 视角和路线是两个独立维度。主力路线中，被帮者看到"代价转移"、帮助者感到"善意接力"；辅助路线中，被转介者同样可能评估代价被转移，而转介者也在传递善意。

## 核心设计理念

> 用工程化思维应对心理困境——先理解困局的机制与悖论（破窗效应、投资偏好、变异临界点），再找到合适的工具和策略（卡牌系统、日常化、剧情化），将抽象信号演绎为可沉浸的具象体验，最终通过注意力调配工具帮助个体绕过"刻意体验死锁"，让改变在环境条件和身体仪式中自然发生。

**三个项目不是独立的孤岛，而是一条从"困境"到"信号"到"沉浸"到"调配"的完整认知管道。**
