# 能量流通桌游设计 Spec

## Why

`道-能量承诺与意义的流通.md` 构建了一套关于能量六环、GTD 承诺下注、PARA 意义结晶的抽象框架。`桌游.md` 提供了桌游设计的核心要素和主流机制。将前者转化为桌游，可以让抽象的"流通"概念通过游戏机制被直观体验——玩家在游戏中亲身经历"能量代谢""承诺下注""意义结晶"和"流通淤塞"的后果。

## What Changes

- 在 `桌游/` 下新增文件：`能量流通：桌游规则设计.md`
- 不修改现有任何文件

## 设计定位

### 游戏类型
- **核心机制混搭**：工人放置（能量分配）+ 引擎构筑（PARA 资产）+ 推运测试（见好就收）
- **主题**：知识工作者的"一日代谢"——管理能量、下注承诺、结晶意义
- **玩家人数**：1-4 人
- **游戏时长**：60-90 分钟
- **复杂度**：中策（介于轻策与重策之间）

### 核心映射

| 道框架概念 | 游戏化映射 |
|-----------|-----------|
| 能量六环（睡眠/规划/专注/修复/协作/投资） | 玩家的六种行动格位，每轮分配有限工人 |
| GTD 五步（捕获/理清/组织/执行/复盘） | 卡牌流转路径，构成游戏主循环 |
| PARA 稳定度谱（发散→灵感→启发→项目→归档） | 玩家版图上的成长轨道，引擎构筑 |
| Top3 = 今日有限生命契约 | 每轮只能执行 3 个核心承诺 |
| 流通（产出=下一环输入） | 卡牌/资源的链式传递机制 |
| 淤塞（只捕获不理清等） | 惩罚机制——资源卡在中间环节无法流通 |
| 幸存者偏差 | 游戏中只有完成完整循环的玩家才能得分 |
| 不可逆痕迹（执行才有现实重量） | 分数点数只能通过"执行"环节获得 |

## 游戏核心循环

### 每轮（代表"一天"）流程

```
1. 规划阶段：抽取承诺卡（inbox），理清为"事"或"料"
2. 组织阶段：从已理清牌中选择 Top3 作为本轮下注
3. 执行阶段（专注环）：将工人放入专注格，执行 Top3 承诺（获得分数 + 产出）
4. 修复阶段：移除疲劳标记，恢复工人
5. 协作阶段：用产出与他人交互（获得反馈/共鸣资源）
6. 投资阶段：将协作获得的反馈解构为 AREA 资产（引擎升级）
7. 复盘阶段：结算本轮，回流未完成承诺
8. 睡眠阶段：重置，进入下一轮
```

### 胜利条件

经过 7 轮（一周）后，总分最高的玩家获胜。

分数来源：
- 执行完成的承诺卡分数
- PARA 资产（area/archive）的持续产出分数
- 完成"完整流通链"的奖励分

## 组件设计

### 玩家版图
- 能量环轨道（6 个环位，初始解锁 3 个，可逐步解锁）
- 承诺槽位（Top3 专用）
- PARA 资产区（收藏已结晶的原则/项目）

### 卡牌类型
| 卡牌类型 | 对应概念 | 功能 |
|----------|----------|------|
| **承诺卡** | GTD 捕获 | 可执行的任务，分为"事"（执行得分）和"料"（沉淀为资产） |
| **反馈卡** | 协作产出 | 来自其他玩家的交互结果，用于投资环解构 |
| **资产卡** | PARA 结晶 | 升级引擎的永久收益卡，分灵感/启发/项目三级 |
| **事件卡** | 外部干扰 | 随机事件，模拟现实中的"不可控因素" |

### 工人/指示物
- 能量工人（每人 3-5 个，代表当日可用能量）
- 疲劳标记（执行专注环后获得，消耗修复环移除）
- 结晶标记（用于标记 PARA 资产等级）

## 机制细节

### 工人放置与能量环
- 玩家每轮将工人分配到不同的能量环格位
- 同一环位可容纳多个玩家（非排他），但后行动的玩家收益递减
- 能量环之间有"转接奖励"：将工人放入专注环前，若上一轮在规划环有工人，获得额外行动

### 承诺执行（推运测试）
- 执行承诺卡时，玩家可选择"继续执行"或"见好就收"
- 继续执行可能触发连锁收益，也可能导致"大脑死机"（获得额外疲劳标记）
- 见好就收确保当前收益落袋为安

### 淤塞惩罚
如果玩家在某环节积压过多未处理的卡牌：
- 捕获区 > 5 张 → 焦虑标记（每轮失去 1 个工人）
- 理清区 > 3 项未组织 → 决策瘫痪（组织阶段需弃掉一张才可行动）
- 未完成承诺积累 → 负分（guilt 标记）

### 引擎构筑（PARA 成长）
- 玩家通过将"料"卡沉淀获得资产卡
- 资产卡梯度：灵感（1级）→ 启发（2级）→ 项目（3级）
- 高等级资产每轮自动产出分数，无需消耗工人
