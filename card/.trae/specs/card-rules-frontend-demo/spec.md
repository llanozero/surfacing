# 认知觉醒规则前端演示页面 Spec

## Why

`桌游/认知觉醒资源/` 下已有完整的六阶段规则文档（`阶段/`）和七类特殊机制说明（`特殊机制/`），但所有内容仍停留在 Markdown 文本中。创建一个交互式前端演示页面，可以：
1. 将六阶段规则以可切换的交互界面呈现，降低阅读负担
2. 将分散在多个文件夹的规则整合到单一可视化页面
3. 作为桌游规则的"快速入口"，方便试玩时查阅

## What Changes

- 在 `桌游/认知觉醒资源/` 下新增 `规则演示/` 子目录
- 创建独立 HTML 页面 `index.html`，内嵌 CSS + JS（零构建依赖，双击即可在浏览器打开）
- 页面以**六环导航切换**为核心交互，展示所有阶段规则和特殊机制

## 设计定位

- **类型**：静态交互式规则手册（前端演示页）
- **技术**：单文件 HTML + CSS + 原生 JS（零构建）
- **来源数据**：`阶段/1-6/` 六个阶段文档 + `特殊机制/` 七个机制文档

## Impact

- 仅新增 `桌游/认知觉醒资源/规则演示/index.html`
- 不修改任何已有文件

## ADDED Requirements

### Requirement: 六环导航切换
系统 SHALL 在页面顶部提供六个能量环的切换标签（睡眠/规划/专注/修复/协作/投资），点击切换下方内容区。

- **WHEN** 用户点击环标签
- **THEN** 该标签高亮（含对应颜色），内容区切换为该阶段的规则详情
- **WHEN** 页面首次加载
- **THEN** 默认选中"规划阶段"

### Requirement: Hero 区
系统 SHALL 在每个环切换时显示阶段概要：阶段名称（中+英）、时间设定、一句话定位（副标题）。

### Requirement: 规则三卡片
系统 SHALL 在每个环的工作台区域展示三张规则卡片：允许的操作、禁止的行为、流通出口。每张卡片内用列表展示具体条目。

### Requirement: 阶段监督与衔接表
系统 SHALL 在规则卡片下方附加两个表格：阶段监督表（沟通状态/违规惩罚）和上下游衔接（上一阶段/下一阶段）。

### Requirement: 资源指示物面板
系统 SHALL 在导航条下方固定展示五种资源指示物卡片：红专注能量、黄社交能量、蓝修复资源、白信息碎片、黑精神噪音，含颜色标识和用途简述。

### Requirement: 全局特殊机制入口
导航条 SHALL 增加一个独立的"特殊机制"标签，点击后展示：Burnout 破产机制、暴露/隐藏双状态、噪音与破窗惩罚的规则说明卡片。

### Requirement: 全局卡牌类型入口
导航条 SHALL 增加"卡牌类型"标签，点击后展示七种卡牌类型的网格卡片，含名称、来源牌堆、存放位置、功能。

### Requirement: 六阶段流程图
页面底部 SHALL 常驻展示六阶段循环流程图（CSS 绘制或 ASCII），每个阶段标注沟通状态（🔇禁言/🔈轻声/🔊开放）和流转方向。

### Requirement: 暗色主题
系统 SHALL 使用暗色 UI 风格，各阶段有独立 accent 色：
- 睡眠：靛蓝 (#6366f1)
- 规划：琥珀 (#f59e0b)
- 专注：红 (#ef4444)
- 修复：青 (#14b8a6)
- 协作：紫 (#a855f7)
- 投资：金 (#fbbf24)
