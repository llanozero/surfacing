# 认知觉醒：能量六环 桌游规则 Spec

## Why

将 GTD+PARA+能量六环 的工作流框架转化为一款六阶段严格限制的重度策略桌游，核心机制为"引擎构筑 + 资源管理 + 阶段限制"。与之前设计的《能量流通》基于相同的道框架但采用了完全不同的游戏结构——本作更像狼人杀的"阶段推进制"，每个阶段只允许对应操作，强调节奏感和时序策略。

## What Changes

- 在 `桌游/` 下新增文件：`认知觉醒：能量六环 桌游规则.md`
- 不修改已有文件

## 设计定位

- **游戏名**：认知觉醒：能量六环
- **机制**：引擎构筑 + 资源管理 + 阶段限制推演
- **风格**：狼人杀式的"阶段发言/行动"——睡眠和专注阶段禁言，协作阶段开放交互
- **玩家人数**：2-4 人
- **复杂度**：重策

## 核心组件与术语

### 玩家面板：PARA 认知图谱
- **P槽（项目仓）**：存放高分任务卡
- **A槽（领域池）**：存放被动能力卡，提供持续Buff
- **R槽（资源库）**：存放素材卡/工具卡，可消耗加成
- **A槽（归档区）**：存放已结算卡牌，最终计分堆

### 能量与信息指示物
- 专注能量（红）：高算力核心资源
- 社交能量（黄）：交互核心资源
- 修复资源（蓝）：清空异常状态
- 信息碎片（白）：基础卡牌原料
- 精神噪音（黑）：负面卡牌，堆积扣分

### GTD 调度中心
- 收集箱：抽牌堆和临时置牌区
- 执行清单：本轮确定要执行的卡牌队列

## 六阶段规则

### 一、睡眠阶段（后台编译）
夜间阶段，自动编译。可指定P槽/R槽中最多2张信息卡塞入A槽下方"潜意识孵化"。根据健康指数恢复红/黄能量。上一轮若留有噪音，恢复减半。

### 二、规划阶段（能量调度）
清晨阶段，全员亮牌。强制翻开收集箱所有卡牌；将信息卡转化为行动卡放入执行清单；将能量标记锚定在执行清单卡牌上。禁止执行效果或调取未规划资源。

### 三、专注阶段（深度产出）
上午阶段，绝对防壁。只能执行锚定红色能量的卡牌；禁止社交标签卡牌。核心机制：【防壁】——此阶段任何外部事件卡直接丢入收集箱，不得阅读，否则"分心"扣能量。

### 四、修复阶段（系统清空）
中午阶段，垃圾回收。消耗蓝色修复资源丢弃噪音；允许执行0能量机械杂务；将专注产出正式排入P槽。禁止消耗红色能量或玩家间交易。

### 五、协作阶段（验证表达）
下午阶段，打破防壁（类似狼人杀白天发言）。打出锚定黄色能量的卡牌对外展示/交易；与其他玩家结盟、资源交换。禁止独自行动，所有结算须含交互属性。

### 六、投资阶段（解构升维）
傍晚阶段，复盘升级。解构协作反馈为认知精粹；永久升级A槽领域池；P槽已完成项目移入归档区计分。禁止对外交付；未处理反馈自动转化为噪音。

## 胜负条件

指定轮次结束或某玩家A槽领域池全满时结算：归档区分 + 领域池等级分 - 收集箱残留噪音 = 最终总分。

## 亮点机制

- **Burnout 破产惩罚**：连续两轮专注阶段受干扰/红色能量归零 → 跳过下一轮专注+协作阶段
- **狼人杀式阶段监督**：专注阶段全员禁言，说话拿噪音卡；协作阶段开放交易谈判
