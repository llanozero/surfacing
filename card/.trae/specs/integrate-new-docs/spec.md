# 新文档串联衔接 Spec

## Why

`核心内容文档/未串联文档/` 中存在大量未纳入叙事链的文档。现需将其中3篇关键文档与已串联文档 `个人现状与核心挑战.md` 按逻辑顺序衔接，并整体嵌入 `index.md` 的现有叙事链中。

## 四篇文档的叙事顺序

### 顺序逻辑

```
个人现状与核心挑战 → 冻结的灵魂与变贵的理解 → 投资潜力，而非抚慰苦难 → 通话复盘_表达补课
     (起点)               (起点深化)                    (社会机制)                      (实践案例)
```

| 序号 | 文档 | 功能定位 | 回答的核心问题 |
|------|------|----------|----------------|
| 1 | 个人现状与核心挑战 | **问题起点** | 我的困境是什么？为什么需要自救？ |
| 2 | 冻结的灵魂与变贵的理解 | **起点深化** | 为什么成年后的修复如此艰难？为什么理解变贵了？ |
| 3 | 投资潜力，而非抚慰苦难 | **社会偏好分析** | 社会为什么不帮助成年人？偏好"投资潜力"的底层逻辑是什么？ |
| 4 | 通话复盘_表达补课与向下兼容训练 | **实践案例** | 在困境中的人如何一步步训练表达能力？真实复盘展示 |

### 四篇之间的衔接逻辑

```
个人现状与核心挑战
    │  提出问题：困境、压力、自救方向
    ▼
冻结的灵魂与变贵的理解
    │  深化问题：不仅困境存在，而且"修复窗口"已关闭，
    │  社会对成年人的"理解"成本变得极其昂贵
    │  引出追问：为什么社会不愿意为一个成年人付出理解成本？
    ▼
投资潜力，而非抚慰苦难
    │  回答追问：因为社会的支持系统遵循投资逻辑——
    │  年轻人有"潜力溢价"，成年人只有"即战力"；
    │  支持从"无偿"变为"交换"，痛苦从"公有"变为"私有"
    │  引出下一个问题：知道这些之后，具体怎么做？
    ▼
通话复盘_表达补课与向下兼容训练
    │  回答"怎么做"：一份真实的训练记录——
    │  如何通过"向下兼容阶梯"一步步训练表达能力，
    │  从热线电话到亲戚、到父母、到职场的分级推进
    └── 完成从"问题→原因→策略→行动"的闭环
```

## 在现有 index.md 中的嵌入位置

现有 index.md 叙事链为7章：
1. 起点 → 2. 工具 → 3. 社会机制(破窗) → 4. 个体困局(变异) → 5. 策略选择 → 6. 沟通实践 → 7. 总结

四篇文档的嵌入方式：

| 现有章节 | 嵌入内容 | 方式 |
|----------|----------|------|
| **一、起点**（个人现状与核心挑战） | 冻结的灵魂与变贵的理解 | 在同一章节内增加一小节"起点深化"，作为起点的延伸 |
| **三、社会机制**（破窗效应） | 投资潜力，而非抚慰苦难 | 作为社会机制的第二小节，破窗效应讲"被排斥的机制"，投资潜力讲"不被投资的逻辑" |
| **六、沟通实践**（体面替代策略） | 通话复盘_表达补课与向下兼容训练 | 作为沟通实践的实战案例，展示理论在真实场景中的应用 |

### 具体章节标题更新

- 第三章标题从"社会机制 — 破窗效应与恶性循环"扩展为 **"社会机制 — 破窗效应与社会偏好"**，分为两节：

  - 3.2 投资潜力：社会对年轻人的偏好逻辑 ← 新增

  - 6.1 体面替代策略
  - 6.2 向下兼容阶梯：表达补课的实战复盘 ← 新增
- 第一章"起点"中增加"起点深化"小节 ← 新增
