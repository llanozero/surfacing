# 三篇文章串联衔接 Spec

## Why

现有三篇独立文章（`个人现状与核心挑战.md`、`卡牌机制与生活映射.md`、`变异临界点.md`）各自阐述了不同层面的内容，但彼此之间存在内在的逻辑递进关系，缺乏一篇串联文档将其衔接成一个完整的叙事体系。新增串联文档可以让读者清晰理解三篇文章之间的因果链条和整体结构。

## What Changes

- 新增 `index.md`，作为三篇文章的**串联总览文档**
- 不修改现有的三篇文章内容
- 串联文档按照指定顺序组织：个人现状与核心挑战 → 卡牌机制与生活映射 → 变异临界点

## Impact

- 新增文件：`c:\Users\llano\Desktop\龙虾\card\index.md`
- 不涉及对现有文件的修改

## 串联逻辑结构

三篇文章构成 **"困境 → 工具 → 悖论"** 的三层递进关系：

```
┌──────────────────────────────────────────────────┐
│                变异临界点.md                        │
│           (深层社交悖论：暴露 vs 隐藏)               │
├──────────────────────────────────────────────────┤
│                        ↑                          │
│                        │ 工具要应对的底层困境         │
│                        │                          │
│                卡牌机制与生活映射.md                  │
│           (自救工具：卡牌系统的设计逻辑)              │
├──────────────────────────────────────────────────┤
│                        ↑                          │
│                        │ 困境催生的自救需求           │
│                        │                          │
│              个人现状与核心挑战.md                    │
│           (起点：现状、压力、自救方向的确立)           │
└──────────────────────────────────────────────────┘
```

## 章节设计

### 第一章：起点 — 困境与自救方向（关联 `个人现状与核心挑战.md`）

- 总结：心理障碍的根源与表现、外部四重压力、专业医疗路径评估结论
- 串联要点：引出"功能代偿"自救模式，作为通往卡牌系统的桥梁

### 第二章：工具 — 卡牌系统作为代偿方案（关联 `卡牌机制与生活映射.md`）

- 总结：借刀杀人机制解析（主力=直接帮到，辅助=转介支持）、代价转移+支持接力双视角的生活类比、设计动机
- 串联要点：卡牌系统是"代偿工具包"的具象化实现，回应第一章提出的自救需求

### 第三章：困境 — 变异临界点的深层悖论（关联 `变异临界点.md`）

- 总结：传染病隐喻、双重困局、两种互动模式
- 串联要点：揭示卡牌系统要解决的底层社交悖论——"暴露则被排斥，隐藏则无人援助"

### 第四章：整体叙事总结

- 三篇文章的完整叙事弧
- 从个人困境（现状）→ 工具应对（卡牌）→ 困境本质（变异临界点）的认知深化

## 文件格式规范

- Markdown 格式
- 每章以 `---` 分割
- 每个章节关联的原始文章使用相对链接引用
- 末尾添加"叙事脉络"可视化关系图
