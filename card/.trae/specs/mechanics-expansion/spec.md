# 机制提取与卡牌效果设计 Spec

## Why

现有桌游《能量流通》已基于"道框架"（能量六环+GTD+PARA）构建了核心循环。`手册.md` 包含一套完整的人际关系策略框架（五步关系建立法、生态位竞争、策略性投资等），`已串联文档/` 包含一系列心理与社会机制分析（变异临界点、破窗效应、主流与非主流路径等）。这些内容可以作为桌游的"机制扩展包"——新增卡牌类型、玩家能力、事件效果，丰富游戏的策略深度和主题厚度。

## What Changes

- 在 `桌游/` 下新增文件：`能量流通：机制扩展包.md`
- 不修改已有文件

## 提取来源与映射

### 来源一：《手册.md》——人际关系策略框架

| 手册概念 | 游戏化映射 | 实现方式 |
|----------|-----------|----------|
| **有限性-递减性-结构化** | 每轮能量工人递减机制 | 核心规则增强——每轮开始前需弃掉1个工人（模拟衰老/疲惫） |
| **五步技能精进** | 技能升级路径 | 新增"技能树"玩家版图——理论→模仿→练习→信念→稳定，每级解锁新能力 |
| **多面性锚点生态** | 多重身份卡牌 | 新增"锚点卡"——玩家可持有多个身份角色，在不同环切换 |
| **五步关系建立法** | 互动序列机制 | 新增"关系链"卡牌——集体规范→形象稳固→黑盒操作→锚点对接→信任交付，完整链奖励 |
| **黑盒操作** | 神秘行动牌 | 新增"黑盒卡"——不揭示效果直接打出，对手需猜测应对 |
| **装糊涂/示弱** | 欺骗/伪装机制 | 新增"示弱标记"——降低对手警惕，后续行动收益翻倍 |
| **多留一手与偶然失手** | 手牌上限与时机卡 | "多留一手"=手牌上限+1；"偶然失手"=主动弃牌换收益 |
| **对上位者的策略** | 不对称能力 | 资源领先玩家有"指点"能力（消耗行动帮他人，获得声誉分） |
| **时间规划六段** | 与现有八阶段互补 | 可做快速变体（将八阶段压缩为六段） |

### 来源二：《已串联文档》——心理与社会机制

| 文档概念 | 游戏化映射 | 实现方式 |
|----------|-----------|----------|
| **变异临界点**（暴露 vs 隐藏） | 双重状态机制 | "暴露"状态得分高但易被攻击；"隐藏"状态安全但得分低——玩家需在两者间切换 |
| **破窗效应** | 连锁惩罚 | 若某环位产生"破窗标记"，相邻环位也受影响；第一个破窗标记触发后后续惩罚加倍 |
| **受害者有罪论** | 舆论标记 | 被攻击的玩家获得"有罪标记"——其他玩家可合理化对其的进一步压制 |
| **主流与非主流路径** | 双轨制得分路径 | 每轮可选"主流路径"（安全低分）或"非主流路径"（高风险高分） |
| **伤口展示与体面替代** | 替代行动卡 | 暴露伤口可得同情分但受持续伤害；体面替代卡可得分且无副作用 |
| **投资潜力** | 前期优势加速 | 年轻玩家（低轮次）获得额外起始资源；高轮次玩家失去此加成 |
| **向下兼容阶梯** | 受众分层互动 | 互动效果取决于"兼容度"——对高兼容玩家互动收益递减，对低兼容玩家互动收益递增 |
| **代际翻译** | 沟通成本机制 | 与不同"代际"的玩家互动需要额外消耗"翻译能量" |
| **冻结的灵魂** | 修复延迟惩罚 | 若长期不进入修复环，下一轮专注环效率减半 |

## 新增卡牌类型

### 策略卡（新类型）
从手册中提取的可打出的策略性卡牌：

| 卡牌名 | 效果 | 来源 |
|--------|------|------|
| **黑盒操作** | 暗置打出，对手必须猜测你的行动类型；猜错则你获得双倍收益 | 手册·黑盒操作 |
| **装糊涂** | 本轮你被视为"无害目标"，不可被攻击；但得分减半 | 手册·装糊涂/示弱 |
| **示弱** | 指定一名对手，他本轮必须"指点"你（消耗1行动帮你），你获得他消耗的资源 | 手册·对上位者策略 |
| **多留一手** | 永久效果：手牌上限+1，回合结束时可多保留1张承诺卡 | 手册·多留一手 |
| **偶然失手** | 主动弃掉1张已完成承诺卡（不记分），从供应堆获得3个任意资源 | 手册·偶然失手 |

### 事件卡增强（已有类型扩充）

| 事件名 | 效果 | 来源 |
|--------|------|------|
| **破窗效应** | 目标玩家获得1个「破窗标记」。若已有破窗标记，改为获得2个 | 破窗效应与受害者困局 |
| **变异临界点** | 所有暴露状态的玩家立即被所有其他玩家各攻击一次 | 变异临界点 |
| **主流与非主流** | 本轮所有玩家的得分路径翻转为反向——选主流的得非主流分，反之亦然 | 主流与非主流路径分析 |
| **代际翻译失败** | 本轮协作环中，所有互动消耗翻倍 | 代际翻译 |

### 玩家能力/角色卡（新类型）
每名玩家在游戏开始时抽取一张角色卡，获得独特能力：

| 角色名 | 能力 | 来源 |
|--------|------|------|
| **锚点建立者** | 每轮可额外保留1个锚点关系（联盟），与他人的协作收益+1 | 手册·锚点生态 |
| **体面替代者** | 执行"暴露"行动时可不触发负面效果（替代为体面策略） | 伤口展示困局与体面替代策略 |
| **向下兼容者** | 你的互动消耗减半（代际翻译费用减半） | 通话复盘·向下兼容 |
| **破窗修复者** | 每轮可清除1个自己或他人的破窗标记 | 破窗效应 |
| **潜力投资者** | 前3轮获得额外1个工人；第4轮起此加成消失 | 投资潜力 |
| **主流领航员** | 选择主流路径时额外获得1分；选择非主流路径时不受惩罚 | 主流与非主流路径 |

## 新机制：关系链完成奖励

从手册的"五步关系建立法"提取的链式机制：

1. **集体规范预置**（开始关系链）→ 消耗1行动
2. **形象稳固** → 连续2轮未改变角色身份
3. **黑盒操作触发** → 对目标打出黑盒卡且猜错
4. **锚点对接成功** → 与目标建立联盟关系
5. **信任交付完成** → 目标主动赠予你1张资源卡

完整完成五步的玩家获得"深度连接"奖励分（10分）+ 永久联盟关系。
