# 文件夹重组 Spec

## Why

当前所有 Markdown 文件散落在 `card/` 根目录下，缺乏分类组织结构。随着内容增多，需要按主题归类到独立文件夹中，便于管理和后续扩展。

## What Changes

- 在 `card/` 下创建三个分类文件夹：`核心内容文档/`、`桌游/`、`文字模拟冒险/`
- 将现有文件按主题移动到对应文件夹
- 更新 `index.md` 中的引用路径，使其在新结构下仍可正确链接
- 不修改各文件的内在内容

## 文件夹结构与文件归属

```
card/
├── index.md                         # 串联总览文档（保留在根目录，更新内部链接）
├── 核心内容文档/
│   ├── 个人现状与核心挑战.md
│   ├── 变异临界点.md
│   ├── 破窗效应与受害者困局.md
│   └── （待扩展…）
├── 桌游/
│   ├── 卡牌机制与生活映射.md         # 涉及三国杀机制解析
│   └── （待扩展：三国杀、剧本杀、狼人杀…）
└── 文字模拟冒险/
    └── （待扩展：规则怪谈…）
```

## Impact

- 受影响文件：`index.md`（需更新内部相对链接路径）
- 移动的文件：4 个 .md 文件移动到新文件夹
- 不涉及内容修改，仅改变文件路径

## 文件路径映射

| 当前路径 | 目标路径 |
|----------|----------|
| `个人现状与核心挑战.md` | `核心内容文档/个人现状与核心挑战.md` |
| `变异临界点.md` | `核心内容文档/变异临界点.md` |
| `破窗效应与受害者困局.md` | `核心内容文档/破窗效应与受害者困局.md` |
| `卡牌机制与生活映射.md` | `桌游/卡牌机制与生活映射.md` |
| `index.md` | 保留在根目录，更新内部链接 |

## index.md 链接更新规则

- 所有指向 `个人现状与核心挑战.md` 的链接 → `核心内容文档/个人现状与核心挑战.md`
- 所有指向 `卡牌机制与生活映射.md` 的链接 → `桌游/卡牌机制与生活映射.md`
- 所有指向 `变异临界点.md` 的链接 → `核心内容文档/变异临界点.md`
- 所有指向 `破窗效应与受害者困局.md` 的链接 → `核心内容文档/破窗效应与受害者困局.md`
