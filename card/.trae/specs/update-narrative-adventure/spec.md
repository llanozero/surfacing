# 更新串联 & 规则怪谈冒险设计 Spec

## Why

1. 现有 `index.md` 串联文档只覆盖了前三篇文章（个人现状、卡牌机制、变异临界点），新增的 `破窗效应与受害者困局.md` 和 `主流与非主流路径分析.md` 尚未纳入叙事链
2. `文字模拟冒险/` 文件夹尚为空，需要填充规则怪谈式的内容作为分类的起点

## What Changes

### 变更一：更新 index.md 串联

将 **破窗效应与受害者困局.md → 变异临界点.md → 主流与非主流路径分析.md** 作为新的叙事链，纳入 `index.md`。

**叙事逻辑：**

```
破窗效应 → 变异临界点 → 主流与非主流路径分析
  │              │               │
  │       解释为什么暴露困境    │
  │       会被排斥的底层机制    │
  │                            │
  └── 揭示为什么状态差的人      │
      会持续被"统一标准"打压    │
                                │
                     └── 在面对以上困局时，
                         选择非主流路径的策略与代价
```

整体叙事链更新为：

```
个人现状与核心挑战（起点）→ 卡牌机制与生活映射（工具）
→ 破窗效应（社会机制）→ 变异临界点（个体困局）→ 主流与非主流路径（策略选择）
```

### 变更二：创建规则怪谈式文字模拟冒险

在 `文字模拟冒险/` 下创建 `规则怪谈.md`，内容为规则怪谈风格的文字模拟冒险剧情设计。

内容要求：
- 规则怪谈风格：以一系列"规则"为线索，玩家通过遵循/违反规则推动剧情
- 互动式叙事：包含分支选择、不同结局
- 紧密关联已有文章的核心主题：变异临界点的双重困局、破窗效应的恶性循环、非主流路径的策略挣扎
- 将抽象的心理困局转化为具象的"规则"和"场景"

## Impact

### 规则怪谈设计要求

#### 风格定位
- 规则怪谈（Rule Horror）：通过看似合理的"规则"营造不安感
- 文字模拟冒险：玩家通过选择推进剧情，多种结局

#### 主题映射

| 核心概念 | 规则怪谈化映射 |
|----------|---------------|
| 变异临界点（暴露 vs 隐藏） | 玩家需在"暴露异常"和"隐藏异常"之间选择，违反规则会被"惩罚" |
| 破窗效应 | 一旦行为出现瑕疵，后续规则会越来越严苛，他人态度恶化 |
| 受害者有罪论 | 系统/他人会认为"你被惩罚是因为你本身有问题" |
| 主流 vs 非主流 | 安全路径（遵循规则）vs 高风险路径（探索规则之外） |
| 双重困局 | 遵循规则会失去自由，违反规则会招致惩罚 |

#### 内容结构
- 背景设定
- 核心规则列表（5-8条，看似合理但暗藏陷阱）
- 剧情分支（至少3个关键决策点）
- 多种结局（至少3种：好结局、坏结局、隐藏结局）
- 规则解读（揭示每条规则背后的隐喻含义）
