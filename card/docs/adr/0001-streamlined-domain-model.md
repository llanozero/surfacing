# 精简领域模型：四层架构与术语统一

15 份核心文档中存在大量重叠概念和术语不一致。我做了一次系统性精简，核心决策如下：

## 四层架构

将原本分散的概念归入四个具有明确接口的层级：
- **心理康复层**：创伤→代偿→重温人气的修复路径
- **社会导航层**：外部感知→内部支持→共鸣激活的社交策略
- **能量运营层**：信息/能量/行动在每日六环中的流通闭环
- **表达推进层**：以"表达即推进"为元原则的沟通训练体系

前两层是"修复与定位"（补课），后两层是"运行与产出"（运转）。这样的切割让补课阶段的读者可以跳过运营层，反之亦然。

## 术语统一

- **"剧情化"恢复为独立术语，作为黑盒操作的有注解扩展**（grilling session 2026-07-29）：初始 ADR 将"剧情化"并入"黑盒操作"，但 grilling 揭示两者不在同一维度——黑盒定义"不解释原理"这一瞬间行为，剧情化定义时间维度的叙事经营（角色分配、节奏控制、可持续性）。恢复为独立术语，明确标注为黑盒操作的扩展。
- **"变异临界点"≠"破窗效应"**：前者是他人判断从良性转向恶性的单次临界节点；后者是"状态差→被统一标准否定→状态更差"的持续恶性螺旋。一个触发阈值，一个自加速循环。
- **"功能代偿"≠"体面替代策略"**：代偿是对内用工具替代受损功能（如话术卡片）；体面替代是对外用社会可接受的叙事翻译真实困境。方向不同，不可互换。（后续 grilling 中此边界将重新审视。）
- **"能量六环"作为时间规划的唯一规范模型**：手册第四章的六阶段描述与此重复，以"能量六环"为准。
- **"表达推进"从层降级为贯穿属性**（grilling session 2026-07-29）：原四层架构中"表达推进"与其他三层存在大量行为重叠。经 grilling 确认，表达推进是其他三层的共享基础设施，不是独立层。相应地，"向下兼容阶梯"归入心理康复层；"路径依赖"和"形象弹性"归入社会导航层；"能量匹配原则"和"机会窗口递减效应"归入贯穿属性。架构变为三层（心理康复、社会导航、能量运营）+ 一条元属性（表达推进）。
- **新增"认知导航层"作为操作元层**（grilling session 2026-07-29）：来自 cognitive-cards 系统的"设计者/执行者身份隔断"理念揭示了一个缺口——三层模型定义了"有什么"，但未定义"谁在什么状态下操作"。新增的操作元层填补这个缺口，包含设计者/执行者身份、模式切换仪式、提前复盘死锁、认知导航工具等概念。它不是第四层"内容"，而是所有层的动态操作接口。
- **引入三轴结构作为顶层组织框架**（grilling session 2026-07-29）：将整个系统重新组织为三个关系轴——**我与我**（认知导航，代偿认知断裂）、**他人与我**（信号简化，让他人安全认识无法随大流的我）、**他人与他人**（协作工具，让他人之间协作）。三层领域模型和操作元层成为"内容"，三轴是"关系方向"。关键区分：信号简化≠让环境理解真实的我，而是让环境不误判为威胁。
