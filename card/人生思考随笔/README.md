## 阅读顺序与主题衔接

建议按以下顺序阅读：

1. `Part0_TheoryFramework.md`：给出整套叙事的“操作系统”——人类作为预测加工/强化学习/系统论意义上的实时推理引擎，明确目标函数（稳态）与损失函数（本能/痛苦/奖励）。
2. `Part0_ResourceInheritanceAndDisappointment.md`：回答在宏观死锁与历史车轮面前，个体如何不宕机——把“意义焦虑/失望”重新表述为预测误差与资源流动性问题，并进一步落到低容错率、风险规避、防御性生存策略，以及“如何把自己调试成可接入节点”的兼容逻辑，为后续“破局”提供心理与策略前置。
3. `Part1_Breakthrough.md`：从惯性脚本中觉醒，锚定个人框架，并在现实能量博弈中找到“最小可行破局点”。
4. `Part2_Modeling.md`：将破局中的血泪采样抽象成可复用的规则模型，让个人经验可复制、可容错、可传播。
5. `Part3_Transition.md`：在草台系统里以“身份演戏”降低摩擦，用杠杆把个人模型推到更大范围的资源分发与规则定义层。
