## 检测目标

评估你是否已在**防御机制理解**和**破局准备**层面完成库伯循环，准备好进入经验建模阶段。

---

## 库伯循环自检

### 1. 具体经验 (Concrete Experience)
**检查点**: 你是否体验过自己的防御性反应？

- [ ] 识别过"推演先行"导致的机会流失
- [ ] 体验过"最大负面预期"带来的行动 paralysis
- [ ] 观察过"社交价值转化断层"的社交困境

**如果未满足**: 返回 [防御经验采样](../nav/01_breakthrough/defense_mechanism_analysis.md)

---

### 2. 反思观察 (Reflective Observation)
**检查点**: 你能理解这些防御策略的成因吗？

- [ ] 能追溯某条防御策略的起源事件
- [ ] 能理解"低容错率环境"如何塑造了你
- [ ] 能区分"保护性防御"和"限制性防御"

**如果未满足**: 返回 [失望重构反思](disappointment_reframing.md)

---

### 3. 抽象概念化 (Abstract Conceptualization)
**检查点**: 你能描述自己的防御框架吗？

- [ ] 能列出你的 3-5 条核心防御协议
- [ ] 能用"带泥土的语言"锚定你的逻辑
- [ ] 能说明这些策略在何时/何地有效/无效

**如果未满足**: 返回 [锚定框架练习](../nav/01_breakthrough/README.md)

---

### 4. 主动实践 (Active Experimentation)
**检查点**: 你是否尝试过突破防御的实验？

- [ ] 尝试过降低推演深度直接行动
- [ ] 在关系中尝试过"先进入，后确认价值"
- [ ] 有过"违反"防御协议但结果良好的体验

**如果未满足**: 返回 [破局点定位](../nav/01_breakthrough/breakthrough_point_finder.md)

## 螺旋上升判定

### ✅ 进入 Stage 3 的条件

满足以下全部：
- [ ] 已完成至少 1 次成功的破局尝试
- [ ] 能清晰描述"打破防御 → 获得反馈 → 调整认知"的循环
- [ ] 准备好将个人经验抽象为可复制模型

### ↻ 继续 Stage 2 循环的条件

满足任一：
- [ ] 防御机制仍无法松动
- [ ] 破局尝试失败，需要重新采样
- [ ] 发现更深层、更古老的防御模式

### ↩ 返回 Stage 1 的条件

如果发现自己：
- 对"防御"的理解与系统论框架冲突
- 无法解释为何某些防御如此"顽固"

→ 回到 [Stage 1 螺旋检测点](01_checkpoint.md) 修正理论框架

### ↩ 返回破局点重新尝试

如果：
- 破局尝试失败且原因不明
- 选择的破局点成本过高

→ 回到 [破局点定位](../nav/01_breakthrough/breakthrough_point_finder.md)

## 阶段间过渡：库伯 × 心流

**从 Stage 2 到 Stage 3 的心流过渡**:

```
Stage 2 结束（恢复期）
    ↓ 进入释放期：总结防御分析，整理破局经验
    ↓ 进入挣扎期：面对"建模"这一新挑战
Stage 3 开始（具体经验：战场采样）
```

**关键转换**:
- Stage 2 的"破局"成为 Stage 3 的"具体经验"
- 从"个人挣扎"转向"模式提取"
- 心流从"情绪释放"转为"认知建构"
