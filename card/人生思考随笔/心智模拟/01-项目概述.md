# 项目概述：基于LLM驱动的心智模拟系统

## 项目愿景

构建一个透明、可追溯的心智模拟系统,通过LLM驱动实现"设计者"与"执行者"的分离与协作,避免依赖神经网络的"涌现"特性,而是采用构建式、符号化的方法。

## 核心理念

### 1. 构建式交互 vs 涌现式
- **不依赖**: 深度学习的黑盒涌现
- **依赖**: 明确的逻辑推理、规则系统、符号AI
- **目标**: 可解释、可追溯、可控制的心智模拟

### 2. 双重角色分离
- **设计者(裁判)**: 制定规则、设定目标、评估结果
- **执行者(选手)**: 专注执行、不质疑规则、追求效率

### 3. 唯物与唯心的平衡
- **唯物**: 科学数据支持、外在逻辑、现成场域牵引
- **唯心**: 目标导向、结果起效、主观意图

## 技术架构方向

### BDI模型 (Belief-Desire-Intention)
```
信念(Beliefs) → 知识库、规则、外在逻辑
欲望(Desires) → 长期目标、设计者意图
意图(Intentions) → 具体执行计划、行动步骤
```

### LLM的角色定位
1. **知识整合器**: 处理和组织"信念"层的知识
2. **推理引擎**: 从信念+欲望构建意图
3. **接口层**: 连接设计者与执行者
4. **状态管理器**: 处理"长滞后"和"后台运作"

## 关键挑战

1. **自我欺骗机制**: 如何让设计者"放手"让执行者工作
2. **门槛筛选**: 如何在构建意图前进行合理性检查
3. **长滞后显示**: 如何实现异步的结果反馈
4. **状态切换**: 如何实现意识/潜意识的模拟切换

## 应用场景

- 个人目标管理系统
- 创意问题解决工具
- 习惯养成辅助系统
- 决策支持系统
- 认知训练平台

## 项目阶段

1. **Phase 1**: 理论框架与架构设计
2. **Phase 2**: 核心模块原型开发
3. **Phase 3**: LLM集成与测试
4. **Phase 4**: 用户界面与交互设计
5. **Phase 5**: 实际场景验证与迭代
