## 🎯 **四阶段循环**

```
执行单元 (稳态行动)
    ↓
高难度拆解 (高消耗区)
    ↓
高沉迷恢复 (能量补给)
    ↓
回到执行单元 (稳定落地)
    ↓
[循环重复]
```

## 🧭 **晨间扫描决策树**

### **第一步：2分钟内完成？**
- ✅ 是 → **场景8** 立即执行
- ❌ 否 → 进入第二步

### **第二步：高难度？**
- ✅ 是 → 进入第三步
- ❌ 否 → 进入第四步

### **第三步：高上瘾度？**
- ✅ 是 → 周期长？
  - 长 → **场景1** 深度探索
  - 短 → **场景2** 激烈解谜
- ❌ 否 → 周期长？
  - 长 → **场景3** 苦役磨练
  - 短 → **场景4** 吞青蛙

### **第四步：高上瘾度？**
- ✅ 是 → 周期长？
  - 长 → **场景5** 多巴胺沼泽 ⚠️
  - 短 → **场景6** 零食碎片
- ❌ 否 → 周期长？
  - 长 → **场景7** 流水线工位

## 🎯 **场景1：深度探索的迷宫**

**高难度 + 高上瘾 + 长周期**

| 项目 | 内容 |
| :--- | :--- |
| **策略** | 混合模式（5分钟启动+45分钟校准） |
| **启动** | 5分钟诱饵，哄骗大脑进场 |
| **过程** | 40分钟深度沉浸，全力投入 |
| **校准** | 45分钟后强制中断，检查方向 |
| **风险** | 容易迷失在细节，忘记主线 |
| **防御** | 设置多个闹钟，定期检查方向 |

## 🎯 **场景2：激烈的解谜游戏**

**高难度 + 高上瘾 + 短周期**

| 项目 | 内容 |
| :--- | :--- |
| **策略** | 放行享受，全力投入 |
| **启动** | 1-2分钟克服阻力 |
| **过程** | 直到完成，无需中断 |
| **结束** | 问题解决，自然停止 |
| **风险** | 过度优化，多个问题串联 |
| **防御** | 明确完成标准，记录其他发现 |

## 🎯 **场景3：西西弗斯的苦役**

**高难度 + 低上瘾 + 长周期**

| 项目 | 内容 |
| :--- | :--- |
| **策略** | 重度切碎（5个+执行单元） |
| **拆解** | 全景拆解 → 细节拆解 → 执行单元化 |
| **执行** | 15分钟/单元，机械执行 |
| **恢复** | 每3-4个单元后，进行能量补充 |
| **风险** | 拆解不够细，忽视能量补充 |
| **防御** | 每个单元15分钟内，定期恢复 |

## 🎯 **场景4：吞青蛙**

**高难度 + 低上瘾 + 短周期**

| 项目 | 内容 |
| :--- | :--- |
| **策略** | 哄骗启动（只做第一步） |
| **第一步** | 定义最小第一步（1分钟） |

| **执行** | 执行第一步（1-2分钟） |
| **流淌** | 恐惧消散，事情自然完成 |
| **风险** | 过度思考，在第一步停下 |
| **防御** | 不要思考，直接行动 |

## 🎯 **场景5：多巴胺沼泽** ⚠️

**低难度 + 高上瘾 + 长周期**

| 项目 | 内容 |
| :--- | :--- |

| **预防** | 删除应用、屏蔽网站、物理距离 |

## 🎯 **场景8：两分钟任务**

**低难度 + 低上瘾 + 短周期**

| 项目 | 内容 |
| :--- | :--- |
| **策略** | 即时执行（GTD Rule） |
| **识别** | 2分钟以内的任务 |
| **执行** | 不要记录，不要排程，立刻做 |

## 🎬 **快速启动指南**

### **早上**
1. 拿出待办列表
2. 用晨间扫描决策树分类每个任务
3. 按照场景执行

### **工作中**
1. 遇到新任务，快速判断场景
2. 进入对应的执行模式
3. 按照策略执行

### **疲惫时**
1. 进入高沉迷恢复
2. 选择恢复活动
3. 15-30分钟后回到执行

## 💡 **核心原则**

1. **不同场景，不同策略** - 一刀切无效
2. **识别属性，快速定位** - 难度×上瘾度×周期
3. **执行策略，严格遵循** - 不要自创方法
4. **定期恢复，能量可持续** - 没有恢复，就没有可持续
5. **闭环落地，形成节奏** - 每个循环都要有结束
