## 📋 **文件详解**

### **导航和入口**

#### **[00-主导航.md](./00-主导航.md)**
- **用途**：系统的中心导航页面
- **内容**：四阶段概览、八场景速查、快速链接
- **适用**：第一次使用，或需要全局视图时

#### **[01-晨间任务扫描.md](./01-晨间任务扫描.md)**
- **用途**：5分钟快速决策树
- **内容**：四步决策流程、可视化决策树、八场景详解
- **适用**：每天早上分类任务

#### **[99-快速参考卡片.md](./99-快速参考卡片.md)**
- **用途**：手机端快速查看
- **内容**：速查表、核心原则、快速启动指南
- **适用**：随时随地快速查询

#### **[创伤理解_交互入口.md](./创伤理解_交互入口.md)**
- **用途**：创伤议题的交互式阅读入口
- **内容**：阅读顺序、分流逻辑、承接目标
- **适用**：希望将重议题拆成低损耗阅读流程时

#### **[创伤理解_单卡顺序脚本.md](./创伤理解_单卡顺序脚本.md)**
- **用途**：逐步投放背景信息
- **内容**：8 张核心卡片、过渡话术、停顿规则
- **适用**：需要让对方先理解处境，再进入对话时

#### **[创伤理解_态度与偏好分类器.md](./创伤理解_态度与偏好分类器.md)**
- **用途**：识别对方态度、偏好与承接角色
- **内容**：四层分类、接口模板、最小问法
- **适用**：读完背景后，为后续交流匹配合适节奏时

#### **[创伤理解_交互状态机.yaml](./创伤理解_交互状态机.yaml)**
- **用途**：供应用、脚本系统或流程引擎读取
- **内容**：节点、状态、响应分支、接口输出
- **适用**：希望将流程做成程序化交互时

#### **[创伤理解_交互数据.json](./创伤理解_交互数据.json)**
- **用途**：给前端、自动化脚本或轻量客户端直接读取
- **内容**：入口、展示方式预判断、单卡数据、原文数据、分类器问题、接口映射
- **适用**：不想先解析 YAML、想直接拿结构化数据使用时

#### **[创伤理解_交互原型.html](./创伤理解_交互原型.html)**
- **用途**：本地可直接点击的交互演示页
- **内容**：展示方式预判断、逐卡阅读、原文阅读、分类器、状态侧栏、导出结果、多主题切换（默认深色），页面逻辑已拆到独立 JS
- **适用**：先跑流程、看体验、再决定是否做正式应用时

#### **创伤理解_交互原型.js**
- **用途**：承载原型页的前端逻辑
- **内容**：外部 JSON 读取、展示方式推荐、流程推进、状态渲染、主题持久化
- **适用**：继续演进为正式前端页面时

#### **[创伤理解_交互原型_使用说明.md](./创伤理解_交互原型_使用说明.md)**
- **用途**：说明如何稳定打开原型页
- **内容**：推荐启动方式、文件关系、常见读取限制
- **适用**：外部 JSON 模式下的本地预览

#### **启动创伤理解交互原型.ps1**
- **用途**：一键启动本地静态服务并打开页面
- **内容**：调用内置 Python 的 `http.server`
- **适用**：避免浏览器直接打开 `html` 时的本地文件读取限制

#### **[创伤理解_主持人操作卡.md](./创伤理解_主持人操作卡.md)**
- **用途**：人工主持时的速查卡
- **内容**：开场白、投卡规则、四句分类器、停顿条件
- **适用**：手动跑这套流程、带人阅读时

## 🎯 **使用场景**

### **场景A：早上规划**
1. 打开 [01-晨间任务扫描.md](./01-晨间任务扫描.md)
2. 用决策树快速分类每个任务
3. 按照场景分配到不同的执行模式

### **场景B：工作中遇到新任务**
1. 快速判断任务的三个属性（难度、上瘾度、周期）
2. 用 [99-快速参考卡片.md](./99-快速参考卡片.md) 找到对应场景
3. 进入场景页面，按照策略执行

### **场景C：感到疲惫**
1. 进入 [30-高沉迷恢复.md](./30-高沉迷恢复.md)
2. 选择合适的恢复活动
3. 按照时间限制执行

### **场景D：需要快速查询**
1. 打开 [99-快速参考卡片.md](./99-快速参考卡片.md)
2. 查看速查表或决策树
3. 快速定位对应的场景
