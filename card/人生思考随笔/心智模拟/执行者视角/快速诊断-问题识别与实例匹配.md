# 快速诊断 - 问题识别与实例匹配

*通过症状快速识别问题类型，匹配相应的解决实例和信念库调用策略*

---

## 🎯 使用方法

### 三步诊断法
1. **症状识别**：根据当前感受找到对应症状
2. **问题定位**：确定核心问题类型和优先级
3. **实例匹配**：选择最相似的情景实例作为参考

### 紧急程度分级
- 🔴 **紧急**：需要立即处理，影响基本功能
- 🟠 **重要**：需要优先处理，影响发展进程  
- 🟡 **一般**：可以计划处理，优化提升类

---

## 🚨 紧急问题（🔴 立即处理）

### 症状群1：情绪崩溃类
**典型症状**：
- 失眠、焦虑、抑郁
- 对工作/生活失去兴趣
- 情绪波动剧烈，容易哭泣或愤怒
- 感觉被困住，看不到出路

**问题定位**：创伤疗愈 + 能量管理失衡
**匹配实例**：实例三（社交焦虑与人际关系重建）
**立即调用**：
- B038（负面记忆淡化）+ 9号信念库（创伤疗愈）
- 19号信念库（低迷状态与能量循环管理）

### 症状群2：身份迷失类
**典型症状**：
- 感觉在"演戏"，不是真实的自己
- 工作/生活中极度消耗，但说不清原因
- 害怕被发现"不够格"
- 不知道自己真正想要什么

**问题定位**：身份真实性消耗 + 内外不一致
**匹配实例**：实例一（职场身份迷失与冒名顶替）
**立即调用**：
- B050（身份真实性消耗）+ B039（内外一致）
- 18号信念库（自然涌现与直觉信任）

### 症状群3：关系破裂类
**典型症状**：
- 与重要的人发生激烈冲突
- 感觉对方"变了"或自己"变了"
- 争论从事实变成人身攻击
- 原本的合作关系濒临破裂

**问题定位**：认知对立统一 + 强弱思维置换
**匹配实例**：实例二（创业团队内部冲突）
**立即调用**：
- B052（认知对立统一）+ B043（强弱思维置换）
- 21号信念库（黑盒价值保护）

## 🟠 重要问题（优先处理）

### 症状群4：发展停滞类
**典型症状**：
- 努力工作但得不到认可
- 感觉被困在某个层级无法突破
- 技能在增长但影响力没有提升
- 开始怀疑自己的能力或环境

**问题定位**：认知层次限制 + 价值交换不清
**匹配实例**：实例四（职业发展瓶颈与认知升级）
**优先调用**：
- 16号信念库（认知发展八阶体系）
- B053（价值交换）+ B055（主导权）

### 症状群5：资源匮乏类
**典型症状**：
- 有想法但缺乏资源实现
- 感觉孤军奋战，缺乏支持
- 不知道如何获得需要的帮助
- 在等待机会和主动行动之间纠结

**问题定位**：外部支持缺失 + 延迟满足失衡
**匹配实例**：实例五（创业初期的资源整合与团队建设）
**优先调用**：
- 15号信念库（权威成长资源三角）
- B046（自我指涉困境）+ B053（价值交换）

### 症状群6：人际困扰类
**典型症状**：
- 不知道在不同场合该如何表现
- 担心暴露太多或保护过度
- 与不同层级的人互动感到困难
- 经常被周边人的评价影响

**问题定位**：关系真实度失衡 + 黑盒价值管理
**匹配实例**：实例一（职场身份迷失）的人际策略部分
**优先调用**：
- B044（关系真实度梯度）+ 21号信念库
- B045（周边试错）+ B051（黑盒价值保护）

## 🟡 一般问题（计划处理）

### 症状群7：效率优化类
**典型症状**：

- 任务很多但缺乏优先级
- 感觉忙碌但没有成果

**问题定位**：信息管理系统缺失
**调用策略**：

**典型症状**：
- 思维感觉受限，缺乏突破
- 遇到复杂问题不知如何分析
- 想要提升思维层次
- 对某些概念理解不深

**问题定位**：认知升级需求
**调用策略**：
- 16号信念库（认知发展八阶）

## 📋 快速自测清单

### 基础状态检查
**情绪层面**：
- [ ] 最近一周的睡眠质量如何？
- [ ] 是否经常感到焦虑或抑郁？
- [ ] 对日常活动是否还有兴趣？

**身份层面**：
- [ ] 在工作/生活中是否感觉"像自己"？
- [ ] 是否经常担心被发现"不够格"？
- [ ] 行为与内心价值观是否一致？

**关系层面**：
- [ ] 与重要的人关系是否和谐？
- [ ] 是否经常因为他人评价而困扰？
- [ ] 在不同场合的表现是否自然？

### 发展状态检查
**认知层面**：
- [ ] 面对复杂问题时思路是否清晰？
- [ ] 是否感觉思维受到某种限制？
- [ ] 学习新知识的效率如何？

**资源层面**：
- [ ] 是否有可靠的导师或顾问？
- [ ] 遇到困难时是否有人可以求助？
- [ ] 获取所需资源的能力如何？

**价值层面**：
- [ ] 是否清楚自己能提供什么价值？
- [ ] 在团队/组织中的影响力如何？
- [ ] 是否获得了应有的认可？

## 🎯 匹配决策树

### 如果多个症状群都符合
**优先级排序**：
1. 🔴 紧急问题：先处理情绪崩溃、身份迷失、关系破裂
2. 🟠 重要问题：再处理发展停滞、资源匮乏、人际困扰  
3. 🟡 一般问题：最后优化效率和认知

### 如果症状不明确
**深度诊断**：
1. 回顾最近3个月的重大事件
2. 识别最消耗精力的具体情况
3. 分析问题出现的时间模式
4. 考虑是否有未处理的创伤或冲突

### 如果没有明显问题
**预防性维护**：
- 使用日常检查清单（执行者视角调用指南）
- 定期进行状态评估和优化
- 主动学习和应用相关信念库

## 🚀 行动启动模板

### 确定问题后的标准流程
1. **记录现状**：详细描述当前症状和影响
2. **选择实例**：找到最匹配的情景实例
3. **制定计划**：按照实例的调用策略制定行动计划
4. **开始执行**：从最高优先级的调用开始
5. **跟踪效果**：使用实例中的验证标准跟踪进展
6. **调整策略**：根据实际效果调整后续行动

### 紧急情况的快速响应
- **立即调用**：直接使用症状群对应的立即调用策略
- **寻求支持**：激活外部支持网络（朋友、导师、专业人士）
- **降低标准**：暂时降低对自己的要求，专注恢复
- **记录过程**：为后续深度处理保留信息
