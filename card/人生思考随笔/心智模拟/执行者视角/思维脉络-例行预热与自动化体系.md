# 思维脉络 - 例行预热与自动化体系

*基于状态匹配的渐进式认知练习，从例行预热到自动化内化的完整闭环*

---

## 🎯 核心原则

### 1. 状态优先原则
- **状态好时直接应用**，而非实验回归不好状态测试
- **避免疑罪从有**：不质疑已验证有效的方法
- **保护效果**：测试会消解效果，应用会强化效果

### 2. 渐进内化原则
- **例行预热** → **练习巩固** → **自动化** → **新的例行基础**
- **具体事务练习** > **抽象概念调整**
- **侧面发现问题** > **直接面对内核**

### 3. 隐式评估原则
- **当前能预热哪项例行** = **状态水准区间指标**
- **隐式自动采集** > **显式问卷干扰**
- **后台AI评估** + **前台AI指引**

## 🚀 例行预热分级体系

### Level 0：基础生存预热（最轻松）
**适用状态**：极低迷、刚醒来、疲惫状态
**例行内容**：
- 简单的身体活动（洗漱、整理）
- 基础信息浏览（不需要深度思考）
- 熟悉环境的简单任务

**成功标志**：能够完成基本生活自理
**自动化目标**：让基础生存成为无意识习惯

### Level 1：信息处理预热
**适用状态**：轻度低迷、需要激活思维
**例行内容**：
- 整理桌面/文件夹（B041信息管理五步）
- 查看和分类待办事项（B042 PARA分类）
- 简单的阅读和摘要

**成功标志**：思维开始清晰，能够分类和整理
**自动化目标**：信息处理成为思维激活的自然入口

### Level 2：关系维护预热
**适用状态**：思维清晰，但能量中等
**例行内容**：
- 回复消息和邮件（B044关系真实度梯度）
- 简单的社交互动
- 维护性的人际沟通

**成功标志**：能够自然地与他人互动
**自动化目标**：人际维护成为能量管理的组成部分

### Level 3：价值创造预热
**适用状态**：能量充沛，手感良好
**例行内容**：
- 核心工作的边缘任务
- 创造性思考的准备工作
- 技能练习和提升

**成功标志**：进入创造性工作状态
**自动化目标**：价值创造成为高能量状态的自然表达

### Level 4：认知优化预热
**适用状态**：最佳状态，深度工作能力
**例行内容**：
- 复杂问题的分析和解决
- 认知框架的应用和优化
- 深度学习和思考

**成功标志**：能够处理复杂认知任务
**自动化目标**：高阶认知成为巅峰状态的标配

## 🔄 执行调用顺序表

### 阶段一：状态识别与预热启动
```
当前感受 → 隐式评估 → 匹配预热级别 → 开始例行预热
```

**隐式评估指标**：
- 身体能量感受（1-10分）
- 思维清晰程度（模糊-清晰）
- 情绪稳定性（波动-平稳）
- 社交意愿（回避-主动）

**预热级别匹配**：
- Level 0-1：基础激活阶段
- Level 2-3：能力展现阶段  
- Level 4：巅峰发挥阶段

### 阶段二：例行执行与状态提升
```
选定例行 → 专注执行 → 状态监测 → 适时升级
```

**执行原则**：
- **不跳级**：必须从当前能力范围内的例行开始
- **不强迫**：感到阻力时停止，不强行推进
- **不测试**：不故意回到低状态验证方法有效性

**状态提升信号**：
- 当前例行变得轻松
- 开始有余力关注更多细节
- 自然产生处理更复杂任务的冲动

### 阶段三：练习巩固与自动化
```
熟练例行 → 增加复杂度 → 形成新习惯 → 成为新基础
```

**巩固策略**：
- **重复练习**：在相似情境中重复应用
- **变式练习**：在不同情境中灵活应用
- **教授他人**：通过教授来深化理解

**自动化标志**：
- 无需刻意思考就能执行
- 成为其他高级任务的自然前置
- 在压力下仍能稳定执行

## 📋 背诵衔接的思维脉络大纲

### 一、启动序列（必背）
```
感受当下 → 识别能力 → 选择例行 → 开始预热
不质疑 → 不测试 → 不跳级 → 不强迫
```

### 二、预热级别（必背）
```
Level 0: 基础生存（洗漱整理）
Level 1: 信息处理（整理分类）  
Level 2: 关系维护（沟通互动）
Level 3: 价值创造（核心工作）
Level 4: 认知优化（深度思考）
```

### 三、执行原则（必背）
```
状态好时直接应用，不回归测试
具体事务练习，不抽象概念调整
侧面发现问题，不直接面对内核
例行预热完成，再处理复杂任务
```

### 四、升级路径（必背）
```
轻松执行 → 增加复杂度 → 形成习惯 → 新的基础
当前例行 → 练习巩固 → 自动化 → 下级预热
闭环循环 → 螺旋上升 → 能力扩展 → 状态提升
```

### 五、应急处理（必背）
```
状态崩溃 → 回到最低级例行 → 重新预热
遇到阻力 → 降低一个级别 → 稳定后再升
效果消失 → 停止质疑测试 → 回到应用模式
```

## 🔄 设计模式与执行模式的切换

### 执行模式特征
- **目标导向**：专注完成当前例行任务
- **状态匹配**：根据当前能力选择合适难度
- **流程优先**：按照既定顺序执行，不质疑
- **效果保护**：避免测试和验证行为

### 设计模式触发条件
- **执行崩溃**：当前方法在实际应用中失效
- **系统性问题**：多个例行任务都出现问题
- **能力边界**：达到当前体系的上限
- **环境变化**：外部条件发生重大改变

### 切换机制
```
执行模式 → 遇到bug崩溃 → 自然反思 → 进入设计模式
设计模式 → 优化完成 → 新的例行设计 → 回到执行模式
```
