# 执行者视角 - 信念库调用指南

*从实际应用和执行的角度，按照调用顺序和使用场景组织信念库内容*

---

## 🎯 使用说明

### 设计者视角 vs 执行者视角
- **设计者视角**：按主题模块分类，便于编辑维护（现有信念库结构）
- **执行者视角**：按实际使用顺序和场景分类，便于快速调用应用

### 本文档的价值
- **快速定位**：根据当前情况快速找到需要的信念
- **顺序指导**：提供实际执行时的调用顺序
- **场景匹配**：不同情况下应该优先使用哪些信念

---

## 🚀 启动阶段：建立基础稳定性

### 1. 个体稳固（优先级：🔴 极高）
**使用场景**：刚开始成长、感到迷茫、需要重建基础时

**调用顺序**：
1. **B038: 负面记忆淡化定理** → 处理创伤和负面经历
2. **B039: 内外一致定理** → 确保行动与内心一致
3. **B050: 身份真实性消耗定理** → 避免冒名顶替综合症
4. **18号信念库：自然涌现与直觉信任体系** → 建立基本信任

**关键检查点**：
- [ ] 是否还被过去的负面经历困扰？
- [ ] 当前的行为是否与内心价值观一致？
- [ ] 是否在扮演不符合自己的角色？

### 2. 能量管理（优先级：🔴 极高）
**使用场景**：感到疲惫、状态不佳、需要调节节奏时

**调用顺序**：
1. **19号信念库：低迷状态与能量循环管理** → 接纳能量波动
2. **20号信念库：手感与拆解时机的智慧** → 状态匹配工作
3. **B040: 延迟满足平衡定理** → 平衡当下与长远

**关键检查点**：
- [ ] 当前的能量状态如何？
- [ ] 是否在合适的状态做合适的事？
- [ ] 是否过度延迟满足或过度即时满足？

---

## 🛠️ 工具建设阶段：提升处理能力

### 3. 信息处理系统（优先级：🟡 中等）
**使用场景**：信息混乱、需要建立秩序、提高效率时

**调用顺序**：
1. **B041: 信息管理五步定理** → 建立处理流程
2. **B042: PARA分类定理** → 建立分类体系
3. **实践指导手册** → 具体操作指导

**关键检查点**：
- [ ] 信息输入是否有序？
- [ ] 分类体系是否清晰？
- [ ] 执行效率是否提升？

### 4. 认知升级（优先级：🟡 中等）
**使用场景**：思维受限、需要突破认知瓶颈时

**调用顺序**：
1. **16号信念库：认知发展八阶体系** → 了解认知层次
2. **B052: 认知对立统一定理** → 理解悖论性思维
3. **元认知纲领** → 快速定位核心理念

**关键检查点**：
- [ ] 当前处于哪个认知阶段？
- [ ] 是否陷入了认知悖论？
- [ ] 思维模式是否需要升级？

## 🤝 人际互动阶段：建立外部连接

### 5. 人际关系基础（优先级：🟠 较高）
**使用场景**：人际关系出现问题、需要改善社交时

**调用顺序**：
1. **B044: 关系真实度梯度定理** → 确定表达深度
2. **21号信念库：身份真实性与黑盒价值体系** → 管理自我展示
3. **B051: 黑盒价值保护定理** → 保护核心能力
4. **B043: 强弱思维置换定理** → 理解认知不对称

**关键检查点**：
- [ ] 在不同关系中的表达是否合适？
- [ ] 是否过度暴露或过度保护自己？
- [ ] 是否理解对方的认知局限？

### 6. 冲突处理（优先级：🟠 较高）
**使用场景**：遇到人际冲突、需要化解矛盾时

**调用顺序**：
1. **B052: 认知对立统一定理** → 避免屠龙者成恶龙
2. **B045: 周边试错定理** → 理解周边关系局限
3. **17号信念库：创伤后人格系统重构定理** → 处理关系创伤

**关键检查点**：
- [ ] 是否在对抗中迷失了自己？
- [ ] 是否过度在意周边人的评价？
- [ ] 冲突是否造成了心理创伤？

## 🌍 社群生态阶段：融入更大系统

### 7. 社群参与（优先级：🟢 一般）
**使用场景**：需要融入团队、建立社群关系时

**调用顺序**：
1. **B046: 自我指涉困境定理** → 寻求外部反馈
2. **B047: 物化分工定理** → 找到自己的位置
3. **13号信念库：社会生存定理体系** → 理解社会规律

**关键检查点**：
- [ ] 是否过度依赖自我觉察？
- [ ] 是否找到了自己在团队中的价值？
- [ ] 是否理解社会运作规律？

### 8. 生态平衡（优先级：🟢 一般）
**使用场景**：需要在复杂环境中保持平衡时

**调用顺序**：
1. **B048: 外敌凝聚幻象定理** → 识别虚假统一
2. **B049: 双模型互动定理** → 理解群体动态
3. **15号信念库：权威成长资源三角定理** → 获取成长资源

**关键检查点**：
- [ ] 是否被外敌叙事迷惑？
- [ ] 是否理解不同类型人的互动模式？
- [ ] 是否有可靠的成长资源？

## 🔄 动态调整阶段：持续优化

### 9. 状态监测与调整（优先级：🔴 极高）
**使用场景**：日常维护、定期检视、持续优化时

**每日检查**：
1. **能量状态** → 19号、20号信念库
2. **身心一致性** → B039、B050
3. **人际关系质量** → 21号信念库、B044

**每周检查**：
1. **认知升级** → 16号信念库、B052
2. **信息处理效率** → B041、B042
3. **社群参与度** → B046、B047

**每月检查**：
1. **整体成长轨迹** → 12号信念库全览
2. **创伤疗愈进度** → 9号、17号信念库
3. **价值创造能力** → B051、15号信念库

## 🚨 应急调用：特殊情况处理

### 危机情况下的快速调用

#### 情绪崩溃时
**立即调用**：
1. B038（负面记忆淡化） + 9号信念库（创伤疗愈）
2. 19号信念库（接纳低迷状态）
3. 实践指导手册（能量管理部分）

#### 身份迷失时
**立即调用**：
1. B050（身份真实性消耗） + B039（内外一致）
2. 18号信念库（自然涌现与直觉信任）
3. 21号信念库（身份真实性管理）

#### 人际冲突时
**立即调用**：
1. B052（认知对立统一） + B043（强弱思维置换）
2. 21号信念库（黑盒价值保护）
3. B044（关系真实度梯度）

#### 认知困惑时
**立即调用**：
1. 16号信念库（认知发展八阶）
2. 元认知纲领（快速定位）
3. B052（认知对立统一）
