# 背诵卡片 - 五阶段执行口诀

*从直觉启动到黑盒交付的核心记忆卡片*

---

## 🎯 核心转换（必背）

```
战略上"去魅" - 不要复杂设计，信任直觉
战术上"归真" - 简单可靠行动，直接开始
```

---

## 📋 五阶段口诀（30秒背诵）

### 🔴 第一阶段：接纳低迷
```
潮汐有涨落，人不可能永远高能量
低迷是恢复期，不排斥不代偿
切断负反馈，身心合一基础
```

### 🟠 第二阶段：构建新场域  
```
远离旧源初，靠近新源初
越用力完美，越离自然远
新瓶装旧酒，停止仪式感
```

### 🟡 第三阶段：战术勤奋
```
找最小硬任务，不需要动脑设计
硬背硬敲硬读，简略低效但可靠
不设复杂保险，专注当下行动
```

### 🔵 第四阶段：厚积薄发
```
灵感故意不做，不立刻数字化
打印实体存储，像酿酒放置
手感在时拆解，切勿低迷分析
```

### 🟣 第五阶段：黑盒交付
```
真正天赋是黑盒，不需解释内部
过河搭桥合作，目标达成拆除
渡人以渡己，先投入后回流
```

---

## ⚡ 快速行动指令（10秒记忆）

```
1. 接纳当下状态 → 不排斥低能量
2. 别设计了 → 直接硬学硬敲  
3. 灵感先冷藏 → 状态好再拆解
4. 黑盒选择开放 → 先给予后接受
5. 身心合一 → 无需向任何人证明
```

---

## 🚫 四不禁忌（关键避坑）

```
❌ 不排斥低迷 → 强行维持高能量必透支
❌ 不过度设计 → 仪式感会消解行动力  
❌ 不立即处理 → 低迷时分析会消解灵感
❌ 不假装黑盒 → 身心分离极度消耗
```

---

## 🎯 应急口诀（危机时刻）

### 状态崩溃时
```
立即接纳 → 回到最简单硬任务 → 不分析原因
```

### 过度设计时  
```
提醒去魅 → 选择硬任务 → 立即开始
```

### 灵感冲动时
```
快速记录 → 打印存储 → 提醒不是时候
```

### 社交焦虑时
```
评估边界 → 选择开放度 → 专注给予
```
