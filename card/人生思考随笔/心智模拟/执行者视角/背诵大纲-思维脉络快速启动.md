# 背诵大纲 - 思维脉络快速启动

*供背诵衔接的核心思维脉络，状态好时直接应用的自动化启动序列*

---

## 🎯 核心口诀（必背）

### 状态应用四不原则
```
状态好时直接应用，不回归测试消解效果
具体事务侧面练习，不抽象内核直接面对  
例行预热逐级提升，不跳级强迫超越能力
隐式评估自然匹配，不显式问卷干扰流程
```

### 五级预热启动序列
```
Level 0: 基础生存 - 洗漱整理激活身体
Level 1: 信息处理 - 整理分类激活思维
Level 2: 关系维护 - 沟通互动激活社交  
Level 3: 价值创造 - 核心工作激活能力
Level 4: 认知优化 - 深度思考激活智慧
```

---

## 🚀 启动检查清单（30秒完成）

### 快速状态感知
- [ ] **身体**：疲惫 ←→ 充沛（1-5分）
- [ ] **思维**：模糊 ←→ 清晰（1-5分）  
- [ ] **情绪**：波动 ←→ 平稳（1-5分）
- [ ] **社交**：回避 ←→ 主动（1-5分）

### 预热级别匹配
```
总分 4-8分  → Level 0-1 基础激活
总分 9-12分 → Level 2-3 能力展现
总分 13-16分 → Level 4 巅峰发挥
总分 17-20分 → 维持当前，避免透支
```

---

## 🔄 执行流程（背诵版）

### 第一步：感受识别（5秒）
```
不分析 → 直接感受
不质疑 → 直接接受
不比较 → 直接匹配
```

### 第二步：例行选择（10秒）
```
Level 0: 能站起来 → 基础生存例行
Level 1: 能思考 → 信息处理例行
Level 2: 能交流 → 关系维护例行
Level 3: 能创造 → 价值创造例行
Level 4: 能深思 → 认知优化例行
```

### 第三步：专注执行（不限时）
```
选定就执行 → 不再犹豫
遇阻就降级 → 不强迫推进
完成就升级 → 不停留原地
```

### 第四步：自然升级（自动触发）
```
当前变轻松 → 自动考虑升级
有余力关注 → 自动增加复杂度
产生新冲动 → 自动尝试新任务
```

## 📋 各级例行任务清单

### Level 0：基础生存例行
**身体激活**：
- 洗脸刷牙（2分钟）
- 整理床铺（3分钟）
- 简单拉伸（5分钟）

**环境整理**：
- 清理桌面（5分钟）
- 整理衣物（5分钟）
- 准备水和食物（5分钟）

### Level 1：信息处理例行
**信息整理**：
- 清理手机通知（5分钟）
- 整理桌面文件（10分钟）
- 查看今日日程（5分钟）

**思维激活**：
- 简单阅读（10分钟）
- 记录想法（5分钟）
- 制定简单计划（10分钟）

### Level 2：关系维护例行
**沟通处理**：
- 回复重要消息（15分钟）
- 简单社交互动（10分钟）
- 关心他人近况（10分钟）

**关系投入**：
- 表达感谢（5分钟）
- 提供小帮助（10分钟）
- 分享有用信息（10分钟）

### Level 3：价值创造例行
**核心工作**：
- 处理重要任务（30分钟）
- 创造性思考（20分钟）
- 技能练习（20分钟）

**价值输出**：
- 解决具体问题（30分钟）
- 产出有用内容（30分钟）
- 帮助他人成长（20分钟）

### Level 4：认知优化例行
**深度思考**：
- 复杂问题分析（45分钟）
- 认知框架应用（30分钟）
- 系统性学习（60分钟）

**智慧提升**：
- 哲学思辨（30分钟）
- 创新探索（45分钟）
- 知识整合（60分钟）

## ⚠️ 应急处理口诀

### 状态崩溃时
```
立即停止当前任务
回到Level 0基础生存
不质疑不分析原因
专注完成简单例行
```

### 遇到阻力时
```
降低一个预热级别
重新选择例行任务
不强迫不坚持原计划
等状态恢复再升级
```

### 效果消失时
```
停止测试验证行为
回到纯粹应用模式
不怀疑方法有效性
重新开始例行预热
```
