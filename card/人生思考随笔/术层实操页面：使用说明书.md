# 术层实操页面：使用说明书

> 路径：`/#/practice-loop`
> 一句话：到点进板块，按固化流程跑，跑熟了再拆开。

---

## 一、这个页面是干什么的

术层实操页是**一天六段时间的"剧本执行台"**。

它不是让你自由发挥的。它是让你**在正确的时间，做正确的事，按正确的顺序做完**。

- **道层（`/#/concept-loop`）**：告诉你"为什么要这么做"
- **术层（本页）**：逼着你"现在就按步骤做完"
- **通用工具面板**：等流程跑熟了，你自己挑工具组合着用

核心心智只有一句：**"到点进入板块，按固化流程跑。"**

---

## 二、为什么术层要"重复造工具"

表面上，术层里的"早间规划"有自己的收件箱入口、自己的待办列表、自己的资料初选面板——而通用工具面板里也有这些。这不是重复，这是**分层**。

| | 术层 | 通用工具面板 |
|---|---|---|
| 阶段 | **前期 · 固化流程** | **后期 · 灵活装配** |
| 状态 | 流程还没跑熟，需要被引导 | 流程已稳定，用户想自由组合 |
| 目的 | 强制把对的步骤跑完 | 让用户挑当下要的工具 |
| 心智 | "到点按剧本走" | "我今天想用这几样" |
| 关系 | 包含/约束 | 释放/延伸 |

**通用工具面板是术层流程稳定之后的延伸位；术层是尚未稳定之前的固化训练场。**

两者的方向相反：通用工具面板允许"自由组合"，术层强制"按序执行"。前期必须把流程跑熟，后期才有可能拆开重组——这是 GTD 这类方法论能落地的基本前提。

当某个流程被反复跑通、不再需要被引导时，它就会从术层"毕业"，下沉到通用工具面板的灵活装配位。术层一旦发现某步骤用户已经能稳定执行，就会把它的入口松开，让用户能跳出去自由组合。

## 三、一天六段，各进各的门

页面顶部有一排按钮，代表一天六个能量环。进入页面时，系统会根据**当前小时**自动把你送进对应的环：

| 时段 | 环 | 你在做什么 |
|------|-----|-----------|
| 06:00-09:00 | **早间规划** | 建立地图：收集 → 理清 → 组织 → 资料初选 |
| 09:00-12:00 | **专注工作** | 深度产出：选任务 → 沉浸执行 → 临时捕获 |
| 12:00-15:00 | **午休修复** | 系统清空：午休倒计时 + 营养 + 快速睡眠 |
| 15:00-18:00 | **协作分享** | 验证表达：上午做自己，下午看世界 |
| 18:00-21:00 | **投资复盘** | 解构升维：复盘 + 规则推演 + 理论可视化 |
| 21:00-06:00 | **睡眠** | 离线整合：倒计时 + 入睡捕获 + 轻量记录 |

你也可以手动点击顶部的环按钮切换。但系统默认会把你送进"该在的环"。

## 四、早间规划环：最重的板块

早间规划是术层中最复杂的一环，因为它承担了 GTD 五步中的前四步：收集、理清、组织、资料初选。

### 4.1 四步流程

页面顶部有一排步骤按钮：收集 → 理清 → 组织 → 资料初选。你只能按顺序走，不能跳过。

**第一步：收集**

系统会把你昨晚睡眠环和外部来源的 inbox 条目列出来。你只需做一件事：**勾选"纳入今日"**。没勾的会留在 inbox 里，等以后处理。

**第二步：理清**

对 inbox 里的每一条，你要做一个判断：
- 能两分钟做完？**现在就做**。
- 需要更多时间？**转成待办**。
- 是参考资料？**丢进 PARA**。
- 没用？**删除**。

这一步有 Agent 辅助，但决定权在你。

**第三步：组织**

从待办池里**手动勾选 3 条**作为今日 Top3。Agent 会给出建议，但你可以覆盖。每日限额就是 3 条，多了系统不让你选——这是强制约束，防止你贪多。

**第四步：资料初选**

这是整个术层中最复杂的交互面板。它的目的是：**为每个 Top3 任务，从 PARA 知识库里预选参考资料**。

---

### 4.2 资料初选面板怎么用

面板分成左右两大块：

**左边：找文件**

- **目录树 TAB**：按 PARA 五分类（收件箱/项目/领域/资源/归档）折叠展开。每个分类下，**子目录排在同级文件上方**。点击文件名可以在右边预览；点击 `+` 把文件加入已选列表，`-` 移除。
- **搜索 TAB**：输入关键词实时搜索文件名和路径，结果同样可加可预览。
- **排序**：可以按"类型"（文件夹分组后文件名升序）或"文件名"（全局升序）排列。

**右边：已选 + 预览**

- **右上：已选参考资料**：显示当前 Top3 任务挂载了哪些 PARA 文件。点击文件可以在下方预览；点击 `✕` 移除。
- **右下：预览区**：显示当前选中文件的全文内容。

**顶部：Top3 任务切换**

三个按钮代表三个任务，点击切换。每个任务独立维护自己的已选列表。按钮上的数字表示该任务挂载了多少份参考资料。

**完成**：点击"完成资料初选"，系统会把 `plan_ready_for_focus` 置为 true，专注环会读到这个状态，提示你可以开始专注工作了。

## 五、其他五环：各尽其职

### 专注工作环（09:00-12:00）

**禁止做理清与组织**。中途冒出来的想法只走临时捕获（`sys-inbox`），不打断专注流。

核心动作：
- 从 Top3 选一个当前任务
- 开启 25 分钟番茄倒计时
- 全屏沉浸，屏蔽干扰
- 执行过程随时记录笔记
- 完成勾选

Agent 会在你完成一项后推荐下一项。

### 午休修复环（12:00-15:00）

**专属原则：极低损耗**。不做高算力决策，只清空工作记忆 + 处理两分钟可判定项。

三个子面板：
- **午休倒计时**：20-30 分钟小憩控制
- **营养平衡**：午餐建议（颜色搭配、热量、营养素）
- **快速睡眠**：短小憩引导

### 协作分享环（15:00-18:00）

核心：上午做自己，下午看世界。

- 记录协作笔记（碰撞点、表达要点）
- 捕获反馈（评论/质疑/共鸣）→ 丢进 inbox，**不在此环理清**
- 用 LLM 整理对外表达提纲
- 输出素材来自 project/area 笔记

### 投资复盘环（18:00-21:00）

这是知识晶体深化的核心时段。

**六个理论可视化组件**：树形图、矩形树图、辐射树、科技树、缠绕树、边绑定图——用于把抽象的理论结构可视化。

**GTD 步骤**：
- 复盘 Agent：汇总当日 + 改进建议
- 复盘笔记：手写复盘与颗粒化
- 回流捕获："回流："前缀触发 workflow，处理未完成项和新想法
- 理清下午捕获：处理协作环的反馈
- PARA 提纯：更新领域/资源，归档项目

**特色工具**：规则推演器、人际推演。

### 睡眠环（21:00-06:00）

**最简的板块**。

- 21:00 入睡倒计时
- 睡前捕获：把焦虑/未竟念头记入收件箱（不深度组织）
- PARA 笔记库（仅做轻量记录）

**禁止**：理清、组织、新决策。所有内容推到下一日 plan 环处理。

## 六、数据存在哪里

| 数据 | 存在哪里 | 用途 |
|------|---------|------|
| 步骤进度 | 浏览器本地 | 刷新后恢复 |
| Top3 每日 ID | 浏览器本地 | 跨日切换 |
| 任务挂载的 PARA 引用 | 浏览器本地 | 引用持久化 |
| 待执行的 LLM workflow | 浏览器本地（临时） | 跨页面跳转执行 |
| PARA 文件内容 | 后端文件系统 | 真正的知识库 |

## 七、从术层毕业

术层不是终点。它的目标是让你**不再需要它**。

当你发现某个环的步骤已经能闭着眼睛跑完，当你发现自己更想自由组合工具而不是被步骤条约束——那就是毕业的信号。

毕业后的工具会出现在通用工具面板上，你可以按自己的节奏和偏好重新装配。术层会默默记录你的毕业进度，在某个时刻把入口松开。
