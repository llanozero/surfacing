# 道：能量、承诺与意义的流通

> **定位**：本文回答的不是「点哪个按钮」，而是 **注意力与生命能量如何在一天中代谢**——各阶段消费什么、产出什么、如何把未经分化的体验，变成可复用的自我与可辨认的世界。  
> **术层对照**（工具、存储、工作流）见 `vue-app/docs/GTD-PARA-能量六环-跑通手册.md`，仅作落地附录。

---

## 一、总命题：不是三条流水线，而是一条代谢链

GTD、PARA、能量六环常被误读成三个并列模块。在道的层面，它们是同一条链上的 **三种坐标**：


| 坐标         | 问的不是  | 问的是                        |
| ---------- | ----- | -------------------------- |
| **能量六环**   | 几点开会  | **以何种身心状态**与世界接触           |
| **GTD 主链** | 任务怎么排 | **有限的生命如何下注**在未分化的可能性上     |
| **PARA**   | 文件放哪  | **意义在何种稳定度**上结晶、可被未来的我再次调用 |


```text
        未分化体验（捕获）
              │
    ┌─────────┴─────────┐
    │  理清：事 / 料     │  ← 第一次道德分叉：值不值得用「会死的那部分自我」去换
    └─────────┬─────────┘
              │
    ┌─────────┴──────────────────────────┐
    │  事 → 承诺 → 执行 → 不可逆痕迹      │  生命能量的**消耗与雕刻**
    │  料 → 沉淀 → 晶体 → 原则与参照      │  认知能量的**累积与升维**
    └─────────┬──────────────────────────┘
              │
        复盘：代谢当日；睡眠：离线整合
              │
        新一日规划：从晶体中读取，重新下注
```

**流通**的意思：上一阶段的**产出物**，是下一阶段的**输入物**；若某一环只「经历」不「代谢」，能量就会淤在身体里——表现为焦虑、空转、叙事狂热而无现实增重。

## 二、能量六环：六种「与世界相处的方式」

六环不是时间表上的格子，而是 **意识可用带宽的不同形态**。同一件事，在不同环里做，消费的不是同一样东西。


| 环      | 身心态   | 消费什么            | 产出什么                        | 若跳过或错位             |
| ------ | ----- | --------------- | --------------------------- | ------------------ |
| **睡眠** | 离线、整合 | 白天的残余张力         | 潜意识重组、身体修复                  | 次日 clarify 失真，边界模糊 |
| **规划** | 意图显化  | 昨日晶体 + 未清 inbox | **地图**（今日可下注的方向）            | 专注变成无头苍蝇           |
| **专注** | 单向度输出 | 地图上的承诺 + 深度算力   | **外部痕迹**（稿、代码、决定）+ **自我雕刻** | 只有想法，无现实重量         |
| **修复** | 极低损耗  | 工作记忆占用          | 清空缓存、恢复社交带宽                 | 下午污染上午，协作带怨        |
| **协作** | 对照、镜像 | 上午的「已成型结论」      | **反馈场**（共鸣/漏洞/噪音）           | 无对照，概念飘在词典里        |
| **投资** | 解构、升维 | 下午的反馈 + 上午的产出   | **颗粒化认知**（原则、模板、教训）         | 明日重复低效率搬砖          |


**环与环的转接逻辑（道的核心）**：

```text
专注产出 ──→ 协作验证 ──→ 投资解构 ──→ 睡眠整合 ──→ 规划重组 ──→ 专注…
   │              │              │
  「做自己」    「看世界」      「把世界变成自己的」
```

- **上午专注**：不宜塞入 heavy 社交判断——那会消费本该用于「不可逆下注」的带宽。
- **下午协作**：不是第二生产力，而是 **把内部结论拿到外部称重量**；对照在此发生，差别在此成形。
- **晚上投资**：不是加班，而是 **消化**；若不解构下午的反馈，协作只增加噪音，不增加认知资产。
- **深夜至晨规划**：解构后的零件，在规划中 **重新拼装成可执行的有限承诺**。

这与「濒死边界」同构：**日用而不知**的，往往是「我现在处在哪个环、该消费哪种能量」——直到某天专注环被协作撕碎，或投资环被跳过，才觉察边界存在。

## 三、GTD 五步：有限生命如何下注

GTD 在道层不是待办方法论，而是 ** mortality-aware attention economics**（带死亡自觉的注意力经济学）：承认今天会结束、注意力会耗尽，因此必须对可能性做分叉与取舍。

### 3.1 捕获 —— 悬置判断，留住未分化

**消费**：瞬间的念头、情绪、外部刺激。  
**产出**：尚未承诺的「可能性占位」。

道的要点：**捕获即拒绝立刻行动**。立刻行动会绕过「值不值得用一生的一部分换」的询问。inbox 在概念上是 **高熵场**——一切仍可被改写、仍可不付代价。

AI 可无限捕获且无心理负担；人的捕获若从不进入理清，则 **永远停在无代价区**，学不会「为自己的话负责」的分寸（见《人与 AI 的边界》）。

### 3.2 理清 —— 第一次分叉：事还是料

**消费**：inbox 中的未分化项。  
**产出**：两条路径——**要付行动代价的** vs **要付沉淀代价的**。


| 路径                | 本质           | 后续消费方式                 |
| ----------------- | ------------ | ---------------------- |
| **事（actionable）** | 向未来自我签发支票    | 组织 → 执行 → 复盘；消耗日历与身体   |
| **料（reference）**  | 向未来自我存放参照    | 进入 PARA 稳定度谱；消耗整理与内化时间 |
| **将来也许**          | 承认欲望但拒绝今日下注  | 不占 Top3，防假装已承诺         |
| **丢弃**            | 承认此项不配消耗任何未来 | 从注意力债务中解除              |


**理清是道德节点**：不是分类技巧，而是 **「这一缕注意力，配不配变成不可逆？」**  
事/料混在一Capture 里时，往往因为 **不愿承担分叉的代价**——既想显得在做，又想保留退路。

### 3.3 组织 —— 在稀缺中下注

**消费**：已理清的行动项池。  
**产出**：**Top3 = 今日 mortality contract**（今日有限生命契约）。

道的要点：

- Top3 不是优先级排序而已，而是 **承认通道有限**：不是多元出路都有位置，而是 **今天只有三扇窗能开**（呼应「有限上升通道」与幸存者偏差——多数人不是不够努力，是 **organize 这一环就被结构性地挤在门外**）。
- 绑定能量环：不是「几点做」，而是 **用哪种身心态消费这项承诺**——深度写作要在专注环下注，对外验证要在协作环，解构反馈要在投资环。

### 3.4 执行 —— 唯一改变现实与自我的环节

**消费**：承诺 + 时间 + 身体 + 社会可见性。  
**产出**：**外部结果** + **不可逆的自我调整**。

道的要点：

- 五步中 **只有执行** 具有 ontological weight（存在论重量）：伤害、交付、爽约、完成，都会留痕；道歉可修复关系，裂痕仍在历史里。
- AI 可模拟捕获、理清、组织、甚至生成「复盘文本」，但 **不付生存性代价**——因此不能替代执行环所铸造的「人格」。
- 若长期只捕获-理清-组织，从不执行：人在 **叙事上很 rich，在存在上很 light**——精神体验狂热，现实增重为零。

### 3.5 复盘 —— 代谢与回流

**消费**：完成/未完成项、协作反馈、执行中的摩擦。  
**产出**：**晶体**（可沉淀的原则）+ **回流**（仍值得下注但未完成的 → 新捕获）。

道的要点：

- 复盘不是打分，是 **消化**：把 collab 环的 raw feedback 分解成：情绪 / 逻辑漏洞 / 真共鸣——否则反馈会 poison 睡眠与次日规划。
- **回流** 保证闭环：未完成的承诺不假装消失，而是以 **新的捕获** 回到高熵场，等待下一轮的 moral clarify——而不是 guilt-driven 裸 addTodo（跳过理清 = 跳过责任询问）。

## 四、PARA：意义的稳定度谱，不是文件夹

PARA 在道层是一条 **熵减轴**：从发散到可复用，从外部借来的到内化为原则的。

```text
  高熵 ──────────────────────────────────────→ 低熵、高可调用
  发散(inbox) → 灵感(resource) → 启发(area) → 项目边界(project) → 时间截面(archive)
       │              │               │
   尚未是我的      借来的骨架      已长进肉里的准则
```


| 稳定度       | 心智      | 被谁消费    | 消费方式           |
| --------- | ------- | ------- | -------------- |
| **发散**    | 可能性云    | 规划、理清   | 分叉、删减、下注       |
| **灵感/资源** | 外部世界的片段 | 投资、专注   | 解构、引用、拼贴       |
| **启发/领域** | 内部化原则   | 理清、组织   | 当判准：「这件事配不配我？」 |
| **项目**    | 有边界的赌局  | 执行      | 在截止前消耗生命换交付    |
| **归档**    | 已关闭的时间片 | 复盘、偶尔检索 | 证明「我曾经付过代价」    |


**PARA 与 GTD 的关系（道层）**：

- GTD **生产** 待分流的经验；PARA **收纳** 已分流后的意义形态。
- 仪表盘上的「发散 / 灵感 / 启发 / 资源」是 **阅览与联想面**——用于 **激发下一轮捕获**，不是 GTD 的第六步。
- **误用**：把 area 里的原则当执行完成——读了很多「巨人肩上的叙事」，从未在 execute 环付过代价 → **消费前人牺牲的精神体验**，却无自己的不可逆痕迹（《濒死的边界》中叙事狂热一节）。

## 五、三层如何咬合：一日概念流

用 **最近主题**（人机边界、濒死觉察、幸存者偏差）走一遍概念流，不涉工具：

```text
【投资环 · 前夜】
  写随笔《人与 AI 的边界》《濒死的边界》
  → 产出：高稳定度 area 草案（原则）+ 低稳定度 inbox 片段（未拆行动）
  → 代谢：把「幸存者偏差 / 有限通道」从情绪叙事 decompress 成可检验命题

【睡眠】
  离线整合；若跳过：次日易把「叙事共鸣」误当成「已理清」

【规划环】
  消费：area 原则 + inbox 未拆项
  理清：哪些是可执行的规则网深化（事）？哪些是纯参照（料）？
  组织：Top3 = 在有限通道中下注——例如「两条规则网 + 一次桥接验证」
  → 承认：不是「所有灵感都配今日生命」

【专注环】
  消费：Top3 中的硬核项
  执行：写节点/边、改 YAML——**此处才产生项目级外部痕迹与自我雕刻**
  → 若只做 capture/clarify 不做 engage：停留在 AI 也可模拟的区间

【修复环】
  清空：不写深度东西；允许机械杂事
  → 保护专注环的纯度

【协作环】
  消费：专注环产出（短文、提纲）
  对外：投石问路，收集对照
  捕获：反馈 raw 进 inbox，**不在协作环当场理清**（防社交污染判断）

【投资环】
  复盘：Top3 完成度；未完成 → 回流捕获
  解构：协作 feedback → 情绪/漏洞/共鸣三分
  沉淀：真共鸣 → area；资料 → resource
  → 为明早规划准备「晶体」，而非带 raw 噪音入睡
```

## 六、流通失败：几种常见的「道层淤塞」


| 淤塞                       | 表现           | 缺哪一环的代谢                    |
| ------------------------ | ------------ | -------------------------- |
| **只捕获不理清**               | inbox 爆炸、焦虑  | 未做 moral fork；可能性债务        |
| **只理清不组织**               | 清单很长、无进展     | 未承认 mortality；不敢下注         |
| **只组织不执行**               | 计划精美、现实不动    | 无 irreversible trace；人格不生长 |
| **只执行不复盘**               | 重复踩坑、边界日用而不知 | collab/invest 反馈未消化        |
| **只读 area 不执行**          | 叙事狂热、原则堆砌    | 把 PARA 当 execute 的替代品      |
| **协作进专注**                | 上午被评价绑架      | 环错位；对照与下注混用                |
| **跳过投资**                 | 明日低效率搬砖      | 反馈未颗粒化；规划无晶体可读             |
| **AI 代劳 clarify+review** | 流畅但不增重       | 无生存性代价；缺「在乎」与「负责」          |


**幸存者偏差在道层的版本**：能进入「可被引用的成功叙事」的，多是 **完整跑通过 invest → plan → engage 循环** 的人；停在 capture 或 clarify 外环的人，不会出现在故事里，并非因为他们「不够相信叙事」。

## 七、与人机边界、濒死边界的同一根

三条随笔与本文同一根脉：

1. **现实重量** 只在 **执行 + 复盘** 中生成；AI 主链可停在 clarify/invest 的文本层，**不付生存性代价**。
2. **日用而不知的边界** 要在 **失去或复盘** 时才显形；跳过 review = 拒绝觉察。
3. **对照成概念** 要在 **协作环** 完成；闭门 clarify 易成自洽幻觉。
4. **消费前人牺牲** 发生在 **只读 area/resource 而不 execute** 时；精神体验替代了 metabolic cost。
5. **有限通道** 在 **组织** 环节显形；Top3 是结构承认，不是意志力装饰。
6. **AI 作练习场** 在道层 = 在 **capture/clarify** 高熵区练表达，**必须回流** 到 execute/collab 才完成代谢；否则永远停在无代价区。

## 八、一句话

**能量六环规定「以何种状态接触世界」；GTD 规定「有限生命如何分叉、下注、执行、代谢」；PARA 规定「意义在何种稳定度上结晶、供未来读取」。**

三者的流通，是把 **未分化的体验** 转化为 **不可逆的自我** 与 **可复用的原则**；工具只是这条代谢链的刻度尺，不是链本身。
