# 认知导航与身份隔断

## 一、核心命题：自指悖论

当你同时是系统的**设计者**和**使用者**，元认知的审视目光会破坏执行的纯粹性。每一次执行时，设计者的意识都在场——这本身就瓦解了执行者的沉浸状态。

这不是一个可以"解决"的问题，只能被**绕过**。绕过的核心策略：**将设计态与执行态物理/仪式性地隔断，两种模式不可混淆，模式切换需要真实的物理或感官成本。**

---

## 二、认知导航工具的定位

之前的领域模型（心理康复、社会导航、能量运营三层 + 表达推进元属性）定义了**"有什么"**和**"各层如何运作"**。但缺少一个关键组件：**谁在什么状态下操作哪个层**。

认知导航工具填补了这个空缺——它不是一个"新层"，而是**所有层的操作界面**：

```
领域模型（CONTEXT.md）      认知导航工具
    定义"有什么"         →       定义"谁在什么状态下操作什么"
    静态概念结构                  动态状态导航
```

---

## 三、导航节点的闭环：设计者↔执行者循环

系统的运行建立在**设计者↔执行者**的核心循环上：

```
设计者锚点（设计态）
    │ 模式切换（物理/仪式成本）
    ▼
执行者具身（执行态）
    │ 体验完成
    ▼
设计者复盘（设计态）
    │ 认知提取
    ▼
外沿扩大→再次进入执行态
```

### 三个关键防线

**1. 模式切换的真实成本**
设计态和执行态不能"想切就切"。切换需要预先设定的物理仪式（换衣服、换位置、打开特定环境），否则设计者的审视目光会持续污染执行者的沉浸。

**2. 提前复盘死锁**
最常见的崩溃路径：执行者体验尚不充分 → 设计者想提前复盘 → 复盘没有实质内容 → 对执行者状态产生负面反馈 → 再度崩溃 → 再度提前复盘 → 螺旋恶化。

唯一解法：在感到"想要复盘"时，先检查是否已完整经历了执行者具身。如果没有——回到执行态，继续沉浸。

**3. 遗忘即信任**
执行者不需要知道设计者的全部意图。设计者设计的环境和触发器，对执行者而言应当是不可见的"空气"。执行者越"无知"，执行越纯粹。遗忘不是失败，而是设计者身份真正起作用的标志。

---

## 四、认知导航工具与三层架构的映射

认知导航工具不取代三层架构，而是在每层之上叠加"设计者/执行者"的视角：

| 领域层 | 设计者（设计态） | 执行者（执行态） |
|--------|-----------------|-----------------|
| **心理康复** | 设计代偿工具、规划向下兼容阶梯 | 使用话术模板、经历表达训练——不分析"是否有效" |
| **社会导航** | 设计黑盒操作、规划圈层策略、准备体面理由 | 进入社交场景后按直觉响应——不评估"是否符合计划" |
| **能量运营** | 规划能量-任务匹配地图、复盘信息提纯 | 按六环节律做当前该做的事——不评判"效率" |

**表达推进**（元属性）同样受此约束：设计者在设计表达策略，执行者在表达中推进思维——两者不可同时在场。

---

## 五、与既有概念的关系

**"表演"与"设计者"**：手册中的"表演协议"本质是设计者心态——在外部圈层中预先设计角色脚本。但设计者的设计必须在进入场景前完成，进入后由执行者"表演"，设计者不得现场修改剧本。

**"剧本预演"与"提前复盘死锁"**：变异临界点文档中"模式A（脚本预演型）"的蹩脚感，部分来源于设计者在执行场景中仍试图同时优化脚本——这正是"提前复盘死锁"的表现。

**"认知锚点"的双重身份**：
- 对设计者：锚点是设计出来的稳定参照（如"每个圈层看到的是我的一个侧面"）
- 对执行者：锚点是不需要思考的"本能"——它只需在混乱中自动回归

## 六、总结：认知导航的完整图景

```
                    认知导航工具（操作界面）
                     ┌─────────────────────┐
                     │ 设计者锚点 → 执行者具身 │
                     │ → 设计者复盘 → 外沿扩大 │
                     └─────────┬───────────┘
                               │ 操作
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                    ▼
     ┌──────────┐       ┌──────────┐       ┌──────────┐
     │心理康复层 │       │社会导航层 │       │能量运营层 │
     └──────────┘       └──────────┘       └──────────┘
          │                    │                    │
          └────────────────────┼────────────────────┘
                               │ 贯穿
                          ┌──────────┐
                          │表达推进  │
                          │（元属性） │
                          └──────────┘
```

领域模型定义"有什么"，认知导航工具定义"谁在什么状态下如何操作它们"。
