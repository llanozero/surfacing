# Burnout 破产机制

---

## 游戏规则

### 触发条件（满足其一即触发）

| 条件 | 效果 |
|------|------|
| 连续 2 轮在专注阶段「防壁被突破」 | 获得 Burnout 标记 |
| 红色专注能量归零超过 1 轮 | 获得 Burnout 标记 |
| 收集箱中噪音卡超过 5 张 | 获得 Burnout 标记 |

### Burnout 效果

获得 Burnout 标记的玩家：
- **跳过下一轮的专注阶段和协作阶段**（只能在修复阶段恢复）
- 在跳过的轮次中，修复阶段可额外清除 2 张噪音
- 跳过轮次结束后，Burnout 标记移除
- 终局结算时每个 Burnout 标记扣 3 分

## 灵感映射

### 核心来源：[个人现状与核心挑战](file:///c:/Users/llano/Desktop/龙虾/card/核心内容文档/已串联文档/个人现状与核心挑战.md) + [冻结的灵魂与变贵的理解](file:///c:/Users/llano/Desktop/龙虾/card/核心内容文档/已串联文档/冻结的灵魂与变贵的理解：为什么成年后的修复如此艰难？.md)

| 文档概念 | 游戏映射 |
|----------|----------|
| 情绪功能受损，需像骨折一样进行"复健" | Burnout 标记强制跳过专注+协作——系统需要时间"养伤" |
| 长期压抑导致系统无法正常运转 | 红色能量归零是触发条件之一——能量管理失败=系统崩溃 |
| 外部期待与内在能力存在巨大落差 | Burnout 触发后强制跳过——你"撑不住"了 |
| 倒计时焦虑——解决越早越好 | Burnout 扣 3 分——长期不修复成本逐轮递增 |
| 理解变贵——修复窗口关闭 | 只有修复阶段能清除 Burnout——错过了专注和协作的"最佳修复窗口" |

### 设计意图

Burnout 机制是对 **"透支型生存模式"** 的直接惩罚。游戏不鼓励"硬撑"——连续高压运转而不进入修复环，系统必然会崩溃。这与现实生活中 cPTSD 的"高负荷运转→系统死机"完全同构。
