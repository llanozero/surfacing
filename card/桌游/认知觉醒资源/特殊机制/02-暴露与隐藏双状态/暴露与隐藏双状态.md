# 暴露与隐藏双状态

---

## 游戏规则

玩家在每个阶段前可选择当前状态：

| 状态 | 效果 | 切换条件 |
|------|------|----------|
| **暴露状态** | 行动收益 +1，但其他玩家可对你打出攻击类卡牌 | 修复环中可自由切换；其他环切换需消耗 1 个额外行动 |
| **隐藏状态** | 不可被攻击，但行动收益 -1 | 修复环中可自由切换；其他环切换需消耗 1 个额外行动 |

| **暴露病情**（展示真实困境）：被排斥、远离 | 暴露状态：收益高但可被攻击——"露出伤口会被当成靶子" |
| **扮演正常**（隐藏真实困境）：被认为不需要帮助 | 隐藏状态：安全但收益低——"没人注意到你需要帮助" |

| 证明"传染风险"足够低 + 需要支持的精细分寸 | 暴露状态的收益+1 ——用更高的效率换取被攻击的风险 |

### 与协作阶段的联动

协作阶段的「成果外抛」和「信息吸纳」天然对应暴露/隐藏的抉择：
- **成果外抛** → 偏向暴露（高风险高回报）
- **信息吸纳** → 偏向隐藏（低风险低回报）

### 设计意图

双状态机制是 **"变异临界点"双重困局** 在游戏中的核心体现。它迫使玩家在"效率"和"安全"之间做选择——没有"全都要"的选项。这模拟了真实社会中的 **暴露 vs 隐藏悖论**。
