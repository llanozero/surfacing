# 双轨制得分（主流与非主流路径）

---

## 游戏规则

每轮开始时玩家秘密选择本周期的得分路径：

| 路径 | 得分倍率 | 风险 |
|------|----------|------|
| **主流路径** | 执行承诺得分固定为 1 倍 | 上限受约束，无额外风险 |
| **非主流路径** | 得分 × 1.5 | 若未完成 Top3，罚分翻倍 |

## 灵感映射

### 核心来源：[主流与非主流路径分析](file:///c:/Users/llano/Desktop/龙虾/card/核心内容文档/已串联文档/主流与非主流路径分析.md)

| 文档概念 | 游戏映射 |
|----------|----------|
| **主流路径**：大地般的能量感，危险性低，顺其自然 | 双轨制的"主流路径"——安全分低，但不需要过多策略考量 |
| **非主流路径**：人迹罕至，风险未知，代价更高 | 双轨制的"非主流路径"——×1.5 得分但失败罚分翻倍 |
| 主流给予的信任窗口有限 | 主流路径得分上限受约束——社会不会给你无限的空间 |
| 试错时机：有把握才试错 | 非主流路径的高风险——没把握时试错只会透支信任 |
| 将非常规行动"日常化" | 非主流路径更接近真实游戏水平——需要更多策略策略 |

### 与"伤口展示"的关系

双轨制得分与 **暴露/隐藏状态** 形成有趣的交叉：
- 暴露 + 非主流 = 最高收益但风险最高
- 隐藏 + 主流 = 最低收益但最安全
- 暴露 + 主流 = 收益适中但暴露风险不匹配
- 隐藏 + 非主流 = 高风险低回报（最差组合）

### 设计意图

双轨制将 **"生存策略的分叉"** 简化为每一次执行前的决策。玩家必须在"安全但有限"和"高回报但可能崩盘"之间选择。这对应现实中每个人在困境中面对的 **路径选择**：随大流还是另辟蹊径。
