# 流通与代谢链

---

## 游戏规则

### 每一阶段的产出 = 下一阶段的输入

```
睡眠产出 → 规划消耗 → 规划产出 → 专注消耗 → 专注产出 → 修复消耗
    ↑                                                       │
    └─────────── 投资产出 ←─── 投资消耗 ←─── 协作产出 ←─────┘
```

- 任一环节若只"经历"不"代谢"（产出未进入下一环节），能量淤塞
- 淤塞表现为：噪音积累、工人减少、执行清单容量降低

### 流通出口（每阶段积累产物）

| 阶段 | 流通出口产物 |
|------|-------------|
| 睡眠 | 灵感卡 → 收集箱 |
| 规划 | 执行清单（带能量标记） |
| 专注 | 半成品/成果卡 → P槽待整理 |
| 修复 | 整洁面板、清空噪音 |
| 协作 | 资源、反馈卡 |
| 投资 | 升级后的领域池 + 归档区VP |

### 设计意图

流通与代谢链是整个游戏的"发动机"。它模拟的是 **知识工作者一天中能量的完整代谢**——不是线性的任务列表，而是环环相扣的代谢过程。

每个阶段的"流通出口"都是强制性的——这意味着玩家不能跳过任何一环。这和"思维通过表达推进"的机制同构：思想必须外化为某种形态（流通出口）才能被下一环节处理。
