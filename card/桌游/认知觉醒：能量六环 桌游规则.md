# 认知觉醒：能量六环 桌游规则

> 将 GTD + PARA + 能量六环 的工作流框架转化为六阶段严格限制的重度策略桌游。  
> 核心机制：引擎构筑 + 资源管理 + 阶段限制推演。  
> 风格类比：狼人杀式的"阶段发言/行动"——睡眠和专注阶段禁言，协作阶段开放交互。

---

## 一、游戏概述

### 背景设定

你是一名知识工作者。每一天，你的精力以六种形态流转——睡眠整合、规划调度、专注产出、修复清空、协作验证、投资升维。**只有在对应阶段执行被允许的操作，才能高效运转；违规操作会直接产生噪音，累积到一定程度则系统崩溃。**

### 核心机制

| 机制 | 说明 |
|------|------|
| **引擎构筑** | 通过投资阶段永久升级领域池（A槽），获得持续能力加成 |
| **资源管理** | 管理红色专注能量、黄色社交能量、蓝色修复资源、白色信息碎片、黑色噪音五种资源 |
| **阶段限制** | 每阶段只能执行特定操作；违规操作扣除能量或产生噪音 |
| **狼人杀式推演** | 专注阶段全员禁言，协作阶段开放谈判 |

### 玩家人数与时长

- 玩家人数：2-4 人
- 单局时长：90-120 分钟
- 复杂度：重策
- 推荐轮次：7 轮（代表 7 天）

---

## 二、核心组件与术语定义

### 2.1 玩家面板：PARA 认知图谱

每个玩家的个人桌面即为 PARA 存储器，分为四个专属卡牌槽：

| 槽位 | 名称 | 存放内容 | 功能 |
|------|------|----------|------|
| **P槽** | 项目仓（Projects） | 当前正在执行、有明确截止轮次的高分任务卡 | 执行核心产出 |
| **A槽** | 领域池（Areas） | 基础能力被动卡（如健康、财商） | 每轮提供持续Buff |
| **R槽** | 资源库（Resources） | 素材卡/工具卡 | 可在特定阶段消耗以加成产出 |
| **A槽** | 归档区（Archives） | 已结算的卡牌 | 最终胜利分（VP）计分堆 |

> 注意：两个"A槽"需在版图上用「领域池」和「归档区」区分标注。

### 2.2 核心资源指示物

| 资源 | 颜色 | 用途 | 恢复方式 |
|------|------|------|----------|
| **专注能量** | 红 | 高算力核心资源，用于专注阶段执行卡牌 | 睡眠阶段恢复 |
| **社交能量** | 黄 | 交互核心资源，用于协作阶段展示/交易 | 睡眠阶段恢复 |
| **修复资源** | 蓝 | 用于清空异常状态（噪音、疲劳标记） | 每轮开始固定+1 |
| **信息碎片** | 白 | 基础卡牌原料，可转化为行动卡 | 规划阶段从收集箱获取 |
| **精神噪音** | 黑 | 负面卡牌，堆积在收集箱中会扣分或导致系统卡顿 | 修复阶段消耗蓝色资源清除 |

### 2.3 GTD 调度中心

| 区域 | 功能 |
|------|------|
| **收集箱** | 玩家的抽牌堆和临时置牌区。所有未处理的外部事件、灵感、噪音先进入此区 |
| **执行清单** | 规划阶段完成后，本轮确定要执行的卡牌队列（最多与当前工人数量相同） |

---

## 三、胜负条件

游戏结束条件（满足其一即触发终局结算）：
1. 完成 **7 轮**（代表 7 天）
2. 某玩家的 **A槽·领域池** 全部卡牌升级至最高等级

### 终局计分

```
最终总分 = 归档区VP + 领域池等级分 × 2 + 已完成项目卡基础分
          - 收集箱中残留噪音卡数量 × 2
          - Burnout标记数量 × 3
```

---

## 四、六阶段详细规则

每轮代表"一天"，严格按照以下六阶段顺序推演：

```
┌──────────────────────────────────────────────────────────────┐
│  1. 睡眠阶段（后台编译）──→ 2. 规划阶段（能量调度）             │
│        ▲                                        │            │
│        │                                        ▼            │
│  6. 投资阶段（解构升维）←── 5. 协作阶段（验证表达）             │
│                                            │                 │
│                                  4. 修复阶段（系统清空）←─────┘
└──────────────────────────────────────────────────────────────┘
```

### 一、睡眠阶段（Sleep Phase）—— 离线整合

> **阶段设定**：黑夜阶段。玩家将面板翻面，系统进入"后台自动编译"。全员禁言。

#### 允许的操作

- **【自动编译】**：指定 P槽 或 R槽 中最多 2 张信息卡，秘密塞入 A槽·领域池 下方进行"潜意识孵化"（下轮规划阶段盲抽1张进入收集箱）。
- **【能量重置】**：根据 A槽·领域池中的健康/体能被动卡等级，恢复专注能量（红）和社交能量（黄）。

| 健康等级 | 红色恢复 | 黄色恢复 |
|----------|----------|----------|
| Lv.0 | 2 | 1 |
| Lv.1 | 3 | 2 |
| Lv.2 | 4 | 3 |
| Lv.3 | 5 | 4 |

#### 禁止行为

- 禁止打出任何手牌
- 禁止与其他玩家交流
- 若上一轮结束时收集箱中留有 **精神噪音（黑）**，此阶段恢复的能量 **减半**（向下取整）

#### 流通出口

从潜意识孵化堆中盲抽 1 张"灵感卡"，直接面朝下放入收集箱。

---

### 二、规划阶段（Planning Phase）—— 建立地图

> **阶段设定**：清晨阶段。全员亮牌，开始调度一天资源，进行"排兵布阵"。可交流计划和策略。

#### 允许的操作

- **【清空收集箱】**：强制翻开收集箱中所有卡牌，分类摆放：
  - 信息卡（白）→ 手牌区
  - 噪音卡（黑）→ 留在收集箱（进入惩罚区）
  - 事件卡 → 立即结算
- **【动作转化】**：消耗 1 点专注能量，将手牌中的信息卡转化为"行动卡"，放入执行清单。每张行动卡需标注消耗（红/黄/蓝）与产出（VP/资源）。
- **【能量锚定】**（核心操作）：将本轮拥有的能量标记（红/黄），预先放置在执行清单的卡牌上。每张卡牌必须锚定至少 1 个对应颜色能量才能执行。

#### 禁止行为

- 禁止在此时执行卡牌效果（不能进行生产或攻击/防御）
- 禁止调取未经规划的 R槽 资源
- 执行清单容量 = 当前可用工人数（默认3人）

#### 流通出口

形成一份带有能量标记的 **执行清单**，公开放置于版图旁。

---

### 三、专注阶段（Focus Phase）—— 深度产出

> **阶段设定**：上午阶段。高能计算期，玩家处于"绝对防壁"状态。**全员禁言。使用沙漏计时。**

#### 允许的操作

- **【硬核产出】**：只能执行执行清单中锚定了 **专注能量（红）** 的卡牌。消耗红色能量，将 P槽 中的项目进度向前推进，或将信息碎片加工为"成果卡"。
- **【深度心流】**：连续执行 2 张以上红色卡牌，额外获得 1 个信息碎片。

#### 禁止行为

- 禁止执行任何带有"社交""沟通""协作"标签的卡牌
- **【防壁机制】**（核心规则）：此阶段若场上触发任何"突发外部事件卡"（其他玩家的干扰或系统事件），玩家 **不得阅读卡牌内容**，必须立刻将其直接丢入收集箱，否则视作"分心"，直接扣除 1 点专注能量
- 防壁被突破 2 次以上 → 获得 1 个 Burnout 计数
- **本阶段全员禁言，说话者拿 1 张噪音卡放入收集箱**

#### 流通出口

产生的"半成品/成果卡"进入「P槽待整理区」。

---

### 四、修复阶段（Recovery Phase）—— 系统清空

> **阶段设定**：中午阶段。垃圾回收与内存释放。可轻声交流，不可谈判交易。

#### 允许的操作

- **【内存释放】**：消耗 **修复资源（蓝）**，丢弃收集箱或手牌中的噪音卡（黑）。每 1 点蓝资源可丢弃 1 张噪音。
- **【轻量处理】**：允许执行执行清单中注明"耗时<2分钟"或"0能量消耗"的机械性杂务卡（如补牌、微调面板位置）。
- **【成果落锁】**：将专注阶段产出的卡牌，正式整齐地排入 P槽。

#### 禁止行为

- 禁止执行任何需要消耗红色或黄色能量的卡牌
- 禁止进行玩家间的交易或谈判
- 禁止阅读新事件卡

#### 流通出口

玩家工作记忆清空，个人面板处于整洁状态。收集箱中的噪音卡数量决定下一轮睡眠阶段的能量恢复倍率：
- 0 张噪音 → 正常恢复
- 1-2 张噪音 → 恢复 × 0.75
- 3+ 张噪音 → 恢复 × 0.5

---

### 五、协作阶段（Collaboration Phase）—— 验证表达

> **阶段设定**：下午阶段。打破防壁，玩家之间、玩家与世界交互的公共阶段。  
> **类似狼人杀白天发言——开放谈判、交易、嘴炮。**

#### 允许的操作

- **【成果外抛】**：打出锚定了 **社交能量（黄）** 的卡牌，向中央市场或特定玩家展示、贩卖自己的成果卡，赚取 VP、资源或声望。
- **【信息吸纳】**：与其他玩家进行资源交易、结盟，或从公共牌堆抽取"外部反馈卡"。
- **【狼人杀式交互】**：玩家可自由谈判、说服、结成临时联盟。允许口头承诺（无强制执行）。

#### 禁止行为

- 禁止独自闭门造车——所有卡牌结算必须包含"交互"或"对外交付"属性
- 禁止强制执行口头承诺（联盟是否兑现全凭自觉）

#### 流通出口

赚取的资源进入临时缓存；换回的"外部反馈卡"推入反馈收集箱（投资阶段处理）。

---

### 六、投资阶段（Investment Phase）—— 解构升维

> **阶段设定**：傍晚阶段。复盘与系统大升级，决定玩家长期强弱的胜负手。可轻声交流。

#### 允许的操作

- **【解构反馈】**：将协作阶段收到的外部反馈卡分类拆解。每拆解 1 张反馈卡获得 1 个「认知精粹」。
- **【提纯增殖】**（核心引擎操作）：消耗认知精粹，永久升级 A槽·领域池 中的卡牌。升级效果：
  - Lv.1 → Lv.2：需 2 精粹，Buff 翻倍
  - Lv.2 → Lv.3：需 4 精粹，解锁终极效果
- **【归档沉淀】**：将 P槽 中已完成的项目卡移入 A槽·归档区，转化为最终 VP；将不再需要的资源移入弃牌堆。

#### 禁止行为

- 禁止再向外部世界交付任何成果
- 禁止保留未结算的临时反馈卡——未处理的反馈在阶段结束时会 **自动转化为噪音卡** 进入收集箱

#### 流通出口

升级后的 PARA 系统与清理完毕的 GTD 清单，直接对接下一轮的 **睡眠阶段**。

---

## 五、Burnout 破产机制

> 连续高压运转而无修复，必然导致系统崩溃。

### 触发条件（满足其一即触发）

| 条件 | 效果 |
|------|------|
| 连续 2 轮在专注阶段「防壁被突破」 | 获得 Burnout 标记 |
| 红色专注能量归零超过 1 轮 | 获得 Burnout 标记 |
| 收集箱中噪音卡超过 5 张 | 获得 Burnout 标记 |

### Burnout 效果

获得 Burnout 标记的玩家：
- **跳过下一轮的专注阶段和协作阶段**（只能在修复阶段"摆烂"摸鱼）
- 在跳过的轮次中，修复阶段可额外清除 2 张噪音
- 跳过轮次结束后，Burnout 标记移除
- 终局结算时每个 Burnout 标记扣 3 分

## 六、阶段执行监督规则（狼人杀式）

| 阶段 | 沟通状态 | 违规惩罚 |
|------|----------|----------|
| **睡眠** | 🔇 全员禁言 | 说话拿 1 噪音卡 |
| **规划** | 🔊 可交流策略 | — |
| **专注** | 🔇 全员禁言 + 沙漏计时 | 说话拿 1 噪音卡 + 扣 1 红能量 |
| **修复** | 🔈 可轻声交流 | — |
| **协作** | 🔊 开放谈判交易 | — |
| **投资** | 🔈 可轻声交流 | — |

> 禁言阶段由当前轮次的"阶段监督员"（轮值玩家）执行。监督员若包庇违规者，自己也拿 1 噪音卡。

## 七、游戏设置与卡牌详解

### 初始设置

1. 每位玩家领取：PARA 玩家面板、3 个工人指示物、2 红能量、1 黄能量、2 蓝修复资源
2. 洗牌堆分为三叠：信息牌堆、事件牌堆、被动牌堆
3. 各玩家从被动牌堆抽 2 张放入 A槽·领域池
4. 各玩家从信息牌堆抽 3 张放入收集箱
5. 随机确定首位玩家（兼任第一轮阶段监督员）

### 卡牌类型一览

| 卡牌类型 | 来源牌堆 | 存放位置 | 功能 |
|----------|----------|----------|------|
| **信息卡**（白） | 信息牌堆 | 收集箱→手牌→执行清单 | 可转化为行动卡 |
| **行动卡** | 由信息卡转化 | 执行清单 | 执行产出 VP 或资源 |
| **被动卡** | 被动牌堆 | A槽·领域池 | 持续 Buff |
| **事件卡** | 事件牌堆 | 触发展开 | 全局影响 |
| **噪音卡**（黑） | 违规/未处理反馈 | 收集箱 | 负面，扣分 |
| **反馈卡** | 协作阶段获得 | 临时缓存 | 可解构为认知精粹 |
| **灵感卡** | 睡眠孵化产出 | 收集箱 | 高价值信息卡 |

```
   ┌──────────┐

   └────┬─────┘
        ▼
   ┌──────────┐
   │  规划     │  清空收集箱，转化行动卡，能量锚定
   │  可交流    │
   └────┬─────┘
        ▼
   ┌──────────────┐
   │  专注（禁言）  │  执行红色卡牌，防壁机制，沙漏计时
   │  说1字=拿噪音  │
   └────┬─────────┘
        ▼
   ┌──────────┐
   │  修复     │  清除噪音，轻量杂务，成果落锁
   │  轻声交流  │
   └────┬─────┘
        ▼
   ┌──────────────┐
   │  协作（开放）  │  打黄色卡牌，交易结盟，狼人杀式嘴炮

   └────┬─────────┘
        ▼
   ┌──────────┐
   │  投资     │  解构反馈，升级领域池，归档得分
   │  轻声交流  │
   └────┬─────┘
        │
        └──→ 回到睡眠（下一轮）
```

## 九、设计理念对照

| GTD/PARA/能量六环 | 游戏映射 | 设计意图 |
|-------------------|----------|----------|
| 睡眠环 | 睡眠阶段 · 后台编译 | 能量回充是代谢链的起点 |
| 规划环 | 规划阶段 · 清空收集箱 | 理清未分化的可能性，做分叉决策 |
| 专注环 | 专注阶段 · 防壁禁言 | 深度产出需要外部保护 |
| 修复环 | 修复阶段 · 噪音清除 | 不清理缓存就会逐轮累积惩罚 |
| 协作环 | 协作阶段 · 狼人杀发言 | 内部结论需要外部验证 |
| 投资环 | 投资阶段 · 领域升级 | 反馈不消化等于白费；归档才结晶为资产 |
| GTD收集箱 | 收集箱机制 | 捕捉所有未处理项，堆积=噪音=惩罚 |
| PARA领域池 | A槽被动卡升级 | 引擎构筑——长期能力投资 |
| PARA归档区 | 完成项目移入归档 | 只有完成并归档的卡才算真正得分 |
| Top3有限契约 | 执行清单容量=工人数 | 今天能做的事是有限的 |
