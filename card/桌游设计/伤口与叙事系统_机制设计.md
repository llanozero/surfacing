# 《缝合线：心智建模纪元》—— 伤口与叙事系统（Wound & Narrative System）

> **定位**：在《缝合线：心智建模纪元》基础规则之上引入的核心扩展机制，将"社会性体面维护"这一隐性博弈彻底规则化。在双人对战中，具象化为**"高风险的直接裸露"**与**"高产出的剧情化翻译"**之间的策略博弈。

---

## 一、核心新组件

### 1.1 【真实伤口卡】（True Wounds）

当玩家角色执行高风险的"探索行动"失败，或遭受对手的"心智打击"时，不会直接掉血，而是在该角色面板上留下一张【真实伤口卡】。

**示例伤口**：重度抑郁、家庭经济崩溃、社交障碍

**核心特性**：
- 每张伤口卡自带**功能性致残效果**（如：每回合专注能量产出 -1）
- 玩家需要通过"求助"来获取外部资源治疗伤口
- 伤口如果不处理，会持续削弱角色的行动能力

---

### 1.2 【体面理由卡】（Decent Reasons）

属于玩家的基础功能牌堆。用于将【真实伤口】"翻译"为社会通用的无害语言。

**翻译示例**：

| 真实伤口 | 体面翻译 |
|----------|----------|
| 重度抑郁 | 职业方向调整 |
| 家庭经济崩溃 | 投资策略优化 |
| 社交障碍 | 专业能力沉淀 |

---

### 1.3 【叙事能量轨】与【真空危机】（Narrative Energy & Vacuum）

每个被激活的求助或故事，在桌面上都有一个【叙事能量轨】（10 → 0）。

**衰减规则**：
- 每经历一个游戏阶段（Phase），轨道数值自动衰减
- 衰减公式：

$$\text{每阶段衰减值} = 2 \times (1 + \text{已重复讲述次数})$$

**衰减示意**：
| 讲述次数 | 每阶段衰减 | 能量轨可持续阶段数 |
|----------|-----------|-------------------|
| 第1次 | 2 | 5个阶段 |
| 第2次（同一故事） | 4 | 2.5个阶段 |
| 第3次 | 6 | 近乎立即进入真空 |

> **设计意图**：惩罚"反复咀嚼同一叙事"，鼓励玩家不断构建新的体面故事，而不是一直卖惨。

---

## 二、展示伤口的四大毁灭性惩罚

在【协作阶段】，若玩家选择**不使用**"体面理由"，而是直接向中央市场展示【真实伤口卡】以换取即时资源，将强制触发以下**四大破窗效应**：

### 惩罚总览

| # | 文本概念 | 游戏化机制表现 | 惩罚后果 |
|---|----------|---------------|----------|
| 1 | **无知之害** | 触发"廉价安慰"判定 | 场上不具备相同伤口的NPC或对手角色，强制对你执行一次"错位互动"。为你塞入一张【精神噪音（黑）】，且强行锁死你下回合的一个行动格。 |
| 2 | **集体隔离** | 【隔离轨】（Isolation Track）推进 | 暴露异常的角色在【隔离轨】上前进一格。当隔离值达到 **3** 时，该角色获得"不稳定因素"标签，**永久丧失进入【外部支持圈（名利场）】的资格**。 |
| 3 | **工具化风险** | 对手获得【软肋筹码】 | 对手玩家直接拿走你暴露的【真实伤口卡】的副牌，作为其手牌中的【暗桩武器】。后续任何大回合，对手可在关键节点打出此牌，直接将你的一场关键行动判定为"意外失败"。 |
| 4 | **情绪真空** | 触发"额度耗尽"与"真空期" | 展示伤口换取的资源仅在当前阶段有效。阶段结束，【叙事能量轨】瞬间**清零**。该角色进入【真空期】，未来 **3个大回合** 内无法对该伤口进行二次倾诉，且持续流失【社交能量】。 |

### 四大惩罚的连锁效应

```
直接裸露伤口
    │
    ├──► 无知之害 ──► 塞噪音 + 锁行动格 ──► 下回合更弱
    │
    ├──► 集体隔离 ──► 隔离值累积至3 ──► 永久丧失外部圈资格
    │
    ├──► 工具化风险 ──► 对手拿走软肋筹码 ──► 后续被精准狙击
    │
    └──► 情绪真空 ──► 3回合真空期 + 社交能量流失 ──► 恢复能力崩溃
```

> **核心设计洞察**：直接裸露的代价不是"一次性掉血"，而是**结构性恶化**——你越弱，越难恢复，对手越强。完美模拟现实中"破窗效应"的自增强循环。

## 三、替代策略：将求助转化为"剧情体验契约"

为规避四大惩罚，玩家必须在【规划阶段】启动 **【翻译四步法】** 机制，将求助包装为一场双赢的"游戏剧情"。

### 3.1 翻译流程

```
[真实伤口：重度抑郁]
        │
        ▼  （打出【体面理由卡】）
[功能翻译：职业转型/时间沉淀]
        │
        ▼  （在中央市场发布）
[剧情体验契约：邀请他人共同见证成长]
        │
        ├──► 【对手/NPC投资】
        │
        └──► 【双方平等获利】
```

### 3.2 【剧情体验契约】的运作方式

玩家不再扮演"受害者"向对手或系统乞讨，而是作为**"编剧"**，在公共区域发布一张【剧情体验契约】。

**契约示例**：《关于我从零开启职业转型的10天公路实验》

#### 契约成本
- 玩家必须投入少量的【信息碎片】和【形象弹性值】作为剧本启动资金

#### 互动对赌
- 另一位玩家（或中立NPC）可消耗自己的资源选择"入局成为同路人"

#### 双向回报

| 角色 | 收益 |
|------|------|
| **发布者（你）** | 获得功能性支持（如：借用对方工人棋子、获得通关资金）；由于包装体面，【隔离轨】不上升，【外部圈声望】+2 |
| **参与者（对手）** | 获得独特的【道德满足积分】或【独家阅历卡】 |

> **核心理念对应**："他人帮助你，本质上也是获得一种买不到的特殊人生体验。"

## 四、具体操作框架：玩家的"翻译"决策流

在每个大回合的【规划阶段】，拥有伤口的角色必须面对以下决策树：

### 步骤1：识别功能核心
- **动作**：剥离情感包装
- **说明**：玩家必须声明其真实伤口带来的"功能性短缺"
- **示例**："我的角色因为'社交障碍'无法去外部圈摸牌，我核心需要的是'独处补牌的时间'"

### 步骤2：匹配社会等价物
- **动作**：打出体面理由卡
- **说明**：从手牌中消耗一张【体面理由卡】
- **示例**：宣告将"社交障碍"翻译为"正在闭门专注提升特定专业能力"

### 步骤3：构建连续性叙事
- **动作**：设定能量轨
- **说明**：为这个体面理由设定【叙事能量轨】
- **效果**：只要能量不归零，角色在外部圈的判定依然是"积极向上的正常人"，完美绕过《破窗效应》的压迫

### 步骤4：预留升级/退出通道
- **动作**：动态结算
- **伤口愈合时**：在【投资阶段】宣告"调整完成"，无缝回收角色
- **情况恶化时**：消耗1点【形象弹性】，将剧本升级为"方向不符，换一种策略"，继续维持体面

### 决策流程图

```
              ┌──────────────────────────┐
              │   真实伤口产生            │
              │ (探索失败 / 心智打击)     │
              └────────────┬─────────────┘
                           │
              ┌────────────▼─────────────┐
              │     玩家决策点            │
              └─────┬──────────────┬─────┘
                    │              │
         ┌──────────▼───┐  ┌──────▼────────────┐
         │ 直接裸露      │  │ 体面翻译路线       │
         │(高风险高回报) │  │(规划阶段启动)      │
         └──────┬───────┘  └──────┬────────────┘
                │                 │
       ┌────────▼────────┐ ┌─────▼─────────────┐
       │ 四大惩罚触发     │ │ 剧情体验契约发布   │
       │ ·廉价安慰       │ │ ·投入信息碎片      │
       │ ·隔离轨推进     │ │ ·对手可选择入局    │
       │ ·软肋被拿走     │ │ ·双向回报          │
       │ ·真空期        │ │ ·隔离轨不上升      │
       └────────────────┘ └─────┬─────────────┘
                                │
                        ┌───────▼─────────────┐
                        │    内圈治愈          │
                        │ ·消耗专注能量        │
                        │ ·需要特定资源        │
                        │ ·全程隐秘→完美分     │
                        └─────────────────────┘
```

## 五、终局胜负维度的补完

基于此系统，双人局的胜负博弈形成两条互相对制的路线：

### 路线A：叙事大师（完美人格整合分）

**达成条件**：
- 全场从未暴露过任何一张【真实伤口卡】
- 全部通过【剧情体验契约】和【体面理由】优雅度过所有系统危机
- 将所有伤口隐秘地在【内圈】治愈并归档

**奖励**：获得最高荣誉——**"完美人格整合分"**

### 路线B：猎手路线（工具化收割）

**达成条件**：
- 主动攻击对手，撕开其"体面理由"
- 逼迫对手露出【真实伤口】
- 在对手撑不住进行"一次性倾诉"时，疯狂收割【软肋筹码】
- 通过工具化对手弱点赢得游戏

### 攻防对制关系

```
  叙事大师路线                    猎手路线
  ┌─────────────┐              ┌─────────────┐
  │ 维持体面    │◄─── 对抗 ───►│ 撕开体面    │
  │ 构建契约    │              │ 逼露伤口    │
  │ 隐秘治愈    │              │ 收割软肋    │
  └──────┬──────┘              └──────┬──────┘
         │                            │
         ▼                            ▼
  【完美人格整合分】            【工具化胜利】
```

## 六、待深化的设计问题

### 6.1 体面理由卡的稀缺性平衡
- 是否需要分等级？（轻度翻译 vs 重度翻译对应不同伤口）
- 是否存在"翻译失败"的可能性？（如对手打出"拆穿"牌）

### 6.2 对手"拆穿"的主动攻击路径
当前规则中，对手获取软肋筹码的前提是玩家自己撑不住主动裸露。建议增加主动攻击路径：
- 对手消耗资源打出"质疑"牌 → 强制进行一次"叙事检定"
- 若叙事能量轨 < 3，检定失败 → 伤口暴露
- 若能量轨充足，维持体面，对手浪费资源

### 6.3 内圈治愈的成本明确
- 治愈需要消耗**专注能量** + **特定资源**（如专业帮助卡）
- 治愈过程本身也是一个"叙事窗口"——如果在治愈过程中被对手打断，伤口可能恶化
