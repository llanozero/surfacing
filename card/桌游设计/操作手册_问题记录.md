## 一、基本操作流程

### 1.1 牌桌初始化

```
1. 选择玩家数（3-8人）
2. 选择阵营数（2-3阵营）
3. 选择代打倍速
4. 点击"🔀 洗牌"
5. 点击"🃏 发初始手牌"
```

### 1.2 回合流转

每回合分为 4 个阶段，通过 **"⏭️ 推进阶段"** 按钮流转：

| 阶段 | 名称 | 说明 |
|------|------|------|
| 📜 事件翻牌 | Phase 0 | 自动抽取事件牌，化茧期玩家负面效果 ×5 |
| 🎭 身份行动 | Phase 1 | 玩家可执行质疑/采集/密语/化茧/技能牌 |
| ⚔️ 博弈对抗 | Phase 2 | 攻击/防御/反击结算 |
| 🧠 内省调整 | Phase 3 | 子人格调整/化茧倒计时/状态结算 |

当从 Phase 3 推进到 Phase 0 时，会自动触发 **新回合**（`round++`）。

### 1.3 回合结算

点击 **"⏭️ 回合结算"** 执行：
- 技能冷却 -1
- 非主导意识自动转入休眠
- 行动点重置（理智型主导 = 4，其余 = 3）
- 被动技能效果触发（滋养型回能、内省型冲突觉察等）
- 失语回合倒计时
- 代打玩家自动检查化茧条件

## 二、玩家操作

### 2.1 选中玩家

- **点击任一玩家区域** → 该玩家被选中（黄色高亮边框 + "▶ 当前操作" 指示）
- 再次点击**已选中的玩家** → 无反应（防重复触发）
- 所有操作类按钮（"当前玩家抽牌"等）只作用在**当前选中玩家**上

### 2.2 手动模式

玩家默认处于手动模式。可以执行：
- **切换意识状态**：点击子人格芯片切换活跃/休眠
- **释放技能**：活跃状态下点击技能名称释放
- **弃牌**：手牌卡上的 × 按钮

### 2.3 代打模式

每个玩家右上角有代打切换按钮：

| 按钮状态 | 含义 |
|----------|------|
| 🤖 手动 | 当前玩家手动控制，点击可开启代打 |
| 🤖 代打中 | AI 接管该玩家，点击可切回手动 |

代打 AI 的决策逻辑：
1. 按优先级（R→D→N→E→S→I→P→W）逐个激活高能量意识
2. 自动消耗行动点释放可用技能（有冷却判断）
3. 满足条件时自动宣告化茧（队友存活 + 内耗 ≥ 3回合 + 行动点 ≥ 5）

## 三、代打动画系统

### 3.1 异步执行

`runAutoPilot` 是 `async` 函数，每个操作步骤之间插入延迟：

```
意识激活 1 → delay(800ms/倍速) → 渲染 → 意识激活 2 → delay → 渲染 → ...
技能释放 1 → delay → 渲染 → 技能释放 2 → delay → 渲染 → ...
```

每次 `await delay()` 后都会调用 `renderPlayers()`，确保 UI 在每一步之间更新。

### 3.2 倍速控制

牌桌配置栏中的 **代打倍速** 选择器控制执行速度：

| 倍速 | 步间延迟 |
|------|----------|
| 1x | 800ms |
| 2x | 400ms |
| 4x | 200ms |
| 8x | 100ms |

公式：`stepDelay = 800ms / speedMultiplier`

### 3.3 暂停/继续

代打执行期间操作栏显示 **"⏸ 暂停"** 按钮（"全部代打"按钮自动隐藏）：

| 操作 | 效果 |
|------|------|
| 点击 ⏸ 暂停 | `autoPilotPaused = true`，代打在下一个步骤处冻结 |
| 点击 ▶ 继续 | `autoPilotPaused = false`，代打从冻结处继续 |

实现原理：`stepDelay` 将 800ms/倍速 拆分为 100ms 粒度循环，每段后检测 `autoPilotPaused`，若为 true 则进入 `while` 循环每 100ms 轮询一次直到解除。

### 3.4 状态指示器

代打执行期间：
- 牌桌中央显示 **"🤖 代打进行中..."**（闪烁动画）
- 所有操作按钮自动禁用（灰色 + `cursor: not-allowed`）
- 暂停按钮不受影响（可操作）
- 代打完成后自动恢复

### 3.5 全部代打

点击 **"🤖 全部代打"** 按钮：
1. 将所有手动玩家切换为代打模式
2. **串行执行**每个玩家的代打（前一个完成后才开始下一个）
3. 每个玩家之间输出分割线 `──────── 下一位代打 ────────`
4. 全部执行完毕后自动推进到**下一回合**（`round++`、回到事件翻牌阶段、自动抽事件牌）

## 四、已知问题 & 已修复记录

### 4.1 ✅ 已修复

| # | 问题 | 原因 | 修复 |
|---|------|------|------|
| 1 | 代打无动画，一次性出结果 | `runAutoPilot` 同步执行，UI 来不及渲染 | 改为 `async` 异步队列，每步 `await delay()` |
| 2 | 无法控制代打速度 | 延迟固定不可调 | 添加倍速选择器（1x/2x/4x/8x） |
| 3 | "全部代打"只能执行一次 | 按钮状态未正确重置 | `runAllAutoPilots` 开头重置按钮样式和 `disabled` |
| 4 | 代打中途无法暂停 | 无暂停机制 | 添加暂停/继续按钮 + `autoPilotPaused` 标记 |
| 5 | 点击已选玩家面板闪烁 | `selectPlayer` 未判断是否已选中 | 添加 `index === activePlayerIndex` 提前 return |
| 6 | 代打完成后回合不累加 | `runAllAutoPilots` 尾部无推进逻辑 | 尾部追加 `round++`、`phaseIndex=0`、自动抽事件牌 |

### 4.2 ⚠️ 已知行为说明

| 行为 | 说明 |
|------|------|
| "回合结算" 不推进回合 | "回合结算" 只做状态结算（冷却/被动/行动点），不改变 round。需要靠 "推进阶段" 或 "全部代打" 推进 |
| 代打推进回合后阶段回到事件翻牌 | 这是设计行为——全部代打完成后视为全员行动完毕，直接进入下一轮的事件翻牌阶段 |
| 暂停在步间粒度生效 | 暂停检测在每 100ms 粒度内进行，不是立即停止。最坏情况等待 100ms 后生效 |
| 代打与手动混合使用 | 部分玩家手动、部分代打是支持的。代打只影响标记为 "代打中" 的玩家 |

## 五、JavaScript 关键函数索引

| 函数 | 位置 | 功能 |
|------|------|------|
| `initTable()` | JS 中部 | 初始化牌桌、阵营分配、玩家创建 |
| `nextPhase()` | JS 中部 | 推进 4 阶段流程，round 自增 |
| `endTurnActions()` | JS 尾部 | 回合结算：冷却/被动/行动点重置 |
| `selectPlayer(index)` | JS 中部 | 选中玩家（防重复点击） |
| `toggleAutoPilot(index)` | JS 中部 | 切换玩家代打/手动模式 |
| `runAutoPilot(pi)` | JS 中部 | `async` 异步代打执行（激活→技能→延迟） |
| `runAllAutoPilots()` | JS 中部 | `async` 全部代打 + 回合推进 |
| `toggleAutoPilotPause()` | JS 中部 | 暂停/继续切换 |
| `setAutoPilotBusy(isBusy)` | JS 中部 | 控制忙碌状态、按钮禁用、指示器 |
| `stepDelay()` | 在 `runAutoPilot` 内 | 暂停感知的延迟函数，每 100ms 检测一次 |
| `drawEventCard()` | JS 中部 | 抽取事件牌并结算效果 |
| `triggerCocoon()` | JS 中部 | 启动化茧蜕变（需满足前置条件） |

## 六、数据结构参考

### gameState 关键字段

```js
{
  round: 0,                    // 当前回合数
  phaseIndex: 0,               // 阶段索引 (0-3)
  activePlayerIndex: 0,        // 当前选中玩家
  speedMultiplier: 1,          // 代打倍速
  autoPilotBusy: false,        // 代打忙碌中
  autoPilotPaused: false,      // 代打暂停中
  currentEventCard: null,      // 当前事件牌
  cocoonOmega: 5,              // 化茧脆弱系数 Ω
  cocoonGamma: 0.2,            // 接力递增系数 γ
  twilightActive: false,       // 黄昏降临触发
  turnLimit: 20,               // 硬截止回合
  players: [],                 // 玩家数组
  factions: [],                // 阵营数组
  drawPile: [],                // 摸牌堆
  discardPile: [],             // 弃牌堆
  logs: []                     // 操作日志
}
```

```js
{
  name: '玩家一',
  factionId: 0,                // 所属阵营索引
  factionName: '星火阵营',
  externalPersona: { ... },    // 对外身份卡
  personas: [ ... ],           // 内部子人格数组
  hp: 10, maxHp: 10,           // 生命值
  spirit: 5, maxSpirit: 5,     // 精神值
  actionPoints: 3,             // 行动点
  resources: 5,                // 资源
  alive: true,                 // 存活状态
  silenced: 0,                 // 失语回合数
  cocoonStage: null,           // 化茧阶段：null / 'cocooning' / 'success' / 'failed'
  hasEvolved: false,           // 是否已完成化茧
  autoPilot: false,            // 代打模式
  hand: [],                    // 手牌
  personaStates: { ... }       // 意识状态
}
```
