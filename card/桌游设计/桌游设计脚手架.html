💡 核心理念

每个玩家都是一个"未完成的人格系统"。你在场上扮演什么角色，取决于你选择了什么对外身份；而你真正是谁，取决于你内部子人格的排列组合。

最强大的玩家不是从不受伤的人，而是能在碎裂之后、在队友的守护下完成重组的人。

可见属性计算公式

A_visible = A_persona + Σ(αᵢ × Sᵢ)
A_persona：身份卡基础属性 | Sᵢ：第i个槽位的人格能量值 | αᵢ：适配系数
内耗机制
触发条件：理智型 ≥ 2 且 创伤型 ≥ 2 → 触发内耗
负面效果：每回合开始时抽取一张"干扰牌"并当场结算
正面意义：内耗持续 3 回合以上时，解锁"深度整合"选项 → 可触发化茧蜕变
💡 设计隐喻：内部的矛盾与撕裂不是纯粹的坏事。它是成长的信号，是化茧的前置条件。没有内耗，就没有蜕变。

📜 阶段1：事件翻牌

从公共牌堆翻开一张"事件牌"，所有玩家共同面对。

事件牌可能是：资源卡、危机卡、变局卡、空白羊皮纸。

化茧期玩家：事件牌的负面效果强制放大 5 倍。

🎭 阶段2：身份行动

每位玩家按逆时针顺序，选择执行以下行动之一：

🔪 发起质疑：指定一名对手，强制其公开子人格槽位
📦 资源采集：从牌堆抽取1张资源牌
🤫 阵营密语：与同阵营队友暗中信息交换
🐛 宣告化茧：启动内生破茧流程
🃏 打出技能牌：使用手中的技能牌

⚔️ 阶段3：博弈对抗

玩家之间可进行攻击、防御、反击等操作。

D_hit = max(0, A_attacker - D_defender + Δ_event)
Δ_event 为当前事件牌的修正值。

化茧期玩家：D_defender 临时降为 0，D_hit 乘以 Ω = 5。

🧠 阶段4：内省调整

每位玩家暗中重新调整内部子人格槽位排列。

✅ 检查是否触发内耗状态
✅ 消耗品/持续性效果结算
✅ 化茧期玩家：记录已存活回合数
✅ 达到 X 回合 → 完成蜕变！

🐛 化茧蜕变机制 · 核心差异化系统

💡 核心洞察

这是本游戏最核心的差异化机制。它模拟了"从碎裂到重组"的深度人格成长过程。

在化茧期，你的旧身份已死、新身份未生——你处于最脆弱的真空期。
队友的守护，是你能撑过去的唯一希望。
化茧前置条件
条件说明
1️⃣ 内耗状态内部人格冲突至少持续 3 回合
2️⃣ 有存活队友至少 1 名同阵营队友存活
3️⃣ 行动点储备手中持有至少 5 个行动点作为"茧的能量"
4️⃣ 扣置身份卡宣告后，将当前对外身份卡扣置，进入"无防备缝合状态"
化茧状态规则

⚠️ 负面放大效应

D_real = D_base × Ω   (Ω = 5, 即 500%)
任何来自对手的常规试探、质疑、甚至正常波动，造成的负面效果强制放大 5 倍。
即便原本仅 1 点伤害，也会变成 5 点致命重创。

⏳ 脆弱期持续时长

化茧持续 X = 3 回合
（若身份为"萌芽者"则 X = 2 回合）

🛡️ 对外防御力降为 0（身份卡已扣置）
🚫 不能主动发起攻击或质疑
💛 只能被动承受或接受队友保护

⚡ 行动调度策略
每回合行动点 = 3 + 主导意识加成。理智型主导时4点，其余3点。策略核心：不是选"最强的2个"，而是选"活跃技能+休眠被动"组合最优的那对。

行动效能最优化

T = max { Σ(i∈S) Uᵢ + Σ(i∈S, j∉S) βᵢⱼ · Eⱼ }
S 为激活集合(|S|=k)，Uᵢ 为行动效能，βᵢⱼ 为休眠意识对活跃意识的被动支援系数，Eⱼ 为休眠意识当前能量。
