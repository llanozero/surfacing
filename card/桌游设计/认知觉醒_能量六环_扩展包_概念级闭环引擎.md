# 《认知觉醒：能量六环》扩展包：概念级闭环引擎

> **扩展定位**：高难度进阶规则，适用于已熟悉基础版的玩家
> **核心变革**：能量不再是每回合固定消耗/恢复，而是由**任务完成效果的留存结算**驱动
> **设计理念**：将"信息-能量-行动"的闭环流通逻辑完整注入桌游，让"做得好"产生正向能量飞轮，"做得差"陷入能量枯竭螺旋

---

## 一、扩展核心规则：能量动态引擎

### 1.1 基础版 vs 扩展版对比

| 维度 | 基础版（固定能量） | 扩展版（动态能量） |
|------|-------------------|-------------------|
| 能量恢复 | 睡眠阶段按领域等级固定恢复 | 由**上一轮各阶段完成质量**决定恢复量 |
| 能量消耗 | 卡牌标注固定消耗值 | 消耗值随**任务匹配度**浮动 |
| 信息碎片 | 固定发放或归档回收 | 由**阶段间流通效率**产生 |
| 精神噪音 | 未处理自动转化 | 由**流通断裂**产生 |
| 核心体验 | 稳定但可预测 | 不可预测，高度依赖闭环质量 |

### 1.2 核心变革：能量来源不再是"时间"，而是"行为质量"

$$E_{next\_round} = f(\text{Closure Quality}) = \sum_{i=1}^{6} Q_i \cdot W_i$$

> 其中 $Q_i$ 为第 $i$ 阶段的完成质量评分（0-2），$W_i$ 为该阶段的权重系数。
> **做得好的阶段产生能量盈余，做得差的阶段产生能量负债。**

## 二、六阶段动态能量结算系统

### 2.1 阶段质量评分机制

每个阶段结束时，根据该阶段的**流通完整度**进行质量评分：

| 评分 | 含义 | 条件 |
|------|------|------|
| **2分（完美流通）** | 阶段目标超额完成，产出溢出 | 所有允许操作执行完毕 + 有额外产出 |
| **1分（基础完成）** | 阶段目标基本达成 | 执行了核心操作，无明显失误 |
| **0分（流通断裂）** | 阶段目标未完成或产生负面后果 | 关键操作缺失、产生噪音、违规等 |

---

### 阶段一：睡眠阶段 —— 离线整合（后台编译期）

#### 能量恢复规则（替代固定恢复）

**不再固定恢复，改为"编译产出结算"：**

$$E_{recover} = Base_{sleep} \cdot (1 + B_{seed}) - Penalty_{noise}$$

| 变量 | 说明 | 计算方式 |
|------|------|----------|
| $Base_{sleep}$ | 基础恢复值 | 由 Are 领域被动卡等级决定（Lv1=2, Lv2=3, Lv3=4） |
| $B_{seed}$ | 种子卡编译奖金 | 上一轮睡眠阶段暗置的种子卡，若本轮成功孵化（翻开后转化为有效行动），则 $B_{seed} = 0.5$；否则 $B_{seed} = 0$ |
| $Penalty_{noise}$ | 噪音惩罚 | GTD收集箱中残留的噪音卡数量 × 1（能量恢复被噪音"吃掉"） |

**关键变化：**
- 基础恢复值 $Base_{sleep}$ 不再是"无条件获得"——它会被噪音直接吞噬
- 种子卡孵化成功有额外 50% 恢复加成，形成"睡得好→灵感多→能量足"的正向飞轮
- 如果上一轮噪音堆积过多，可能出现 $E_{recover} \le 0$ 的极端情况（系统崩溃级失眠）

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | 暗置2张种子卡 + GTD收集箱完全清空（零噪音） |
| **1分** | 暗置1-2张种子卡 或 GTD收集箱有少量噪音但已控制 |
| **0分** | 未暗置任何种子卡 且 GTD收集箱残留噪音 ≥ 3张 |

### 阶段二：规划阶段 —— 建立地图（启动与调度期）

#### 能量调度规则（替代固定消耗）

**核心机制："能量-任务匹配度"决定实际消耗**

规划阶段的核心操作是"能量锚定"——将能量标记放在执行清单的卡牌上。在扩展版中，**锚定的匹配质量直接影响实际消耗量**：

**任务-能量匹配矩阵：**

| 任务标签 | 最佳匹配能量阶段 | 匹配消耗系数 | 错配消耗系数 |
|----------|-----------------|-------------|-------------|
| [高算力] 写核心逻辑、复杂决策 | 专注阶段（🔴） | ×1.0 | ×1.5（如果在协作阶段执行） |
| [社交型] 开会、沟通、发布 | 协作阶段（🟡） | ×1.0 | ×1.5（如果在专注阶段执行） |
| [机械型] 整理文件、归档 | 修复阶段（🔵） | ×0.5 | ×1.0 |
| [深度反思] 复盘、提纯 | 投资阶段（🟣） | ×1.0 | ×1.5 |

**关键公式：**

$$Cost_{actual} = Cost_{base} \cdot Match_{coefficient}$$

> **匹配执行**（任务标签与当前阶段对应）：消耗 1.0 倍基础消耗
> **错配执行**（任务标签与当前阶段不对应）：消耗 1.5 倍基础消耗（高算力任务在社交阶段做，效率极差）
> **低能任务在修复阶段**：享受 0.5 倍消耗折扣（垃圾回收本身就是低能耗）

#### PARAs上下文供给奖金

规划阶段执行"动作转化"时，如果 PARA 中已有对应信息上下文：

| PARA供给情况 | 转化效率 |
|-------------|---------|
| P槽有对应项目卡 + R槽有对应工具卡 | 转化消耗 -1⚪（信息充分，转化成本极低） |
| 仅有P槽项目卡，无R槽工具支撑 | 转化消耗正常 |
| 无任何PARA上下文支撑 | 转化消耗 +1⚪（从零建构，成本极高） |

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | 所有收集箱卡牌处理完毕 + 能量-任务完美匹配 + PARA上下文充分调用 |
| **1分** | 大部分卡牌已处理，但存在错配或PARA调用不完整 |
| **0分** | 大量卡牌未处理 或 能量全部错配（规划形同虚设） |

### 阶段三：专注阶段 —— 深度产出（核心计算期）

#### 能量消耗规则（替代固定消耗）

**核心机制："峰值消费"——高专注能量不可分割，必须整块使用**

$$E_{focus\_cost} = \sum_{cards} Cost_{base} \cdot (1 - B_{context})$$

| 变量 | 说明 |
|------|------|
| $Cost_{base}$ | 卡牌标注的基础专注能量消耗 |
| $B_{context}$ | 上下文准备奖金（规划阶段PARA供给是否充分） |

**上下文准备奖金 $B_{context}$：**

| 规划阶段质量评分 | $B_{context}$ | 含义 |
|-----------------|---------------|------|
| 2分（完美规划） | 0.2 | 规划做得好，专注时省力20% |
| 1分（基本规划） | 0.1 | 规划一般，略有省力 |
| 0分（规划缺失） | 0 | 没有规划，专注阶段全消耗 |

**防壁机制升级版——"分心的连锁反应"：**

专注阶段的"分心"不再是简单的"扣1点能量"，而是**连锁反应**：

1. 第一次分心：丢弃1张正在执行的行动卡（进度丢失） + 该卡已消耗的🔴能量**不退还**
2. 第二次分心：额外将1张已产出的成果卡降级为半成品
3. 第三次分心：直接触发 Burnout

> **设计意图**：专注阶段的"分心"成本极高，因为你不只是浪费了能量，还浪费了已经投入的时间成本（沉没成本效应）。

#### 产出效率公式

$$Output_{focus} = \sum_{cards} Base_{output} \cdot (1 + E_{reserve\_bonus})$$

| 变量 | 说明 |
|------|------|
| $Base_{output}$ | 卡牌标注的基础产出 |
| $E_{reserve\_bonus}$ | 能量储备奖金：若执行完所有卡牌后仍剩余🔴≥2，则产出+20%（精力充沛时产出质量更高） |

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | 所有计划卡牌执行完毕 + 零分心 + 有额外产出（超额完成） |
| **1分** | 大部分卡牌执行完毕，分心≤1次 |
| **0分** | 大量卡牌未完成 或 分心≥2次 |

### 阶段四：修复阶段 —— 系统清空（垃圾回收与内存释放期）

#### 能量规则（低损耗充电）

**核心机制："清空质量"决定下午的社交能量基数**

$$E_{social\_afternoon} = E_{social\_base} + B_{cleanup} - L_{residual}$$

| 变量 | 说明 | 计算方式 |
|------|------|----------|
| $E_{social\_base}$ | 社交能量基础值 | Are领域等级（Lv1=1, Lv2=2, Lv3=2） |
| $B_{cleanup}$ | 清空奖金 | 若GTD临时收集箱完全清空，+1🟡 |
| $L_{residual}$ | 残留损耗 | 修复阶段结束时GTD中仍有未处理卡牌，每张 -0.5🟡 |

**关键洞察**：修复阶段本身不消耗能量，但它的**完成质量**直接决定你下午有多少社交能量可用。如果中午没把垃圾清理干净，下午的社交状态必然打折。

#### "两分钟规则"机制化

修复阶段可执行"两分钟卡"（卡面标注 `[2min]` 标签的机械性杂务）：

| 操作 | 效果 |
|------|------|
| 执行1张 `[2min]` 卡 | 免费清除1⚫噪音（不消耗🔵） |
| 执行2张 `[2min]` 卡 | 额外从弃牌堆回收1张⚪信息碎片 |
| 执行3张以上 | 不再额外收益（边际递减） |

> **设计意图**：还原真实生活中"花两分钟处理杂务"的高效感。快速清理小事务，能为下午释放大量认知带宽。

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | GTD完全清空 + 成果全部落锁 + 执行了≥2张两分钟卡 |
| **1分** | GTD基本清空，成果已落锁 |
| **0分** | GTD仍有大量未处理卡牌，成果未落锁 |

### 阶段五：协作阶段 —— 验证表达（输入输出交互期）

#### 能量消耗规则（社交能量动态消耗）

**核心机制："验证质量"决定反馈回报量**

协作阶段是**唯一能产生外部反馈的阶段**。社交能量的消耗不是固定的，而是取决于"你抛出了什么"：

$$Cost_{social} = Base_{cost} \cdot (1 - Q_{output})$$

| 变量 | 说明 |
|------|------|
| $Base_{cost}$ | 基础社交消耗（通常为1🟡） |
| $Q_{output}$ | 上一阶段（专注阶段）产出的质量评分 |

**关键联动**：

| 专注阶段质量 | $Q_{output}$ | 社交消耗系数 | 含义 |
|-------------|-------------|-------------|------|
| 2分（高质量产出） | 0.3 | ×0.7 | 有好东西拿出去，社交成本低（别人愿意听） |
| 1分（普通产出） | 0.1 | ×0.9 | 一般般，社交成本正常 |
| 0分（无产出/低质量） | 0 | ×1.0 | 没有干货还要硬社交，成本全价甚至更高 |

**反馈回报公式：**

$$Feedback_{return} = Base_{feedback} \cdot Match_{quality} \cdot (1 + N_{partner})$$

| 变量 | 说明 |
|------|------|
| $Base_{feedback}$ | 成果卡标注的基础反馈值 |
| $Match_{quality}$ | 成果与交易对象的匹配度（匹配=1.5，不匹配=0.5） |
| $N_{partner}$ | 交易伙伴数量奖金（每多一位 +0.2，上限+0.6） |

> **设计意图**：专注阶段做得好 → 协作阶段"有底气"，社交成本低且反馈回报高。形成"上午深度产出 → 下午高效社交"的真实节律。

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | 完成≥2笔交易 + 反馈收集箱满载 + 社交能量有结余 |
| **1分** | 完成1笔交易 或 反馈收集箱有部分收益 |
| **0分** | 零交易 或 社交能量全部耗尽且无反馈收获 |

### 阶段六：投资阶段 —— 解构升维（迭代与升级期）

#### 能量规则（深度反思 → 永久资产转化）

**核心机制："提纯效率"决定认知精粹的产量**

投资阶段是整个闭环的**价值萃取点**。它不消耗能量，而是**将前五个阶段的所有流通成果，转化为永久性资产**。

**认知精粹产量公式：**

$$\Delta P_{crystal} = \sum_{feedback} Value_{feedback} \cdot Q_{analysis} + B_{archive}$$

| 变量 | 说明 |
|------|------|
| $Value_{feedback}$ | 每张反馈卡的基础价值 |
| $Q_{analysis}$ | 协作阶段质量评分的映射值（2分=1.5, 1分=1.0, 0分=0.5） |
| $B_{archive}$ | 归档奖金：每归档1张已完成项目卡，额外+1🟣 |

**"提纯"操作的三步流程：**

| 步骤 | 操作 | 效果 |
|------|------|------|
| 1. 解构 | 将反馈卡分为"事实""观点""情绪"三类 | "事实"类保留为有效价值；"情绪"类转化为⚫噪音（如果未处理） |
| 2. 提纯 | 消耗2🟣，升级 Are 领域被动卡1级 | 永久提升基础恢复值和被动效果 |
| 3. 归档 | 将P槽已完成项目移入Arc归档区 | 获得卡面VP + 归档奖金🟣 |

**未处理反馈的惩罚（流通断裂）：**

阶段结束时，反馈收集箱中仍有未分类的反馈卡 → 每张自动转化为1⚫噪音进入GTD收集箱。

> **设计意图**：投资阶段的本质是"从经历中提取智慧"。如果你不认真复盘（解构反馈），那些经历就会变成噪音堆积在你脑子里。

#### 阶段质量评分标准

| 评分 | 条件 |
|------|------|
| **2分** | 所有反馈完成解构 + 完成≥1次领域升级 + 归档≥1张项目卡 |
| **1分** | 大部分反馈已解构，但升级或归档未完成 |
| **0分** | 大量反馈未处理（转化为噪音） |

## 三、闭环联动：六阶段连锁反应总览

### 3.1 正向飞轮（做得好的连锁反应）

```
睡眠(清空大脑) → 规划(能量-任务完美匹配) → 专注(高产出+零分心)
    ↑                                              ↓
投资(永久升级+归档) ← 协作(高回报社交) ← 修复(彻底清空)
    ↓
下一轮睡眠：更高的基础恢复值 + 零噪音惩罚 + 种子卡孵化奖金
    ↓
正循环加速！每轮的能量池越来越大，可做的高级操作越来越多
```

### 3.2 负向螺旋（做得差的连锁反应）

```
睡眠(噪音残留→能量减半) → 规划(错配→消耗×1.5) → 专注(准备不足→全消耗+分心)
    ↑                                                        ↓
投资(反馈未处理→变噪音) ← 协作(无产出→社交成本高+零回报) ← 修复(没清空→社交能量打折)
    ↓
下一轮睡眠：更高噪音惩罚 + 更低基础恢复 + 无种子卡奖金
    ↓
负循环加速！每轮能量池越来越小，陷入"想做但做不动"的死局
```

### 3.3 阶段间能量传导公式总表

| 传导路径 | 公式 | 含义 |
|----------|------|------|
| 睡眠 → 规划 | $E_{available} = E_{recover} + E_{carry\_over}$ | 睡眠恢复量决定规划阶段可用能量池 |
| 规划 → 专注 | $Cost_{focus} = Cost_{base} \cdot (1 - B_{context})$ | 规划质量影响专注消耗效率 |
| 专注 → 修复 | $E_{social\_pm} = E_{base} + B_{cleanup} - L_{residual}$ | 修复清空质量决定下午社交能量 |
| 修复 → 协作 | $Cost_{social} = Base \cdot (1 - Q_{output})$ | 专注产出质量决定社交成本 |
| 协作 → 投资 | $\Delta P = \sum V \cdot Q_{collab} + B_{archive}$ | 协作质量决定提纯效率 |
| 投资 → 睡眠 | $Base_{sleep\_next} = f(Are_{level})$ | 投资升级决定下轮基础恢复 |

## 四、新增机制：信息流通货币系统

### 4.1 "流通效率"作为隐藏资源

扩展版引入**信息流通效率**作为隐藏评分维度，贯穿全局：

$$Efficiency_{flow} = \frac{\text{本轮成功流通的信息卡总数}}{\text{本轮进入系统的所有信息卡总数}}$$

| 流通效率 | 评级 | 全局效果 |
|----------|------|----------|
| ≥ 90% | S级（完美闭环） | 下轮所有阶段质量评分+1（上限2） |
| 70%-89% | A级（高效运转） | 下轮信息碎片获取+2 |
| 50%-69% | B级（基本运转） | 无额外效果 |
| 30%-49% | C级（流通不畅） | 下轮所有能量恢复-1 |
| < 30% | D级（系统瘫痪） | 下轮强制进入Burnout状态 |

### 4.2 "信息碎片"的动态来源

在扩展版中，信息碎片（⚪）的来源完全动态化：

| 来源 | 条件 | 数量 |
|------|------|------|
| 专注阶段超额产出 | 专注阶段评分=2 | +3⚪ |
| 协作阶段交易成功 | 每笔成功交易 | +1⚪ |
| 投资阶段归档 | 每归档1张项目卡 | +2⚪ |
| 修复阶段两分钟卡 | 执行≥2张 | +1⚪ |
| PARA上下文被调用 | 规划阶段调用完整PARA | +1⚪ |

> **设计意图**：信息碎片不再是"天上掉下来的"，而是你**高效流通**的副产品。做得越好，获得的"原料"越多，形成正向循环。

## 五、新增卡牌：闭环增强卡

### 5.1 "能量匹配"系列卡

## 八、扩展版核心体验总结

### 8.1 与基础版的本质差异

| 维度 | 基础版体验 | 扩展版体验 |
|------|-----------|-----------|
| 能量感知 | "我有多少能量可用？" | "我上一轮做得好不好，决定了我这一轮有多少能量" |
| 策略重心 | 如何在固定资源下最优分配 | 如何通过提升闭环质量来**创造更多资源** |
| 阶段关联 | 各阶段相对独立 | **六个阶段形成因果链**，上一阶段的质量直接影响下一阶段 |
| 失败体验 | "资源不够用了" | "我的系统在某处断裂了，导致了连锁崩塌" |
| 成功体验 | "我高效地完成了任务" | "我的整个认知引擎在完美运转，飞轮越转越快" |

### 8.2 设计理念收束

> **"顺势而为"** —— 顺着人体的能量节律，顺着信息的流动规律，顺着认知的成长逻辑。
>
> 扩展版的本质不是"更难"，而是**更真实**。它模拟的不是一个简化的资源管理游戏，而是一个"人如何在六个阶段中让信息、能量、行动像水流一样自然流通"的完整系统。
>
> 当你真正理解了每个概念的本质，你就可以灵活调整——让这个闭环为你所用，而不是你为闭环服务。
