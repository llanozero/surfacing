# 《认知觉醒：能量六环》桌游规则 v0.9（磋商稿）

> **游戏类型**：引擎构筑（Engine Building）+ 资源管理（Resource Management）+ 严格阶段限制（Phase-Constrained）重度策略桌游
> **玩家人数**：2-4人（建议）
> **单局时长**：约 90-120 分钟
> **设计理念**：将 GTD + PARA + 能量六环 转化为一套可游玩的桌面游戏

---

## 一、核心组件与术语定义（Terminology）

### 1.1 玩家个人面板：PARA 认知图谱

每个玩家拥有一个四槽个人面板，代表 PARA 存储器：

| 槽位 | 名称 | 功能 | 存放内容 |
|------|------|------|----------|
| **P 槽** | 项目仓（Projects） | 当前正在执行的任务 | 有明确截止轮次的"项目卡" |
| **Are 槽** | 领域池（Areas） | 基础能力被动 | "领域被动卡"（1-3级），提供持续 Buff |
| **R 槽** | 资源库（Resources） | 可消耗素材 | "素材卡 / 工具卡"，特定阶段消耗以加成产出 |
| **Arc 槽** | 归档区（Archives） | 已结算成果 | 已完成的项目卡，作为最终胜利分（VP）计分堆 |

### 1.2 核心资源指示物

| 资源 | 颜色 | 用途 | 恢复方式 |
|------|------|------|----------|
| **专注能量** | 🔴 红 | 高算力核心资源，驱动专注阶段 | 睡眠阶段按健康指数恢复 |
| **社交能量** | 🟡 黄 | 交互核心资源，驱动协作阶段 | 睡眠阶段按健康指数恢复 |
| **修复资源** | 🔵 蓝 | 清空异常状态，驱动修复阶段 | 每轮固定发放少量 |
| **信息碎片** | ⚪ 白 | 基础卡牌原料，用于转化行动卡 | 【待补充：来源机制】 |
| **精神噪音** | ⚫ 黑 | 负面资源，堆积扣分/导致卡顿 | 修复阶段消耗蓝资源清除 |

> **【磋商点 #3】** 信息碎片（白）的获取来源尚未明确。建议方案：
> - 方案A：每轮开始时从公共牌堆按固定数量发放
> - 方案B：从归档区已完成项目中回收（形成正反馈循环）
> - 方案C：两者结合

### 1.3 玩家流转库：GTD 调度中心

| 组件 | 功能 |
|------|------|
| **GTD 收集箱** | 玩家的抽牌堆和临时置牌区。所有未处理的外部事件、灵感、噪音先进入此区 |
| **执行清单** | 规划阶段完成后，本轮确定要执行的卡牌队列 |

### 1.4 卡牌类型标签

> **【磋商点 #2】** 建议为所有卡牌定义统一类型标签，明确流转路径。

| 卡牌类型 | 标签 | 说明 |
|----------|------|------|
| 信息卡 | `[素材]` | 模糊的原始信息，需规划阶段转化为行动卡 |
| 行动卡 | `[行动]` | 有明确消耗和产出的可执行卡牌 |
| 成果卡 | `[成果]` | 专注阶段产出的半成品或完成品 |
| 灵感卡 | `[灵感]` | 睡眠阶段从潜意识孵化堆盲抽获得 |
| 外部反馈卡 | `[反馈]` | 协作阶段获得的外部评价，投资阶段解构 |
| 噪音卡 | `[负面]` | 未及时处理的事务自动转化，扣分 |
| 事件卡 | `[事件]` | 公共牌堆翻出的全局事件，影响所有玩家 |
| 领域被动卡 | `[被动]` | Are槽专属，提供持续属性加成 |

### 1.5 卡牌流转路径图

```
公共牌堆 ──→ GTD收集箱 ──→(规划阶段)──→ 执行清单 ──→(专注阶段)──→ P槽待整理区
                ↑                                                    │
                │                                                    ↓
          外部事件/噪音                                        成果卡/半成品
                ↑                                                    │
          (专注阶段丢弃)                                      (修复阶段落锁)
                                                                       ↓
                                                              P槽正式存放
                                                                       │
                                                              (投资阶段归档)
                                                                       ↓
                                                                  Arc归档区
```

## 二、游戏胜负条件

### 2.1 游戏结束触发

满足以下任一条件时游戏结束：

1. **轮次耗尽**：游戏进行到指定轮次（建议：6-8轮，对应6-8天）
2. **满级触发**：任一玩家的【Are 槽：领域池】全部升级至最高等级（3级）

### 2.2 计分规则

| 计分项 | 得分 |
|--------|------|
| Arc 归档区中每张已完成项目卡 | 按卡面标注 VP |
| Are 领域池每级等级 | +3 VP / 级 |
| GTD 收集箱中每张残留噪音卡 | -2 VP |
| 额外：未使用的能量指示物 | 不计分 |

得分最高者获胜。平局时，比较 Are 槽总等级；仍平局则比较归档区卡牌数量。

## 三、六大阶段游戏规则（Phase Rules）

游戏每轮代表一天，严格按照以下六个阶段顺序推移。

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  1. 睡眠阶段 ──→ 2. 规划阶段 ──→ 3. 专注阶段            │
│     (后台编译)      (能量调度)       (深度产出)           │
│        ▲                                │                │
│        │                                ↓                │
│  6. 投资阶段 ←── 5. 协作阶段 ←── 4. 修复阶段            │
│     (解构升维)      (验证表达)       (内存释放)           │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**核心原则**：玩家只能在对应阶段执行被允许的特定操作。违规操作将直接扣除能量或产生噪音。

---

### 阶段一：睡眠阶段（Sleep Phase）—— 离线整合

> **阶段设定**：黑夜阶段。玩家关闭双眼（或将面板翻面），系统进入"后台自动编译"。
> **氛围**：安静、秘密行动。全员同时操作。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【暗置·种子卡】** | 玩家可以指定【P槽】或【R槽】中的最多2张信息卡，秘密面朝下塞入【Are槽：领域池】下方进行"潜意识孵化"。下一轮睡眠阶段结束时翻开 |
| **【能量重置】** | 根据玩家当前的健康指数（领域被动卡加成后），恢复基础的【专注能量🔴】和【社交能量🟡】 |

#### 阶段限制（禁止行为）

- ❌ 禁止打出任何手牌
- ❌ 若上一轮未清空大脑（留有【精神噪音⚫】），此阶段恢复的能量**减半**

> **【磋商点 #11】** 首轮特殊规则：第一轮睡眠阶段没有"上一轮残留噪音"，建议首轮跳过噪音惩罚，从第二轮开始生效。

#### 流通出口

- 从潜意识孵化堆中盲抽1张"灵感卡"，直接面朝下放入【GTD收集箱】

> **【磋商点 #7】** "潜意识孵化"建议统一命名为 **【暗置·种子卡】**，对应桌游中常见的"面朝下放置"机制，玩家一看就懂。

---

### 阶段二：规划阶段（Planning Phase）—— 建立地图

> **阶段设定**：清晨阶段。全员亮牌，玩家开始调度一天的资源，进行"排兵布阵"。
> **氛围**：思考、策略规划。玩家各自操作，可小声讨论但不交易。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【清空收集箱】** | 强制翻开【GTD收集箱】的所有卡牌，公开展示 |
| **【动作转化】** | 消耗极少能量（1⚪），将模糊的信息卡转化为具有明确消耗和产出的"行动卡"，放入【执行清单】 |
| **【能量锚定】** ⭐ | **核心操作！** 玩家必须将本轮拥有的能量标记（🔴/🟡），预先放置在【执行清单】的卡牌上。锚定后不可更改 |

#### 阶段限制（禁止行为）

- ❌ 禁止在此时执行卡牌效果（不能进行生产或攻击/防御）
- ❌ 禁止调取未经规划的【R槽】资源

#### 流通出口

- 形成一份带有能量标记的【当日执行清单】

> **【磋商点补充】** 未使用的锚定能量是否回收？建议：未使用的能量在投资阶段结束时回收（不跨轮保留），但已锚定但未执行的卡牌效果作废。

---

### 阶段三：专注阶段（Focus Phase）—— 深度产出

> **阶段设定**：上午阶段。高能计算期，玩家处于"绝对防壁"状态。
> **氛围**：全员禁言！只能听到沙漏的声音。谁说话谁拿【噪音卡】。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【硬核产出】** | 玩家只能执行【执行清单】中锚定了【专注能量🔴】的卡牌。通过消耗红色能量，将【P槽】中的项目进度向前推进，或将信息碎片加工为"成果卡" |

#### 阶段限制（禁止行为）

- ❌ 禁止执行任何带有"社交""沟通"标签的卡牌
- ❌ 禁止阅读或讨论任何卡牌内容（全员禁言）

#### 防壁机制 ⚡

此阶段若场上触发"突发外部事件卡"，玩家**不得阅读卡牌内容**，必须立刻将其直接丢入【GTD临时收集箱】。否则视作"分心"，直接扣除1点专注能量。

> **【磋商点 #4】** 突发外部事件卡的触发源需要明确。建议方案：
> - **方案A（系统驱动）**：每轮专注阶段开始时，从公共事件牌堆翻1张，所有玩家同时面对。符合规则的玩家可丢弃，不符合的强制进入收集箱
> - **方案B（玩家对抗）**：其他玩家可以在专注阶段"投放"干扰卡（消耗自身🟡社交能量1点），被投放者必须立即丢弃或分心
> - 推荐：**方案A+B结合**——固定翻1张系统事件 + 每位其他玩家限投1张干扰

#### 流通出口

- 产生的"半成品/成果卡"进入P槽待整理区

---

### 阶段四：修复阶段（Recovery Phase）—— 系统清空

> **阶段设定**：中午阶段。垃圾回收与内存释放。
> **氛围**：放松、整理。允许小声交流，但不进行交易。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【内存释放】** | 消耗【修复资源🔵】，强制丢弃在专注阶段堆积的【精神噪音⚫】。每张噪音消耗1🔵 |
| **【轻量处理】** | 允许执行【执行清单】中注明"耗时<2分钟"或"0能量消耗"的机械性杂务卡（如：补牌、微调面板位置） |
| **【成果落锁】** | 将专注阶段产出的卡牌，正式整齐地排入【P槽】 |
| **【记忆整理】** 🆕 | 将R槽中2张资源卡交换位置，或从弃牌堆回收1张资源卡 |

> **【磋商点 #6】** 新增"记忆整理"操作，给修复阶段一个"主动建设"的选项，避免节奏塌陷。

#### 阶段限制（禁止行为）

- ❌ 禁止执行任何需要消耗【专注能量🔴】的卡牌
- ❌ 禁止进行玩家间的交易或谈判

#### 流通出口

- 玩家工作记忆清空，个人面板处于整洁状态

---

### 阶段五：协作阶段（Collaboration Phase）—— 验证表达

> **阶段设定**：下午阶段。打破防壁，玩家之间、玩家与世界交互的公共阶段。
> **氛围**：像狼人杀白天发言！激烈的谈判、交易和嘴炮。利用社交能量击败对手。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【成果外抛】** | 玩家打出锚定了【社交能量🟡】的卡牌，向中央市场或特定玩家展示、贩卖自己的"成果卡"，赚取金钱、声望或胜利分（VP） |
| **【信息吸纳】** | 与其他玩家进行资源交易、结盟，或从公共牌堆抽取大量"外部反馈卡" |
| **【口头承诺】** | 玩家之间可以达成交易协议（但无强制约束力，下一轮可反悔，反悔产生1⚫噪音） |

#### 阶段限制（禁止行为）

- ❌ 禁止独自闭门造车，所有卡牌结算必须包含"交互"或"对外交付"属性
- ❌ 禁止保留未交互的成果卡（必须尝试外抛或放入公共市场）

#### 流通出口

- 赚取的资源进入临时缓存
- 换回的大量"外部反馈卡"推入反馈收集箱

> **【磋商点补充】** 中央市场的定价机制建议：
> - 每张成果卡有基础售价（卡面标注）
> - 向特定玩家交易时，价格由双方口头协商
> - 向"中央市场"出售时，按基础售价的80%结算（有中间商差价）

---

### 阶段六：投资阶段（Investment Phase）—— 解构升维

> **阶段设定**：傍晚阶段。复盘与系统大升级，决定玩家长期强弱的胜负手。
> **氛围**：安静反思。各自操作，不交流。

#### 允许的操作

| 操作名称 | 说明 |
|----------|------|
| **【解构反馈】** | 将协作阶段收到的"外部反馈卡"分类拆解，剔除情绪，提取"认知精粹"（紫色指示物🟣） |
| **【提纯增殖】** | 消耗认知精粹🟣，永久升级【Are槽：领域池】中的卡牌。升级后常驻属性永久提升 |
| **【归档沉淀】** | 将【P槽】中已完成的项目卡移入【Arc槽：归档区】，转化为最终VP；将不再需要的资源移入垃圾堆 |

#### 阶段限制（禁止行为）

- ❌ 禁止再向外部世界交付任何成果
- ❌ 禁止保留未结算的临时反馈卡（未处理的反馈在阶段结束时自动转化为【精神噪音⚫】进入收集箱）

#### 流通出口

- 升级后的 PARA 系统与清理完毕的 GTD 清单，直接对接下一轮的【睡眠阶段】
- 未使用的能量指示物回收（不跨轮保留）

> **【磋商点 #8】** "认知精粹"建议定义为紫色指示物🟣（而非卡牌），与五种基础资源在视觉上一致，避免"卡牌中嵌套卡牌"的混乱。

## 四、特殊机制

### 4.1 Burnout（职业倦怠）惩罚机制 ⚠️

如果玩家满足以下任一条件，进入"Burnout"状态：

- 单轮内分心2次（专注阶段违规）
- 🔴红能量和🟡黄能量同时归零

**Burnout 效果**：强制跳过**下一轮的专注阶段和协作阶段**，只能在修复阶段"摆烂"摸鱼。

> **【磋商点 #5】** 原版为"连续两轮分心"，建议调整为"单轮2次分心"或"双色能量同时归零"，惩罚触发更及时。持续时间从整轮缩短为半个轮次（仅跳过专注+协作），惩罚更精准。

### 4.2 狼人杀式阶段监督 🐺

- **专注阶段**：全员禁言，只能听到沙漏的声音。谁说话谁拿【噪音卡⚫】
- **协作阶段**：像狼人杀白天发言一样，激烈谈判、交易和嘴炮
- **睡眠阶段**：秘密行动，不得偷看他人面板

### 4.3 每日目标卡（可选规则）🎯

每轮开始时从"目标牌堆"翻1张公共目标卡，所有玩家可竞争完成：

> 示例：
> - "本轮专注阶段产出3张成果卡 → 额外+2VP"
> - "本轮协作阶段完成2笔交易 → 额外获得2🔵"
> - "本轮零噪音通关 → 额外+3VP"

增加每轮变化性和重玩价值。
