# 涌现引擎：用户输入 → 知识库匹配 → 锦囊路径生成

## 概述

当用户输入一段文字时，认知卡片系统通过 LLM + 语料库联动，自动匹配相关卡片、细化语料风格、涌现可用的锦囊路径引导词。整个过程不需要用户手动选择卡片或锦囊——系统在语义层完成匹配，用户只感知到"被理解"和"被引导"。

---

## 1. 整体流程

```
用户输入
    │
    ▼
┌─ 阶段一：语义匹配 ──────────────────────────────┐
│  LLM 将用户输入向量化 → 匹配最相关的认知卡片     │
│  输出：匹配的卡片 ID + 置信度                     │
└──────────────────────────────────────────────────┘
    │
    ▼
┌─ 阶段二：语料库细化 ────────────────────────────┐
│  在匹配卡片的语料库中按语义/关键词精筛           │
│  输出：细化的语料条目子集（风格+关键词已对齐）    │
└──────────────────────────────────────────────────┘
    │
    ▼
┌─ 阶段三：锦囊路径涌现 ──────────────────────────┐
│  LLM 基于细化语料 + 锦囊定义 → 生成引导词        │
│  输出：可用锦囊路径 + 具身引导词                  │
└──────────────────────────────────────────────────┘
    │
    ▼
用户看到：当前状态匹配的认知卡片 + 可用的锦囊路径 + 引导词
```

---

## 2. 阶段一：语义匹配

### 2.1 输入

```json
{
  "user_input": {
    "text": "最近总是设定目标又拖延，每次开始前都觉得自己准备不够，越准备越焦虑。",
    "source": "chat",       // chat | note | reflection
    "timestamp": "2026-07-22T10:30:00Z"
  }
}
```

### 2.2 匹配方式

支持两种匹配策略，可配置切换：

**策略 A：LLM 语义匹配（默认）**

```
LLM 提示词模板：
"""
你是一个认知卡片匹配引擎。用户的输入是：

"{user_input}"

请从以下认知卡片中选出最相关的 1-3 张，按相关度排序。
每张卡片请给出：
- card_id
- 匹配理由（为什么这张卡片与用户当前状态相关）
- 置信度评分（0-1）

卡片列表：
{cards_metadata}
"""

输出格式：
[
  {"card_id": "card_05", "reason": "用户描述的是设定目标后无法进入执行状态，属于合拍飞轮的启动问题", "confidence": 0.92},
  {"card_id": "card_10", "reason": "用户说'准备不够'，反映了对理想前置条件的执着，属于重新定向能量的场景", "confidence": 0.78}
]
```

**策略 B：向量检索匹配**

```
用户输入向量化（通过 EmbeddingProvider）
→ 与所有卡片的关键词向量做余弦相似度
→ 返回 Top-3 卡片
→ LLM 对 Top-3 做最终排序和理由生成
```

### 2.3 匹配依据

LLM 在判断关联性时考虑以下维度：

| 维度 | 说明 | 示例匹配 |
|------|------|----------|
| 情绪状态 | 用户的情绪基调 | 焦虑 → Card 05（飞轮启动）/ Card 10（重新定向） |
| 行为模式 | 用户描述的行为循环 | "越准备越焦虑" → Card 01（二阶观察者困境） |
| 认知阶段 | 用户处于设计者/执行者/迷失 | "开始前准备很久" → 设计者心态过重 |
| 关键词命中 | 匹配卡片的关键词列表 | "拖延" → Card 05 "预热过渡" |
| 历史上下文 | 该用户之前的记录 | 上次匹配过 Card 01，可能在同一循环中 |

### 2.4 输出

```json
{
  "matching_result": {
    "primary_card": {
      "card_id": "card_05",
      "title": "合拍飞轮",
      "confidence": 0.92,
      "match_reason": "用户描述的是设定目标后无法进入执行状态，属于合拍飞轮的启动问题"
    },
    "secondary_cards": [
      {
        "card_id": "card_10",
        "title": "重新定向能量",
        "confidence": 0.78,
        "match_reason": "用户对'准备不够'的执着反映了对理想前置条件的要求"
      }
    ],
    "user_state_analysis": {
      "dominant_mindset": "设计者心态",
      "cycle_position": "在执行者入口处受阻",
      "risk_signals": ["过度准备", "拖延启动"]
    }
  }
}
```

## 3. 阶段二：语料库细化

### 3.1 输入

阶段一的 `matching_result` + 对应卡片的完整语料库。

### 3.2 细化流程

```
用户输入特征提取：
  - 情绪关键词: ["焦虑", "拖延"]
  - 行为关键词: ["设定目标", "准备", "开始"]
  - 风格倾向: 用户输入偏"叙事/内省"
    │
    ▼
语料库过滤（按 match_keywords 粗筛）:
  corpus_card_05.entries
    → 命中 "启动" 的条目: 3 条
    → 命中 "过渡" 的条目: 2 条
    → 命中 "焦虑" 的条目: 1 条
    │
    ▼
风格对齐（按 style_tags 精筛）:
  用户输入风格 → "叙事_内省"
  语料 style_tags 匹配:
    "诗意_温和" → match 0.7
    "清晰_克制" → match 0.3
    "学术_严谨" → match 0.1
    │
    ▼
输出: 细化后的语料子集（按综合评分排序）
```

### 3.3 综合评分公式

```
final_score = quality_score × 0.4
            + style_match_score × 0.3
            + keyword_match_count / max_keyword_count × 0.3
```

### 3.4 输出

```json
{
  "refined_corpus": {
    "card_id": "card_05",
    "card_title": "合拍飞轮",
    "user_style_profile": "叙事_内省",
    "entries": [
      {
        "id": "corpus_05_003",
        "content": "飞轮启动前最安静的时刻，恰恰是最需要信任的时刻。你不需要推动它——你只需要把手放在上面。",
        "style_tags": ["诗意_温和", "简洁"],
        "match_keywords": ["启动", "信任", "阻力"],
        "final_score": 0.87,
        "annotation": "适合安抚过度准备阶段的焦虑，用温和意象降低启动门槛"
      },
      {
        "id": "corpus_05_001",
        "content": "每一次预热都不是浪费，而是在告诉你的神经系统：安全了，可以开始了。",
        "style_tags": ["温暖", "清晰"],
        "match_keywords": ["预热", "过渡", "开始", "安全"],
        "final_score": 0.82,
        "annotation": "将预热重新定义为神经系统信号，而非时间浪费"
      }
    ]
  }
}
```

## 4. 阶段三：锦囊路径涌现

### 4.1 什么是"涌现"

涌现不是"从数据库里选一条固定的锦囊"，而是 **LLM 基于细化语料 + 锦囊结构，实时生成贴合当前用户的引导词**。

固定的锦囊定义提供骨架（触发条件、机制说明），细化语料提供血肉（文笔、意象、风格），LLM 将两者融合为一段**此刻可用**的引导词。

### 4.2 涌现流程

```
阶段二的 refined_corpus
    + 锦囊定义库（骨架）
    │
    ▼
LLM 涌现生成：
"""
你是一个认知引导词生成器。基于以下信息，为用户生成一段锦囊引导词。

用户状态分析：
- 当前心态：设计者心态（过度准备）
- 循环位置：在执行者入口处受阻
- 核心障碍：越准备越焦虑

匹配的认知卡片：Card 05 "合拍飞轮"
核心洞察：工具的任务是创建进入飞轮的入口，而非维持飞轮本身。

细化的语料条目（风格参考）：
1. "飞轮启动前最安静的时刻，恰恰是最需要信任的时刻。你不需要推动它——你只需要把手放在上面。"（诗意_温和）
2. "每一次预热都不是浪费，而是在告诉你的神经系统：安全了，可以开始了。"（温暖_清晰）

请生成：
1. 推荐使用的锦囊 ID
2. 一段具身引导词（参考语料的风格，贴合用户的叙事方式）
3. 引导词要绕过语义层，使用感官意象
4. 结尾给出一个身体动作指令（不是思维指令）
"""
```

### 4.3 LLM 涌现输出

```json
{
  "emergent_guidance": {
    "primary_card": "card_05",
    "recommended_kit": "kit_B",
    "kit_name": "迷失预警",

    "guidance_text": "你描述的那种'越准备越焦虑'的感觉，我认得它。\n\n那不是你准备不够——是你的设计者心态太早入场了。它在没有球的时候就开始调整姿势，结果越调整越僵。\n\n飞轮启动前最安静的时刻，恰恰是最需要信任的时刻。你不需要再推它了——你只需要把手放上去。\n\n现在，站起来，走三步。不是去做什么事——只是走三步，感受脚底踩到地板的感觉。三步之后，你会发现那个'准备'的声音安静了一些。\n\n就在那个安静里，开始。",

    "body_action": "站起来，走三步，感受脚底踩到地板的感觉",

    "style_note": "采用叙事_内省的风格，与用户输入一致；借鉴语料 corpus_05_003 的诗意意象（手、安静、信任）",

    "cycle_positioning": {
      "from": "设计者心态（过度准备阶段）",
      "to": "执行者入口（预热过渡阶段）",
      "next_kit_after": "kit_F（具身认知临战）"
    }
  }
}
```

### 4.4 涌现 vs 模板选择

| | 模板选择 | 涌现生成 |
|------|----------|----------|
| 方式 | 从预定文案中匹配 | LLM 实时生成 |
| 风格 | 固定 | 动态贴合用户输入风格 |
| 语料使用 | 不引用 | 引用细化语料的意象和句式 |
| 场景适应 | 通用 | 用户专属 |
| 成本 | 低 | 需一次 LLM 调用 |

**策略**：系统默认为**涌现生成**；当 LLM 不可用时，降级为基于匹配规则的模板选择。

## 7. 技术实现要点

### 7.1 LLM 调用链

```
用户输入
  │
  ├──→ EmbeddingProvider.get_embeddings(text)    // 向量化
  │
  ├──→ LLM 调用（阶段一匹配）
  │     系统提示词：cognitive_card_matcher
  │     传入：cards_metadata + user_input + user_history
  │     输出：matching_result
  │
  ├──→ 逻辑层细化（阶段二，无需 LLM）
  │     refine_corpus_by_keywords()
  │     refine_corpus_by_style()
  │     calculate_final_score()
  │
  └──→ LLM 调用（阶段三涌现）
        系统提示词：cognitive_kit_emergence
        传入：refined_corpus + kit_definitions + user_input
        输出：emergent_guidance
```

### 7.2 提示词设计要点

**阶段一提示词（匹配器）**：
- 角色：认知卡片匹配引擎
- 输入：用户文本 + 卡片元数据
- 输出：card_id + 置信度 + 匹配理由
- 注意事项：不要过度匹配，置信度低于 0.5 的卡片不输出

**阶段三提示词（涌现器）**：
- 角色：认知引导词生成器
- 输入：细化语料 + 锦囊定义 + 用户状态分析
- 输出：推荐锦囊 ID + 引导词 + 身体动作指令
- 注意事项：
  - 引导词必须使用感官意象，不使用抽象概念
  - 必须包含一个身体动作指令
  - 参考语料风格但不要直接复制
  - 引导词长度控制在 150 字以内

### 7.3 降级方案

| 场景 | 降级策略 |
|------|----------|
| LLM 不可用 | 直接用向量检索匹配卡片 → 从锦囊库选默认文案 |
| Embedding 不可用 | 基于关键词硬匹配（Jaccard 相似度） |
| 细化语料为空 | 使用卡片默认语料 + 锦囊默认文案 |
| 用户输入过短（<5字） | 不触发涌现，提示用户多描述一些 |

## 8. 与两层架构的关系

```
                ┌─────────────────────────────────────────┐
                │          执行模式（执行者心态）            │
                │   用户感知层：只看到卡片 + 锦囊 + 引导词   │
                └─────────────────────────────────────────┘
                              │ 涌现结果
                              ▼
                ┌─────────────────────────────────────────┐
                │         涌现引擎（本节定义）              │
                │   匹配 → 细化 → 涌现                    │
                └─────────────────────────────────────────┘
                              │ 读取
                              ▼
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│  卡片数据模型    │   │  语料库          │   │  锦囊定义库      │
│  (认知卡片)      │   │  (优质文笔)      │   │  (骨架 + 触发)   │
└─────────────────┘   └─────────────────┘   └─────────────────┘
                              ▲
                              │ 管理
                ┌─────────────────────────────────────────┐
                │         设计模式（设计者心态）            │
                │   添加语料、编辑层级、配置锦囊            │
```
