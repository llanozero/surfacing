# 认知卡片 · 设计理念总览

## 核心理念

认知卡片是一个**既是设计说明书，也是产品本身**的认知工具系统。它围绕一个根本问题展开：

> 当一个人试图设计一个工具来改变自己，他同时是**设计者**和**使用者**。这种自我指涉的结构产生了一个无法从内部解决的悖论——你需要遗忘才能进入状态，但遗忘意味着无法按计划执行；你需要信念才能启动飞轮，但信念需要飞轮转动才能产生。

这套系统不试图"解决"这个悖论，而是**绕过它**。

---

## 十张认知卡片

### Card 01 · 二阶观察者困境
**核心洞察**：当你同时是系统的设计者与使用者，元认知的审视目光会破坏执行的纯粹性。每一次执行时，设计者的意识都在场，而这本身就瓦解了执行者的沉浸状态。

**设计指令**：将设计态与执行态物理分离。工具必须拥有两种不可混淆的模式，模式切换需要真实的物理成本。

### Card 02 · 悖论绕过
**核心洞察**：某些悖论无法被"解决"——它们只能被绕过。用语言去对抗语言制造的困境，只会加深困境。

**设计指令**：工具的核心策略不是"说服"或"解释"，而是用感官锚点、环境线索、身体仪式来直接激活状态，绕过语言意识层。

### Card 03 · 环境级工具
**核心洞察**：工具不应告诉你"做什么"，而应改变"你在什么条件下做"。指令级工具激活设计者心态；环境级工具只创造条件和触发，执行者自然响应。

**设计指令**：工具架构为五层环境系统——触发器（环境线索）、容器（时间边界+最少约束）、过渡（无关沉浸预热）、沉淀（无评判记录）、关闭（仪式性结束）。每一层只改变条件，不规定反应。

### Card 04 · 容器非模具
**核心洞察**：滋养来自开放，但执行需要封闭。规范应设计为"容器"而非"模具"——容器提供边界，但不规定内部发生什么。

**设计指令**：只定义时间、空间、节奏的边界，不定义体验的内容。如禅宗坐禅：形式严格封闭，但内部体验完全开放。

### Card 05 · 合拍飞轮
**核心洞察**：存在一种节律，一旦进入就会自我维持。工具的任务是创建进入飞轮的入口，而非维持飞轮本身。飞轮一旦启动，工具应退出。

**设计指令**：设计"预热过渡"环节——一段无关、沉浸、低门槛的活动，作为从日常意识到专注状态的桥梁。点燃即撤，不越界。

### Card 06 · 直觉即压缩理性
**核心洞察**：直觉不是理性的对立面，而是理性内化到不需要显式计算的阶段。"刻意"之所以唤醒旧负面回路，是因为它调用显式、被命名的框架——而这些框架在历史上与失败经验绑定。

**设计指令**：不使用任何"你应该"的语言，不定义任何"正确方法"。所有引导通过感官通道而非语义通道。语义层完全留白。

### Card 07 · 具身认知
**核心洞察**：知识不在脑中，而**在你与处境的互动中涌现**。工具的目的不是告诉你答案，而是把你放到一个处境里，让答案自己从互动中长出来。

**设计指令**：工具的核心交付物不是信息，而是处境。设计目标从"传递正确认知"转变为"创造让正确认知自发涌现的条件"。

### Card 08 · 自发命名
**核心洞察**：旧框架的问题不在于"错"，而在于"早"——过早的命名污染了体验，用旧分类框住了新意蕴。正确的命名时机：当体验本身产生"寻求表达"的内在冲动，而非"应该总结一下"。

**设计指令**：在体验与命名之间设置强制延迟。命名不是任务，而是体验的自然溢出。

### Card 09 · 信念覆盖机制
**核心洞察**：信念不是通过"替换"来覆盖的，而是通过"让旧信念失去相关性"来自然消退的。旧的神经回路不会消失，但新回路的高频激活会抑制旧回路——不是对抗，而是让旧路径因长期不被激活而自然褪色。

**设计指令**：不设计"对抗旧信念"的环节。只创造高密度、高强度的新体验，让新回路的激活频率超过旧回路。完全的路径隔离。

### Card 10 · 重新定向能量
**核心洞察**：你不需要从零开始。上次失败信念的"残留"不是需要消灭的敌人——它恰恰是已经存在的能量，只是方向不对。工具不需要产生新能量，只需要重新定向已有的能量流。

**设计指令**：工具的起点不是"创造新状态"，而是"接住已有状态"。设计一个温和的转弯，而非一个彻底的断裂。

## 四层系统架构

十张卡片构成一个四层协同系统，层与层之间形成递进依赖关系：

| 层级 | 卡片 | 解决的问题 |
|------|------|------------|
| Layer 1 · 问题识别与元策略 | 01–02 | 承认困境的结构性，确立"绕过而非解决、感官而非语义"的元策略 |
| Layer 2 · 工具范式与设计原则 | 03–04 | 确立工具的根本范式：环境级（非指令级）；确立设计的根本原则：容器（非模具） |
| Layer 3 · 核心机制 | 05–08 | 飞轮解决启动、直觉解决执行通道、具身解决知识来源、自发命名解决沉淀 |
| Layer 4 · 转化与起点 | 09–10 | 信念覆盖让旧路径褪色、重新定向从任何起点开始 |

## 核心循环与八枚锦囊

系统运行在一个**设计者 ↔ 执行者**的核心循环之上：

```
设计者锚点 → 执行者具身 → 设计者复盘 → 外沿扩大
```

共八枚锦囊对应循环中的八个关键分支节点：

| 锦囊 | 名称 | 触发场景 |
|------|------|----------|
| A | 锚点确立 | 你正处于设计者心态——承认它、信任流程 |
| B | 迷失预警 | 注意力涣散、方向感弱化——回到感官锚点 |
| C | 负向沉沦 | 陷入负向信念、越搞越乱——允许暂停和失忆 |
| D | 自防御后 | 身体抽离结束，迷失了方向和经验——不要急着复盘 |
| E | 回归执行者 | 内生能量重新凝聚——经历稳妥的神经回路 |
| F | 具身认知临战 | 执行者状态中，临门一脚捅破窗户纸 |
| G | 复盘提取 | 回到设计者心态——从环境级角度优化系统 |
| H | 提前复盘警告 | 感到想要提前复盘——但执行者体验还不够，这是刻意体验的死锁循环 |

### 关键防线：提前复盘死锁

```
设计者心态 ──(未经历足够执行者具身)──▶ 提前复盘
    → 崩溃报错波及执行者状态
    → 再度崩溃 → 再度提前复盘 → 再度崩溃
    → 循环Bug：刻意体验，非自然体验
    → 内核内生能量磨损 → 撑不起流程 → 散架
    → 负面自我指涉无法自决 → 第二十二条军规
```

**唯一解法**：在感到"想要复盘"时，检查是否已完整经历执行者具身。如果没有——回到执行者轨道，继续沉浸。

## 数据模型：卡片、语料库与层级

### 卡片结构

每张卡片包含三段式内容（核心洞察 / 设计指令 / 产品形态）、标签、关键词、父子关系、语料库引用。字段参见 `docs/认知卡片数据模型设计.md`。

### 语料库

每张认知卡片都有一个**主题语料库**，存储与卡片主题相关的优质文笔、经典论述、范例段落。语料库的定位：

- **不是文档库**——每条语料是精炼的片段，而非完整文章
- **不是引用库**——语料是"如何写"的示范，而非"说了什么"的出处
- **是风格参照**——当需要表达卡片主题时，语料库提供文笔、句式、意象的参考

每条语料包含：来源、正文、设计者批注、风格标签、匹配关键词、质量评分、使用计数。语料类型分四类：摘录、改写、自创、引用。

### 层级继承

卡片支持父子嵌套：
- 子卡片继承父卡片语料库（继承的语料可用但不可删除）
- 关键词冲突时子卡片覆盖父卡片
- 子卡片 tags 自动包含父卡片所有 tags
- sections（三段式内容）不继承，子卡片必须独立定义

示例层级树：
```
根目录
├── Card 01: 二阶观察者困境
│   ├── Card 01-a: 设计者心态详解
│   │   └── Card 01-a-i: 模式切换仪式清单
│   └── Card 01-b: 执行者心态训练
├── Card 03: 环境级工具
│   ├── Card 03-a: 五层环境系统参考实现
│   └── Card 03-b: 感官锚点设计模式库
├── Card 05: 合拍飞轮
│   ├── Card 05-a: 预热过渡环节模板
│   └── Card 05-b: 节奏锚点设计
├── Card 07: 具身认知
│   ├── Card 07-a: 情境触发器清单
│   └── Card 07-b: 处境设计模式
...
```

## 涌现引擎：输入 → 匹配 → 锦囊生成

当用户输入一段文字时，系统通过三阶段管道自动匹配相关卡片、细化语料风格、涌现可用锦囊引导词：

### 阶段一 · 语义匹配
用户输入向量化（通过本地 Embedding Provider）→ 与所有卡片的关键词和内容做相似度匹配 → 返回 Top-3 卡片并给出置信度和匹配理由。同时分析用户心态（设计者/执行者/迷失）和循环位置。

### 阶段二 · 语料库细化
在匹配卡片的语料库中按 match_keywords 粗筛 → 按 style_tags 与用户输入风格对齐精筛 → 综合评分排序（quality_score × 0.4 + style_match × 0.3 + keyword_match × 0.3）。

### 阶段三 · 锦囊路径涌现
LLM 基于细化语料（血肉）+ 锦囊定义库（骨架/触发条件）→ 实时生成贴合当前用户的引导词。引导词必须使用感官意象、绕过语义层、包含身体动作指令。同时推演整条锦囊路径并输出风险预警。

### 技术基础设施

**向量知识库**：基于 AstrBot 的 FAISS 向量数据库 + SQLite FTS5 全文索引，支持稠密检索（向量相似度）和稀疏检索（BM25 关键词）的混合检索，经 RankFusion 加权融合后返回结果。

**本地嵌入模型**：通过 OpenAI 兼容的 `/v1/embeddings` 端点连接本地 LM 服务（LM Studio / Ollama / vLLM）。推荐中文模型：`bge-large-zh-v1.5`（1024 维）、`bge-m3`。

**降级方案**：LLM 不可用时，降级为向量检索 + 模板选择；Embedding 不可用时，降级为 Jaccard 关键词匹配；用户输入过短时，不触发涌现。

## 设计哲学

### 1. 阅读即构建
这些卡片不是"先读后用"的说明书。每一次阅读，你都在构建这个工具在你心智中的版本。读完即拥有。

### 2. 不追求完整理解
不需要一次性理解全部。卡片的排列顺序本身就是渐进式激活——从最有共鸣的一张开始，其余会自然跟进。

### 3. 卡片即界面
回顾设计原则时不是"回忆内容"，而是"回到卡片"。卡片的视觉形态本身就是认知锚点。

### 4. 环境优先于内容
使用环境比卡片内容更重要。安静、独处、不受打扰的环境本身就是工具的一部分。

### 5. 允许遗忘
不需要记住任何卡片的内容。一旦理解了系统架构，卡片的具体内容会"到了处境自会知道"。遗忘不是失败，而是信任具身认知的开始。
