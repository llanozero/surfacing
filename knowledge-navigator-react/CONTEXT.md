# 认知导航（Knowledge Navigator）

以"知识图谱 + 路径导航"为核心隐喻的个人知识管理应用。用户搜索概念（像搜索地点）、规划学习路径（像规划路线）、逐站浏览内容（像沿导航行驶）。

## Language

**导航节点（NavNode）**:
导航路径中的"站点"，连接认知卡片与导航方向。
_Avoid_: 路径节点

**认知卡片（Cognitive Card）**:
最小知识单元，回答"是什么"。包含标题、语料库、类型、绑定的导航节点。
_Avoid_: 认知节点

**导航图（NavGraph）**:
一组导航节点及其连接的命名空间。一个项目可包含多张导航图，用户可在图间切换、钻入子图。
_Avoid_: 知识图、认知子图

**途径点（Waypoint）**:
导航路线中的经停点。用户可通过添加多个途径点构建有序浏览序列。
_Avoid_: 站点、经停点

**序列浏览（Sequential Browse）**:
沿途径点顺序逐站加载并浏览认知卡片。
_Avoid_: 浏览视图、途径浏览

**分支探索（Branch Explore）**:
不按预设途径点，从当前节点自由选择下一跳的无序浏览模式。
_Avoid_: 自由分支浏览、自由导航

**导航痕迹（Nav Trace）**:
导航节点上的跳转记录，追踪从哪些节点跳转过来及频次，用于动态权重计算。
_Avoid_: 浏览历史、browse_history

**权重合成（Weight Composition）**:
将预设权重、导航痕迹、用户覆盖按优先级合成总权重序列的算法。
_Avoid_: 权重混合

**部署模式（Deployment Mode）**:
系统的运行形态。Lite 模式为纯本地单机运行；Pro 模式连接后端服务器，支持多用户与数据同步。

**认知卡片父子推导**:
认知卡片以扁平列表存储，运行时通过 `id` 层级路径（如 `root/1/1`）自动计算 parent/children，存储不含冗余的父子字段。
