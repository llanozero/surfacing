# 面板拖拽未跟紧鼠标问题修复

## 问题描述

拖拽节点上拉面板（DropDownPanel）的手柄时，面板位移量明显小于鼠标移动量，感觉面板"拖不动"或"跟不紧"。

## 根因

**文件**: `src/hooks/useDragPanel.ts` 第 49 行

```typescript
// 位移 /3 映射为面板位移（百分比）
const pct = st.startPct + (dy / 3 / h) * 100
```

`dy / 3` 对鼠标移动距离做了 1/3 阻尼。假设面板高度 600px：

| 鼠标下移 | 实际百分比 | 面板移动 |
|---------|-----------|---------|
| 150px | `(150/3/600)*100 = 8.3%` | 约 50px |
| 300px | `(300/3/600)*100 = 16.7%` | 约 100px |
| 600px | `(600/3/600)*100 = 33.3%` | 约 200px |

面板位移量只有鼠标位移的 **1/3**，用户体验上感觉面板滞后于鼠标。

## 修复

移除 `/3` 阻尼因数，改为 1:1 跟随：

```typescript
// 位移映射为面板位移百分比（1:1 跟随鼠标）
const pct = st.startPct + (dy / h) * 100
```

修复后的对应关系：

| 鼠标下移 | 实际百分比 | 面板移动 |
|---------|-----------|---------|
| 150px | `(150/600)*100 = 25%` | 约 150px |
| 300px | `(300/600)*100 = 50%` | 约 300px |
| 600px | `(600/600)*100 = 100%` | 约 600px |

面板位移量与鼠标位移量 **1:1** 映射，拖拽手感更跟手。

## 影响范围

- 仅 `useDragPanel.ts` 一个文件，1 行代码变更
- `setDragPct` 的 `Math.max(0, Math.min(92, pct))` 限幅保持不变
- 吸附逻辑不受影响
- touch 与 mouse 行为一致

## 验证步骤

1. 打开 DropDownPanel（half 或 full 态）
2. 按住面板顶部手柄垂直拖拽
3. 面板位移应紧跟随鼠标/手指位置，无明显滞后感
4. 松手后吸附到最近停靠位（collapsed/half/full）
