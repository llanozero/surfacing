## 一、背景

全局全览视图（Global View）是认知导航的入口画面，展示所有导航节点的拓扑结构，帮助用户快速理解知识领域的整体布局并选择导航入口。

## 二、功能需求

### FR-1: 画布仅展示导航节点

**描述**：全局全览画布中只渲染导航节点（Navigation Node），不显示认知卡片。

**理由**：
- 全局全览的职责是让用户选择"从哪个导航节点进入"，而非浏览知识卡片
- 认知卡片属于内容层，在内容浏览视图（Browse View）和树形管理视图（Tree View）中处理
- 简化画布视觉密度，降低用户认知负荷

**实现要点**：
- `graphData.nodes` 中只保留 `type: 'nav'` 的节点
- `graphData.edges` 中只保留导航节点之间的连接（nav → nav），移除认知卡片到导航节点的连接（card → nav）
- 力导向图仅对导航节点进行布局

### FR-2: 删除图例

**描述**：移除画布底部的颜色图例栏。

**当前图例**：
- 认知卡片（蓝色方框）
- 导航节点（青色圆点）
- 预设权重（实线）
- 浏览权重（虚线）

**理由**：
- 画布仅剩导航节点一种节点类型，无需颜色区分
- 减少底部占用空间，最大化画布面积

### FR-3: 选中导航节点弹出顶部下拉面板

**描述**：点击导航节点后，画布顶部弹出可拖拽的下拉面板（Drop-down Panel）。面板有三个停靠位置：收起态（仅底部边缘可见，含节点状态和拖拽控件）、半屏、全屏。该面板在全览视图和导航视图间共享——从一个视图切换到另一个时面板内容保持不变。

**交互流程**：

```
点击导航节点（全览或导航视图）
    ↓
节点高亮 + 脉冲动画
    ↓
顶部下拉面板滑出至半屏（默认）
    ↓
用户可：
  ├── 按住底部拖拽控件下拉 → 面板展开至半屏/全屏
  ├── 按住底部拖拽控件上推 → 面板收回至收起态
  ├── 点击「进入导航」→ switchView('nav')，传入 currentNodeId
  └── 点击其他导航节点 → 面板切换内容，保持当前拉取位置
```

**三段停靠位置**：

| 状态 | translateY | 可见内容 | 
|------|------------|----------|
| 收起态（collapsed） | `-85%` | 面板底部约 15% 露出，含选中节点名称 + 青色圆点 + "进入导航"按钮 + 拖拽控 |
| 半屏（half） | `-50%` | 拖拽控件 + 名称 + 描述 + 卡片/跳转统计 + "进入导航"按钮 |
| 全屏（full） | `0` | 半屏内容 + 绑定卡片列表 + 可跳转节点列表 |

**共享机制**：
- 面板 DOM 位于 `#app` 内作为全局浮层，不在任何单个 view 内部
- `switchView` 时，若目标视图为 global 或 nav 且面板已打开，面板保持可见和当前位置
- 若切换到 browse 或 tree 视图，面板自动隐藏
- `sheetState.node` 是全局状态，切换视图时不清空

**拖拽行为**：
- 手指/鼠标按住面板底部的拖拽控件区域上下滑动
- 下拉（手指向下）→ 面板展开，上推（手指向上）→ 面板收起
- 松手时根据位置自动吸附到最近停靠位
- css transition 控制吸附动画

**面板样式要求**：
- 定位：`position:absolute; top:0;`，覆盖在画布区域上方
- transform：通过 `translateY(-X%)` 控制可见量
- 外观：深色背景（`var(--bg-card)`），底部圆角，底部边框
- 拖拽控件：位于面板最底部，居中横条
- 动画：松手吸附时 `transition: transform .3s cubic-bezier(.32,.72,0,1)`

### FR-4: 搜索功能适配

**描述**：搜索框 placeholder 改为"搜索导航节点..."，搜索逻辑仅匹配导航节点。

```
│  认知导航 · 全览              │

│                              │
│   🟦 认知卡片（7个）         │

├──────────────────────────────┤
│  ▢ 认知卡片  ● 导航节点 ...  │  ← 图例

```

## 四、数据模型变更

### 导航节点新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `description` | string | 节点简要描述，用于信息面板展示 |
| `bound_cards` | string[] | 绑定的认知卡片 id 列表 |
| `next_nodes` | array | 出向连接的目标导航节点列表 |

### 前端 graphData 简化

```javascript
// 修改前：混合 card 和 nav 节点
nodes: [
  { id:'ml', type:'card', ... },
  { id:'nav-ai', type:'nav', ... }
],
edges: [
  { source:'ml', target:'nav-ai', weight:8 }  // card → nav
]

// 修改后：仅 nav 节点
nodes: [
  { id:'nav-ai', label:'AI 入门', type:'nav', r:24,
    description: '人工智能基础入门学习路径',
    boundCards: 3, nextCount: 4 }
],
edges: [
  { source:'nav-ai', target:'nav-adv', weight:6 }  // nav → nav
]
```

## 五、验收标准

- [ ] 画布中不渲染任何认知卡片节点
- [ ] 画布底部无图例栏
- [ ] 点击导航节点后顶部下拉面板滑出至半屏
- [ ] 面板可拖拽至全屏、半屏、收起三个位置（下拉展开、上推收起）
- [ ] 收起态底部边缘显示节点名称、拖拽控件和"进入导航"按钮
- [ ] 面板内"进入导航"按钮可触发视图切换
- [ ] 面板在全览和导航视图间共享，切换视图不清空面板状态
- [ ] 切换到浏览或管理视图时面板自动隐藏
- [ ] 点击其他导航节点时面板切换内容，保持当前拉取位置
- [ ] 搜索仅匹配导航节点
- [ ] 视图标题更新为"导航全览"
